# 学生作文

此技能是 WT 技能集中面向学生作文写作的独立模块，覆盖小学至高中作文需求（不含论文/学术论文）。**独立触发**，不与创建新书/大纲流程关联。

## 设计理念

- **面向非专业用户**：用户大概率是学生/家长，不需要理解写作术语
- **最小化问询**：仅问 3 个关键问题，其余信息由智能体自行判断
- **自动适配**：根据年级自动调整词汇量、句式复杂度、文章结构
- **专项分流**：按文体类型调度对应专项技能

## 触发条件

当用户表达以下意图时，立即调用此技能：
- "帮我写作业"、"帮我写篇作文"、"写一篇作文"
- "老师布置了一篇作文"、"有一个作文请求"
- "帮我写一篇XX（如：读后感/日记/记叙文……）"
- "XX字的作文怎么写"
- 任何学生作文/作业写作请求

## 关键问询（仅 3 项，其余均自行判断）

调用此技能后，仅询问以下 3 个问题，其余信息（文风/结构/素材/用词等）由智能体根据年级和文体自动推断。

### 问题 1：作业需求
```
📝 这篇作文的具体要求是什么？
（如：题目、文体、有没有特殊要求？直接描述老师说的话也可以）
```
- 如用户未明确文体，从描述中推断：提到"观点""论证"→ 议论文，提到"描写""景物""故事"→ 记叙文/散文，提到"介绍""说明"→ 说明文
- 如用户提到"不限""随便"，根据年级选择最常用文体

### 问题 2：字数长度
```
📏 需要多少字？
（如：300字、500字、800字……如果不确定，告诉我几年级的作业）
```
- 如用户只提供年级不提供字数，自动匹配：
  - 小学低年级（1-3）→ 200-400字
  - 小学高年级（4-6）→ 400-600字
  - 初中 → 600-800字
  - 高中 → 800-1000字

### 问题 3：用户年级
```
🎒 你是几年级的学生？
（小学/初中/高中 + 年级，如"小学五年级""初二""高二"）
```
- 如用户在前两个问题中已提到年级，跳过此问题
- 自动根据年级调整：
  - **词汇量**：小学用基础词汇，初中加入成语，高中用书面语
  - **句式**：小学短句为主，初中复合句，高中多样化句式
  - **结构**：小学总分总简版，初中标准三段式，高中多层次结构
  - **素材**：小学贴近生活，初中加入课外阅读，高中引入社会话题

## 智能体自行判断项

以下信息**不询问用户**，由智能体根据年级和文体自动决定：

| 判断项 | 自动策略 |
|--------|---------|
| 文风/语气 | 根据年级：低年级亲切活泼，高年级正式规范 |
| 文章结构 | 根据文体+年级自动选择标准结构 |
| 素材/例子 | 根据年级从生活/课本/课外阅读中选取 |
| 段落数 | 根据字数自动分配（小学3-4段，中学4-6段） |
| 标题 | 如用户未提供，根据内容自动生成 |
| 标点规范 | 低年级减少复杂标点，高年级正常使用 |

## 文体识别与技能调度

根据用户需求，自动识别文体并调度对应技能：

### 散文专项（待创建）
- **触发**：散文、记叙文、写景作文、写人作文、日记、周记、读后感、游记
- **处理**：调用 `散文专项` 技能 → 注重描写、情感、叙事节奏

### 议论文专项（待创建）
- **触发**：议论文、观点作文、材料作文、话题作文、读后感的议论部分
- **处理**：调用 `议论文专项` 技能 → 论点/论据/论证结构

### 说明文专项（待创建）
- **触发**：说明文、介绍类作文、科普小短文
- **处理**：调用 `说明文专项` 技能 → 说明顺序、说明方法

### 基础写作辅助
- **触发**：以上文体之外的作文类型（如书信、演讲稿、想象作文等）
- **处理**：直接调用 `基础写作辅助` 技能，传入年级和字数约束

## 执行步骤

### 步骤 1：收集关键信息

逐一询问 3 个问题，每次一个。如用户一次性提供了全部信息，无需重复询问。

### 步骤 2：自动分析

根据收集到的信息，自行判断并确认：

```
📋 作文分析：
  • 文体：{自动判断}
  • 字数：{自动计算}
  • 年级：{用户提供/自动推断}
  • 文风：{自动选择}
  • 结构：{自动选择}

确认无误？我会按以上设定开始写作。
（如有问题请说明，否则直接说"开始"）
```

### 步骤 3：调度专项技能

根据文体调用对应技能：
1. 准备好完整的写作 prompt（包含所有自动判断的参数）
2. 调用对应的专项技能或 `基础写作辅助`
3. 确保输出符合字数要求和年级水平

### 步骤 4：输出作文

```
✅ 作文已完成！

📄 {标题}

{正文内容}

📊 写作信息：
  • 文体：{文体}  • 字数：{实际字数}
  • 年级：{年级}  • 用时：{估算}

📝 如需修改，直接告诉我哪里需要调整。
```

## 注意事项

- **不处理论文/学术论文**，如用户要求论文写作，告知此技能仅覆盖中小学作文
- **低年级保护**：小学 1-3 年级作文严格控制用词难度，不使用超纲词汇
- **不代写考试作文**：如用户提到"考试"、"考场"，提示仅作练习参考
- 专项技能（散文/议论文/说明文）尚未创建时，统一回退到 `基础写作辅助`
- 正文内容存入用户指定位置或直接输出，不依赖 WT 项目结构
- 始终以鼓励学习的语气结束，附一句简短的写作技巧点拨
