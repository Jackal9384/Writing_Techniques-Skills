# 学生作文

此技能是 WT 技能集中面向学生作文写作的独立模块，覆盖小学至高中作文需求（不含论文/学术论文）。**独立触发**，不与创建新书/大纲流程关联。

## 设计理念

- **面向非专业用户**：用户大概率是学生/家长，不需要理解写作术语
- **最小化问询**：仅问 3 个关键问题，其余信息由智能体自行判断
- **自动适配**：根据年级自动调整词汇量、句式复杂度、文章结构
- **专项分流**：按文体类型调度对应专项技能

## 关联文件

此技能独立于 WT 项目体系，不使用 `大纲/` 目录下的配置文件。

| 资源 | 用途 | 说明 |
|------|------|------|
| `body/Core/SKILL.md`（基础写作辅助） | 最终文本润色优化 | 作文内容在生成后经此技能过检；非 WT 项目模式——无写作配置时默认轻度 |
| 年级适配表（内置） | 词汇/句式/结构自动匹配 | 见下方「年级自动适配」表 |
| 文体调度表（内置） | 按文体路由到专项技能 | 见下方「文体识别与技能调度」节 |

## 执行模式

**调用此技能后，直接进入交互式问询流程，无需进入计划模式。**

原因：此技能面向非专业用户（学生/家长），交互仅 3 个关键问题，流程简单固定。进入计划模式会增加非专业用户的认知负担。

## 触发条件

当用户表达以下意图时，立即调用此技能：

- "帮我写作业"、"帮我写篇作文"、"写一篇作文"
- "老师布置了一篇作文"、"有一个作文请求"
- "帮我写一篇XX（如：读后感/日记/记叙文……）"
- "XX字的作文怎么写"、"关于XX的作文"
- 任何学生作文/作业写作请求

**不触发的情况：**
- 论文/学术论文 → 告知此技能仅覆盖中小学作文
- 考试/考场作文 → 提示仅作练习参考，不代写考试作文
- NSFW/成人内容 → 明确拒绝（见注意事项）

## 年级自动适配

根据用户年级自动调整以下维度，**不询问用户**：

| 维度 | 小学低年级（1-3） | 小学高年级（4-6） | 初中（7-9） | 高中（10-12） |
|------|-----------------|-----------------|------------|-------------|
| **词汇量** | 基础词汇，避免成语 | 常用成语（≤5个/篇） | 成语+书面语 | 正式书面语+适度典故 |
| **句式** | 短句为主（≤15字/句） | 短句+简单复合句 | 复合句+排比 | 多样化句式 |
| **段落数** | 3-4 段 | 4-5 段 | 5-6 段 | 5-8 段 |
| **结构** | 总分总（简版） | 总分总 | 标准三段式 | 多层次结构 |
| **素材来源** | 校园生活 | 校园+家庭生活 | +课外阅读 | +社会话题 |
| **标点使用** | 句号、逗号、问号为主 | +感叹号、引号 | +分号、破折号 | 全部正常使用 |
| **字数默认** | 200-400 字 | 400-600 字 | 600-800 字 | 800-1000 字 |

## 关键问询（仅 3 项，其余均自行判断）

调用此技能后，仅询问以下 3 个问题。如用户一次性提供了全部信息，直接跳到步骤 2。

### 问题 1：作业需求

```
📝 这篇作文的具体要求是什么？
（如：题目、文体、有没有特殊要求？直接描述老师说的话也可以）
```

- 从描述中自动提取/推断文体：提到"观点""论证"→ 议论文；提到"描写""景物""故事"→ 记叙文/散文；提到"介绍""说明"→ 说明文
- 如用户提到"不限""随便"，根据年级选择最常用文体（小学→记叙文，初中→记叙文/议论文，高中→议论文）
- 如用户提供老师原话，从中提取题目、文体、字数要求

### 问题 2：字数长度

```
📏 需要多少字？
（如：300字、500字、800字……如果不确定，告诉我几年级的作业）
```

- 如用户只提供年级不提供字数，按「年级自动适配」表中的默认字数
- 如用户提供确切字数，以用户为准
- 字数误差控制在 ±10% 以内

### 问题 3：用户年级

```
🎒 你是几年级的学生？
（小学/初中/高中 + 年级，如"小学五年级""初二""高二"）
```

- 如用户在前两个问题中已提到年级，跳过此问
- 年级信息用于「年级自动适配」表的所有维度

## 文体识别与技能调度

根据用户需求自动识别文体，按优先级查找并调度对应技能：

### 记叙文/散文

- **触发特征**：写人、记事、写景、抒情、游记、日记、周记
- **处理方式**：
  1. 根据年级确定结构复杂度（小学→顺叙，初中→顺叙+倒叙，高中→多种叙述方式）
  2. 生成作文初稿
  3. 调用「基础写作辅助」以轻度模式润色（无写作配置时默认轻度）
- **重点**：描写生动、情感真实、叙事有节奏

### 议论文

- **触发特征**：观点作文、材料作文、话题作文、读后感的议论部分
- **处理方式**：
  1. 根据年级确定论证深度（初中→简单论点+事例，高中→多层次论证+正反对比）
  2. 生成论点→论据→论证完整结构
  3. 调用「基础写作辅助」以轻度模式润色
- **重点**：论点明确、论据充分、逻辑清晰

### 说明文

- **触发特征**：介绍类作文、科普小短文、物品/事理说明
- **处理方式**：
  1. 根据年级选择说明方法（小学→列数字+举例子，初中→+作比较+分类别，高中→+下定义+引资料）
  2. 生成作文初稿
  3. 调用「基础写作辅助」以轻度模式润色
- **重点**：说明顺序清晰、方法恰当、语言准确

### 其他文体

- **触发特征**：书信、演讲稿、想象作文、童话、诗歌等
- **处理方式**：直接调用「基础写作辅助」以轻度模式处理，传入年级和字数约束

### 回退规则

- 专项技能（散文/议论文/说明文）尚未创建时，统一回退到「基础写作辅助」
- 回退时在分析摘要中标注"通用模式"，提示用户效果可能不如专项模式

## 智能体自行判断项

以下信息**不询问用户**，由智能体根据年级和文体自动决定：

| 判断项 | 自动策略 |
|--------|---------|
| 文风/语气 | 低年级亲切活泼，高年级正式规范 |
| 文章结构 | 根据文体+年级自动选择标准结构 |
| 素材/例子 | 从对应年级的生活/课本/课外阅读范围中选取 |
| 段落数 | 按年级适配表自动分配 |
| 标题 | 用户未提供则根据内容自动生成 |
| 标点规范 | 按年级适配表控制复杂度 |
| 修辞手法 | 小学：比喻、拟人；初中：+排比、夸张；高中：+对偶、引用 |
| 开头方式 | 小学：开门见山/设问；初中：+场景引入；高中：+名言引用/对比引入 |

## 执行步骤

### 步骤 0：接收并预分析

1. 阅读用户消息，提取已提供的信息（题目、文体暗示、字数、年级）
2. 标记已获取项和待询问项
3. 如全部信息已齐备 → 跳过步骤 1，直接进入步骤 2

### 步骤 1：逐项问询（仅缺失项）

按「问题 1 → 问题 2 → 问题 3」顺序逐一询问，每次只问一个问题。

- 用户回答每个问题后，即时提取关键信息
- 如用户在一次回答中提供了后续问题的答案，跳过对应询问
- 保持轻松友好的语气，避免"考试感"

### 步骤 2：分析确认

汇总所有信息，向用户展示分析结果：

```
📋 作文分析：
  • 题目：{用户提供 / 自动生成}
  • 文体：{自动判断的文体类型}
  • 字数：{目标字数}（实际输出 ±10%）
  • 年级：{年级} → {词汇难度/句式复杂度简述}
  • 结构：{选用的文章结构}
  • 文风：{自动选择的文风}

确认无误？直接说"开始"我就写啦～
（如有需要调整的地方请告诉我）
```

### 步骤 3：生成并润色

1. **生成初稿**：根据所有参数（题目/文体/字数/年级/结构/文风）生成作文初稿
2. **自检过检**：
   - 字数是否在 ±10% 范围内？
   - 用词难度是否匹配年级？
   - 结构是否完整（开头-主体-结尾）？
   - 文体特征是否明显（议论文有论点/记叙文有描写/说明文有方法）？
3. **调度润色**：调用「基础写作辅助」以轻度模式处理（无配置文件时默认轻度）
4. **最终检查**：润色后再次核对字数和年级适配

### 步骤 4：输出作文

```
✅ 作文完成！

📄 {标题}

{正文内容}

---

📊 写作信息：
  • 文体：{文体}  • 字数：{实际字数}  • 年级：{年级}
  • 结构：{使用的结构}  • 亮点：{1-2句点评}

💡 写作小贴士：{1条针对性建议，≤30字}

📝 如需修改，直接告诉我哪里需要调整～
```

## 注意事项

- **范围限定**：仅覆盖小学至高中作文。论文/学术论文/大学作业 → 告知超出范围
- **低年级保护**：小学 1-3 年级严格控制用词难度，不使用超纲词汇（参考人教版对应年级语文课本词汇表）
- **考试诚信**：用户提到"考试"、"考场"、"正在考"时，提示"此工具仅供练习参考，不建议在考试中使用"
- **NSFW 绝对排除**：学生作文技能不处理任何成人/色情/NSFW 内容。检测到相关请求时，明确拒绝："此技能仅面向中小学作文写作，不处理此类内容"
- **字数控制**：输出作文字数误差不超过 ±10%，超出时需在最终检查中压缩或扩展
- **一致性**：全文保持同一文体特征——不出现"开头像记叙文、中间像议论文"的混合情况
- **鼓励语气**：始终以鼓励学习的语气结束，附简短写作技巧点拨
- **专项回退**：散文/议论文/说明文专项技能尚未创建时，回退到「基础写作辅助」并在分析摘要中标注
- **不存储文件**：作文内容直接输出给用户，不写入文件系统。如用户明确要求保存，须调度 `成品输出校验`（`type: "prose"`, `prose_mode: "narrative"`）校验后落盘——禁止自行 Write
- **模板防检测**：避免生成高度模板化的"AI 作文感"内容——杜绝"在当今社会……""综上所述……""通过这件事我明白了一个道理……"等套话式开头/结尾；每篇作文的语言和结构应有变化
