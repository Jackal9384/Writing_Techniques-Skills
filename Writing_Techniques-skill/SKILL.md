# Writing Techniques — 写作技法技能包

此技能是 Writing Techniques (WT) 体系的统一入口，覆盖小说创作的全生命周期。根据用户意图自动分发到对应子技能处理。

## 执行规则

1. **识别意图**：根据用户消息和上方路由规则，确定对应子技能
2. **读取子技能**：使用 Read 工具读取对应路径的 SKILL.md（路径相对于本技能根目录 `Writing_Techniques-skill/`）
3. **执行子技能**：严格按照子技能 SKILL.md 中的指令执行（包括是否进入计划模式、询问用户哪些信息等）
4. **歧义处理**：如果用户意图同时匹配多个子技能（如"写小说"可能触发创建新书或基础写作辅助），优先询问用户具体想做什么，或根据上下文（是否已有项目/是否在创作流程中）推断最合适的选择
5. **跨技能调度**：子技能之间可按需互相调度（如创建新书后自动建议创建人物或编辑剧情；NSFW项目创建后触发NSFW偏好配置；人物创建涉及NSFW字段时协调NSFW技能做词汇选择；Core/剧情编辑检测到零提示词指定章节时调度提示词增强先生成提示词再执行写作）
6. **NSFW偏好传播**：当 `项目信息.json` 中 `content_rating` 为 `NSFW` 时，创建新书/设定编辑/NSFW首次调用均应触发偏好配置询问；偏好数据（`nsfw_output_level` / `nsfw_character_tone` / `nsfw_tier_range`）写入同一文件后，所有后续技能自动读取

## 注意事项

- 子技能 SKILL.md 中标注"必须首先进入计划模式（EnterPlanMode）"的，务必遵守
- 子技能之间的调度通过读取对应 SKILL.md 并按其指令执行来完成
- 路径均为相对于本技能根目录的相对路径，实际读取时需拼接完整路径（`Writing_Techniques-skill/` + 子路径）
- 润色配置（`润色配置.json`）和项目信息（`项目信息.json`）是所有子技能共享的权威数据源；`项目信息.json` 同时承载 NSFW 偏好字段（由创建新书/NSFW技能/设定编辑维护）和伏笔数据（由长篇专项维护）
