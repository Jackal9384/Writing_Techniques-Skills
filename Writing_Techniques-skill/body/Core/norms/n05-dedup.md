# 规范 5：降重率规范

**核心原则：大纲/设定/角色/Prompt.md 等参考文件提供的是合法性验证，不是写作素材。正文必须对所有参考源进行二次加工后输出——直接引用、近义复述、跨章重复使用同一描述角度，均属违规。**

**为什么**：参考文件的意义是让 LLM 知道"这个角色有什么特征、这个世界有什么规则、这章要写什么"——即验证描写合法性。若正文照搬参考源描述，这套技能系统就失去存在价值。

**参考源 → 正文的正确链路**：

```
参考源中的原始数据（大纲/设定/角色/Prompt.md）
    │
    ▼
合法性验证（"这个角色确实有 B 罩杯""本章确实要写后山奇遇"）── ✓ 允许
    │
    ▼
禁止 ── 直接引用原句（"底盘紧致、乳峰高翘挺立"）
禁止 ── 直接引用 Prompt.md 中的提示词原文作为正文叙述
禁止 ── 近义改写原句（"底盘紧致，乳峰挺翘，即便放松也保持上翘"）
禁止 ── 跨章反复使用同一组描述词
    │
    ▼
要求 ── 换角度、换感官、换语境、换精度，二次创作后输出
```

## 四条禁令

**禁令 1：禁止完全引用（照搬原文）**

不得将任何参考文件中的描述语句原封不动或仅调换语序后用于正文。Prompt.md 中的提示词是"写作指令"而非"写作文本"——正文不得将提示词里的叙述性语句直接复制为正文段落。

> 反例（大纲原句 → 正文照搬）：大纲：`乳房并不丰硕，B 罩杯——胜在形态近乎完美：底盘紧致、乳峰高翘挺立` → 正文：`乳房的轮廓在烛光中半明半暗——B 罩杯，底盘紧致，乳峰挺翘……`（三个数据点完全复刻，仅加包装）✕
>
> 正例（二次加工——换感官+换语境）：`他解开她衣襟时，掌侧擦过一处：不大，刚好盈满手心。那团柔软在他指间微微上挑，像一瓣被晨露压弯后又弹起的花。` ✓（保留"不大"事实，换触感/语境/比喻）

**禁令 2：禁止近义复述（换皮不换骨）**

不得将参考源描述换几个同义词后当作新内容输出。判断标准：正文与参考源在**同一特征维度**使用**相同的数据、相同的比喻方向、相同的描写器官/部位**，或叙事结构与 Prompt.md 剧情要点一一对应，即视为近义复述。

> 反例：大纲：`阴茎粗长，约18cm，龟头饱满呈紫红色` → 正文：`又粗又长，目测接近二十公分，前端那个蘑菇头鼓鼓的，颜色偏深` ✕（每个数据点都找到同义词，但无新增角度）
>
> 正例（换角度——视觉换触觉/感受）：`她两只手才勉强握住。顶端蹭过她小腹时，她才发现那处的皮肤比想象中烫，像一块被太阳晒了一下午的石头。` ✓（换触感/温度/视角，无重复数据）

**禁令 3：禁止跨章重复（同一角度反复使用）**

同一人物/事物的同一特征，在不同章节中**不得**从同一角度使用同一组词汇重复描写。每次出现该特征时，必须换一个描述维度。

| 章节 | 描述同一特征"她身材娇小" | 判定 |
|------|------------------------|------|
| 第1章 | "她个子小小的，站在人群中只到别人肩膀" | ✓ 视觉/对比 |
| 第3章 | "她踮起脚尖还是够不到最上面那格" | ✓ 动作/功能后果 |
| 第5章 | "她的身形娇小，在人群中格外显眼" | ✕ 回到第1章同一角度 |
| 第8章 | "别人三步的距离她要走四步" | ✓ 行为节奏 |
| 第10章 | "她个子不高，但每次抬头看人时眼神从不落下风" | ✓ 视觉+性格（新组合） |

**禁令 4：禁止感官单一（始终用一种感官描写同一特征）**

同一特征的多次描写必须轮换感官通道，不能每次都用同一感官（如始终是视觉描述）。

| 感官通道 | 可用描写角度 |
|---------|------------|
| 视觉 | 形状、颜色、光影、对比 |
| 触觉 | 温度、质地、压力、重量 |
| 听觉 | 声音、节奏、呼吸、布料摩擦 |
| 动作/后果 | 该特征导致的行为后果（够不到、塞不进、被挡住） |
| 他人反应 | 他人的目光、动作、回避或靠近 |

## 合法二次加工手法

| 手法 | 操作 | 示例（大纲"身高180cm"） |
|------|------|------------------------|
| 换感官 | 从视觉换为触觉/听觉/动作 | "他进门时低头躲了下门框" |
| 换语境 | 嵌入互动场景而非静态陈述 | "她仰头看他，脖子酸了" |
| 换精度 | 用模糊感受替代精确数据 | "他比周围所有人都高出大半个头" |
| 换视角 | 从他人眼中看，而非客观叙述 | "站他旁边说话，总觉得自己像被一面墙罩着" |
| 换时间 | 不同时间/光线/状态下的不同呈现 | "晨光从他背后打过来时，影子把她整个人吞了进去" |
| 换隐喻 | 不同的比喻体系 | 一次用建筑比喻（"像面墙"），一次用自然比喻（"像棵树"） |

## 检验标准

写完一段涉及人物特征的正文后，逐条自检：

1. 有没有任何参考源中出现过的**原词或原数据**？（有 → 重写）
2. 这个特征是否**已用同样的感官通道**写过？这次换了吗？（没换 → 换感官/换语境）
3. 这段描写去掉后，参考源中的那条数据能否被**独立还原**？（能 → 太接近原文，重写）
4. 正文叙事结构是否与 Prompt.md 提示词剧情要点**一一对应**？（是 → 等于用提示词做底稿，重写）

## 补充规则（承自原"防过度润色"规范）

- **克制情感用词**：避免堆砌"心痛如绞"、"泪如雨下"等高度饱和的情感表达。情感靠情节与动作传递，不靠形容词堆叠
- **相近角度扩写**：从相邻语义维度展开扩写，而非原地叠加同义词。如已写"小巧玲珑" → 可从"因此走路轻快""在人群中容易被忽略""总被误认为比实际年龄小"等后果与表现角度扩写
