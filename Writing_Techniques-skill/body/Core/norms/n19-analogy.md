# 规范 1.9：禁用类比句

**为什么**：类比句——"不是……而是……""并非……而是……""不是……是……"——是 AI 写描写的默认捷径。用否定-对照来定义一件事的本质，读起来像叙述者在替读者解读一切。核心问题：**叙述者跳出来做裁判**，他不是在让读者看，他是在告诉读者"你这么看不对，我来告诉你正确的看法"。

**核心链路**：

```
类比（AI 默认）                        直接陈述（规范1.9 约束后）
──────────────                       ────────────────────
叙述者在定义"这是什么"                  事件本身在发生
否定-对照-定义 → 读者被"告知"            角色在做具体的事 → 读者自己"看见"
每次类比都是叙述者插嘴一次                 叙述者闭嘴，让事情说话
```

**规则：默认禁止使用类比句**

不得使用"不是A，而是B""并非A，而是B""不是A，是B"结构的类比句。可以直接陈述B，不需要先否定A再定义B。

```
禁用（类比）：
  "不是没有人说话的那种安静。是所有人都在等一个人的决定的那种安静。"

直接陈述：
  "大家都在等徐明发话。"
```

八个字做到的事不需要五十六个字做。直接陈述之后跟了具体的角色动作——握方向盘、合上手册、铅笔停在空中——安静本身已经通过动作被"看见"了，不需要类比句来定义它。

**唯一例外：情节上确实存在意想不到的转折**

只有当角色（或读者）有一个**已被前文建立的合理预期A**，而实际发生的是B，且这个反转本身就承载叙事意义时——类比句在此处不是叙述者做裁判，而是情节本身在翻转。除此之外一律禁止。

```
允许（意想不到的转折）：
  她以为他会骂她。他没有。他把外套递给她，说外面冷。

  ↑ "她以为A→实际B"是情节本身，不是叙述者在插嘴定义。
    前文建立了"他在生气"的预期，此处翻转才有了力量。
```

```
禁止（仍是叙述者在裁判——无转折，纯定义）：
  "她不是在害怕，而是在期待。"
  "他并非沉默，而是在用沉默表达蔑视。"

  ↑ 没有情节转折——叙述者只是在定义角色的状态"到底是什么"。
    改为直接陈述："他沉默着。但那种沉默让所有人都不舒服。"
```

**检测标准**：写完一章后搜索"不是""并非""与其说"——所有类比句结构标记删除，直接陈述B。仅在前文确实建立了合理预期A且反转本身承载叙事意义时保留。
