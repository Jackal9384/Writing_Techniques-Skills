# 规范 1.8：对话衔接描写

**为什么**：纯描述性叙事——叙述者从头到尾讲述发生了什么，读起来像产品说明书。AI 补全文本时默认把所有信息通过叙述者之口"报告"出来。规范 1.8 的作用是**用角色的对话来打断、衔接、承载描述信息**，让读者通过角色的眼睛和嘴巴进入场景。

**对话衔接的三种形式**：

| 形式 | 说明 | 本质 |
|------|------|------|
| **角色说出口的话** | 用人物之间的对话直接传递信息，替代叙述者陈述 | 角色在对他人的对话中承载信息 |
| **角色心里想说的话** | 用内心独白/心理闪念承载描述——角色在"对自己说" | 角色在与自己的对话中承载信息 |
| **想说但没说的话** | 其他角色认为他会说的、或读者能感知到的"咽回去的那句"——留白本身成为描述 | 角色未发生的对话同样承载信息 |

**核心链路**：

```
纯描述（AI 默认）                    对话衔接（规范1.8 约束后）
─────────────────────              ─────────────────────────
叙述者广播一切信息                    角色"开口"传递信息
描述→描述→描述（堆砌）                 描述→对话→描述→心理→描述（交替）
读起来像看说明书                      读起来像在听人讲故事
读者是"被通知"的                     读者是"偷听到"的或"听到"的
```

## 四条核心规则

**规则 1：信息尽量通过角色之口抵达读者**

世界设定、人物关系、环境氛围、过往事件——这些信息如果能通过角色的对话（说出口的或心里想的）传递，就不要让叙述者直接陈述。

| 叙述者直接陈述（应减少） | 对话衔接（更好） |
|----------------------|-----------------|
| "这间酒馆已有三百年历史，是整条街上最老的建筑。" | "『这破地方比城主年纪都大。』酒保擦着杯子，头也不抬。" |
| "她注意到他左手的旧伤——一道从虎口延伸到手腕的疤痕。" | "『你那手怎么弄的。』他缩了一下，把手插进口袋。『没什么。』" |
| "两人已经冷战三天了，谁都不愿意先开口。" | "她把茶杯推到他那边。他没接。杯子在桌上放凉了。她知道他在想什么——不就是三天前那件事？他要是想开口早就开了。" |

**规则 2：纯描述段落中必须有角色声音来"换气"**

连续纯描述（仅叙述者在陈述环境/人物/状态，无对话、无心理闪念、无角色声音）持续下去，读者会逐渐脱离角色的视角。判断标准是**读者的注意力位置**：如果连续纯描述让读者开始感觉自己不是在场景里、而是在"阅读关于这个场景的文字"，就需要角色声音介入。

角色声音可以是：
- 一句对话（说出口的）
- 一个心理闪念（"他注意到……""她突然想到……"）
- 一个被感知到的、没说出来的想法（"她等他开口。他没开口。"）

```
连续纯描述让读者脱离视角（应打断）：
  巷子的尽头是一扇半掩的木门。门上的漆已经剥落了大半……墙上爬了半人高的青苔，屋檐下挂着一排晾晒的草药，有些已经干透了……

修正（角色声音介入，把读者拉回场景）：
  巷子的尽头是一扇半掩的木门。门上的漆已经剥落了大半，露出下面灰白的原木。门槛上蹲着一只黑猫。

  "这猫从我来的时候就在那。"他回头看了她一眼，"三年了，没挪过窝。"

  她弯腰凑近那只猫——猫连眼睛都没睁。空气里有一股陈年木头混着药材的气味，从门缝里一丝一丝渗出来。
```

注意：角色声音插入后，描述本身仍在继续——它不是替换描述，是给描述一个"从谁的视角在看"的锚点。

**规则 3："想说但没说的话"是最高级的对话衔接**

角色把一句话压在喉咙里——其他角色或读者能感知到它的存在，但叙述者不替他说出来。

| 类型 | 操作 | 示例 |
|------|------|------|
| **角色自己咽回去** | 角色想说什么，但没开口，读者通过上下文感知到那句话的存在 | "她看了看他的行李，又看了看他。他等着她问'什么时候回来'。她没问。他也没说。" |
| **其他角色替他说** | 另一个角色在对话或心理中"脑补"出他会说的话 | "我知道他会怎么说——『你从来不听我把话说完。』但他不在这里。所以我替他说了。" |
| **读者替他说** | 叙述留白到读者自己会补上那句没说出口的话 | "他最后一次站在那道门前。手抬起来——又放下了。"（读者自己补：他想敲门。还是没敲。） |

**规则 4：对话衔接的豁免场景**

- 大纲/设定类文件（适用规范 1.5）
- 战斗场景中的连续动作描写（由战斗描写专项自行控制节奏）
- NSFW 场景中的身体白描段落（NSFW 专项有自己的对话/发声规则）
- 角色独处时纯粹的客观环境镜头——如"太阳从东边升起来""雪还在下"等一句话环境收束

**检测标准**：写完一段叙事/描写文本后通读一遍——纯描述段落中读者是否长时间听不到任何角色的声音？如果连续几段下来只有叙述者在"广播"，在最近的自然断点处插入角色对话或内心活动。不是数字检查，是阅读感受检查。
