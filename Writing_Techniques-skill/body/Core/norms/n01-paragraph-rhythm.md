# 规范 1：段落节奏控制

**为什么**：AI 默认倾向"产品报告式"写作——每个信息点用独立陈述句罗列，句间只有并列没有逻辑流转。本规范将彼此关联但被句号割裂的短句融合为有逻辑、有转折、有呼吸的自然句。

**核心链路**：

```
产品报告式写作（AI 默认）              自然叙事（规范1 约束后）
─────────────────────────          ────────────────────────
句号 = 分项标记                      句号 = 段落收束
每句独立陈述一个事实                   多句融合为一个逻辑流
句与句之间只有并列                     句与句之间有因果/转折/递进
读起来像看说明书                      读起来像在经历这件事
```

**原则**：约束的不是"一段能写多长"，而是**哪里不该用句末标点**。一段极长但标点使用正确的句子是被允许的。**禁止的是**在语义彼此关联的句子之间滥用句末标点（。！？…）将其截断为碎片。

**"句子"的定义**：指以句末标点（。！？… 等）收尾的**完整自然句**，一个自然句的结束表示一件事情被终结，要慎重考虑。

**核心规则：句末标点的正确使用**

| 标点 | 何时使用 | 何时不用 |
|------|---------|---------|
| 句号（。） | 语义完整收束、一个意群自然结束、形成段落感时 | 前后两句语义紧密关联、属同一逻辑链时——改用逗号连接 |
| 问号（？） | 疑问语气结束，**独立成段** | 连续追问挤在同一段（必须逐句拆段换行） |
| 感叹号（！） | 感叹/强烈语气结束，**独立成段** | 连续感叹挤在同一段（必须逐句拆段换行） |
| 省略号（…） | 留白、余韵、渐弱，**独立成段** | 与句号/问号/感叹号串联使用 |

**核心禁令：禁止句末标点链接**

彼此语义关联的句子之间，**不得**用句末标点串联为"X{标点}Y{标点}"的链式结构。应用逗号（，）融合为自然句，或用换行使独立情感句各自成段。

| 违规形态 | 说明 | 纠正 |
|---------|------|------|
| 短句 + 标点 + 短句 | 两个 6~15 字、语义关联的短句用句号/问号/感叹号断裂 | 句号→逗号合并；问号/感叹号→各自拆段换行 |
| 超短句 + 标点 + 任意句 | 超短句（≤5字）后方跟句末标点再接其他句子 | 超短句应单独成行，或用逗号并入前/后句 |
| 长句 + 标点 + 短句 | 长句以标点收束后紧跟一个语义相关的短句 | 句号→逗号合并为一个更长但逻辑流畅的自然句 |
| 任意句 + 标点 + 超短句 | 超短句前方有句末标点将其孤立 | 超短句并入前句（逗号），或独立成行 |

**纠正原则**：目标是**将断裂的语义碎片融合为有逻辑流转的自然句**——调整语序、增删连接词、改变句式结构，确保读起来像一句话自然流淌，而非两句话被逗号硬拼在一起。

| 句末标点 | 纠正路径 | 原因 |
|---------|---------|------|
| 句号（。） | 合并为一个完整自然句，或拆段换行 | 陈述语气中性，两种路径均可 |
| 问号（？） | **仅拆段换行**，禁止合并 | 疑问句情感独立，换行强化追问感 |
| 感叹号（！） | **仅拆段换行**，禁止合并 | 感叹句情感强烈，换行保留冲击力 |

**超短句处理规则**：

- 超短句（≤5字）在没有必要的情况下，不与其他超短句用句末标点相连，各自单独成行
- 有必要时（同一意群、快速动作序列等），将它们**融合为一个完整的自然句**——调整语序、增减虚词、用逗号或省略号连接
- 超短句成段时不得出现连续两个及以上的句末标点

**典型示例**：

反例（短句间句号链接）：`她走进房间。房间很暗。窗帘拉着。她打开灯。然后看到了桌上的信。`
正例（合并+拆段混合）：

> 她走进房间，窗帘紧拉着，光线昏暗，空气里浮着一层薄灰。
>
> 打开灯后，她看到了桌上的信。

反例（问号链接——连续追问挤在同一段）：`这是什么？这怎么可能呢？为什么会这样呢？`
正例（问号强制拆段）：

> 这是什么？
>
> 这怎么可能呢？
>
> 为什么会这样呢？

**检测标准**：写完后检查——语义关联的句子之间是否被句末标点截断？超短句是否孤立堆叠？发现即按上表修正。
