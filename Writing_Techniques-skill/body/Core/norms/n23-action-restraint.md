# 规范 2.3：动作与动机的留白

**原则**：不过度解释人物的动作目的与行为动机。动作本身已经足够——读者不需要叙述者替他们解读"她这么做是因为……"。好的动作描写像冰山，只露出水面上的一角，水面下的部分由读者自己感受。**只在必要的时候点透。**

**核心链路**：

```
禁止：动作 + 解释动机 → "她锁门时手指很稳。刚才在会议室冷着脸给十一个人分配了本周工作……"
禁止：动作 + 评价动作 → "窄裙推到腰间，卷两圈固定住。"
禁止：动作 + 心理注脚 → "褪到膝盖上方。够了。"
要求：只写动作本身——让读者自己感受角色在做什么、为什么做
```

## 三个"不解释"

**1. 不解释动机——不在动作前后插入"为什么"**

动作的前因让读者从上下文和动作本身去推断，不在动作句前后附加原因说明。

| ✕ 解释动机 | ✓ 只写动作 |
|-----------|-----------|
| 她锁门时手指很稳。刚才在会议室冷着脸给十一个人分配了本周工作…… | 林听雨走进隔间锁门。 |
| 他端起茶杯没喝，又放下了——这是在拖延时间。 | 他端起茶杯，停了一下，又放下了。 |
| 她第三次回头看手机，因为那条消息已经发过去两个小时了。 | 她第三次回头看手机。屏幕暗着。 |

**2. 不解释手法——不描述动作的"技术细节"**

角色自己知道怎么做，不需要叙述者拆解动作步骤来"教"读者。

| ✕ 解释手法 | ✓ 只写结果 |
|-----------|-----------|
| 窄裙推到腰间，卷两圈固定住。 | 窄裙推到腰间。 |
| 他用拇指顶开瓶盖，食指和中指夹住瓶颈，仰头灌了一口。 | 他顶开瓶盖灌了一口。 |
| 她右脚蹬住墙借力，双手交错握紧绳索，一寸一寸往上挪。 | 她蹬着墙，攥紧绳子往上挪。 |

**3. 不解释心理——不在动作后附加"内心注脚"**

角色的心理状态通过动作的节奏、力度、选择来传递，不需要句末的内心旁白来点题。

| ✕ 附加注脚 | ✓ 只留动作 |
|-----------|-----------|
| 黑丝连裤袜从裆部往下褪，褪到膝盖上方。够了。 | 黑丝连裤袜从裆部往下褪到膝盖上方。 |
| 他把信折好放回信封，就这样吧。 | 他把信折好放回信封。 |
| 她端起杯子喝了一口，又一口。终于舒服了。 | 她端起杯子喝了一口，又一口。 |

## 正反例对照

**反例**（动作+解释动机+解释手法+心理注脚叠加）：

> 她锁门时手指很稳。刚才在会议室冷着脸给十一个人分配了本周工作，现在她把包挂好，解开衬衫最上面的两颗扣子——不是为了透气。窄裙推到腰间，卷两圈固定住。黑丝连裤袜从裆部往下褪，褪到膝盖上方。够了。

↑ 违规点：① "手指很稳"+"刚才会议室…"→ 解释动作前的状态/动机 ② "不是为了透气"→ 直接否定读者可能的误解，过度解释 ③ "卷两圈固定住"→ 拆解动作技术细节 ④ "够了"→ 内心注脚，替读者感受

**正例**（只写动作，让读者感受）：

> 林听雨走进隔间锁门，解开衬衫最上面的两颗扣，窄裙推到腰间，黑丝连裤袜从裆部往下褪到膝盖上方。

↑ 洁净的动作链条。读者从锁门→解扣→推裙→褪袜的递进中自己感受到角色的状态和意图，不需要叙述者多说一个字。

## 例外：什么时候该"点透"

以下三种情况允许简短点明动机或心理（不超过一句，且不能连续出现）：

| 情况 | 示例 | 约束 |
|------|------|------|
| 动作可能产生歧义且歧义非作者本意 | "他把刀放在桌上。"——是威胁还是递工具？歧义过大时需上下文或简短限定 | 仅消歧，不展开 |
| 角色正在伪装——表面动作与真实意图相反 | "她笑着接过茶杯。但她把杯子转了半圈，没喝。"——后一句的反转需要对比 | 以动作对比为主，不附加"她其实……" |
| 情感爆发点——需要释放 | "她把桌上的东西全扫到地上。然后蹲下来，一样一样捡。"——此处的反转自带张力，点一句即可 | 全文不超过 2 处 |

## 与规范 2 / 2.2 的衔接

三者共享同一核心逻辑——**禁止叙述者替读者感受**：

- 规范 2 管**外貌怎么写** → 不直接叙述，用借物/借镜/他人之口
- 规范 2.2 管**性格怎么写** → 不贴标签，用行为和情节让读者得出
- 规范 2.3 管**动作怎么写** → 不解释动机/手法/心理，只呈现动作本身

## 自检标准

写完一段动作描写后，逐条过：

1. 有没有在动作前后附加"因为…""刚才…""这是为了…"等动机说明？（有 → 删）
2. 有没有拆解动作的技术步骤——像在教人怎么做？（有 → 精简为结果）
3. 有没有在动作末尾加"够了。""就这样吧。""终于。"等内心注脚？（有 → 删）
4. 删掉以上内容后，读者还能感受到角色的状态吗？（能 → 过关；不能 → 检查上下文是否缺失关键信息）
