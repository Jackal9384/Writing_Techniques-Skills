# 规范 1.6：破折号禁令

**原则**：双字线破折号 `——`（U+2014 U+2014）在中文正文中**禁止使用**。唯一例外：声音延长（如"啊——"表示拖长的叫声）等特定写作技法中 `——` 是标准表达方式，允许保留。

**为什么禁止**：`——` 占两个字宽、视觉冲击力强，但绝大多数可被更精确的标点替代（逗号、句号、省略号、冒号各有明确语义）。大量使用 `——` 是 AI 生成文本的典型特征，导致破折号泛滥、停顿节奏单一。

**替代规则**：

| 原用法 | `——` 原句 | 替代 |
|--------|-----------|------|
| 解释说明 | `他提到了那个人——他的父亲` | 逗号：`他提到了那个人，他的父亲` / 括号：`他提到了那个人（他的父亲）` |
| 转折 | `她想说点什么——又咽了回去` | 逗号：`她想说点什么，又咽了回去` |
| 停顿/犹豫 | `我——我不知道` | 省略号：`我……我不知道` |
| 强调 | `只有一个答案——不` | 句号拆分：`只有一个答案。不。` |
| 话语中断 | `你难道——` | 省略号：`你难道……` |
| 插入补充 | `张三——那个从来不笑的人——居然笑了` | 逗号：`张三，那个从来不笑的人，居然笑了` |
| 突然中断+延长 | `"你——"她指着他的鼻子，尾音拖了三秒才接上"——给我站住"` | 省略号：`"你……"她指着他的鼻子，尾音拖了三秒才接上"……给我站住"` |

**允许保留的例外**：

| 用法 | 示例 | 原因 |
|------|------|------|
| 声音延长 | `"救命啊——"声音在山谷里拖了很长` | 表示声音拖长，省略号不适用（省略号是断续/渐弱，非延长） |
| 拟声词延长 | `呜——汽笛声响彻码头` | 同上，声音延长的唯一标准表记 |

**硬约束**：

- **全技能不豁免**：NSFW、成品校验、提示词增强——没有任何技能允许在产出文本中保留非例外用途的 `——`。这是跨技能的绝对禁令，不进入 `exempted_norms` 列表，任何技能无权豁免
- 成品输出校验在结构扫描中**强制过检本规则**——发现非例外用途的 `——` 一律按上述替代表自动修正；无法确定用途的标记 `[⚠️ 需人工：破折号用途不明]`
- 人物对话中的声音延长不在此限，但连续出现 ≥3 个 `——` 时触发提醒——可能不是技法需要而是写作习惯
