# 基础写作辅助

此技能是写作系统的**文本处理基础层**。所有需要写入文件系统的非格式性文本内容（正文、描写、对话、叙事等），在写入前必须经过此技能优化，以提升逻辑性与可读性。

## 核心定位

- **必经之路**：任何写作技能在将非格式性文本写入文件前，必须先调用此技能进行优化
- **专项调度**：当内容超出此技能范围时（NSFW 内容、言情专项等），自动识别并调度对应专项技能处理
- **模式感知**：始终从项目 `大纲/润色配置.json` 读取对应类型的润色模式（大纲类读 `大纲.polish_mode`，正文类读 `正文.polish_mode`），依据轻度/中度/重度调整加工强度

## 触发条件

### 用户直接触发

当用户表达以下意图时调用此技能：

- "润色这段文字"、"优化写作"、"帮我改一下这段"
- "写正文"、"开始写正文"、"写章节"、"写这一段"
- "改写"、"润色"、"优化一下"、"帮我看看这段"
- 任何表达"对文本进行优化/润色/规范化处理"的表述
- 用户在对话中提供待写入的正文内容

### 技能间调用

其他写作技能在写入非格式性内容前，必须：
1. 先将待写入的文本传入此技能
2. 由此技能按写作规范优化后返回
3. 再将优化后的文本写入目标文件

## 关联文件

| 文件 | 位置 | 用途 | 读写 |
|------|------|------|------|
| `润色配置.json` | `大纲/` | 润色模式（大纲类读 `大纲.polish_mode`，正文类读 `正文.polish_mode`） | 读写 |
| `项目信息.json` | `大纲/` | 内容分级（`content_rating`），用于 NSFW 检测调度 | 只读 |

| `Prompt.json` | `大纲/剧情/` | 预生成的章节写作提示词（由提示词增强技能产出），零提示词指定章节时优先读取 | 只读 |

## 执行模式

**由用户直接触发时**：进入计划模式（EnterPlanMode），列出处理步骤后执行。

**由其他技能调用时**：跳过计划模式，直接按如下步骤处理：

### 步骤 0：零提示词检测与 Prompt.json 读取

**仅当用户直接触发且未提供正文/提示词内容时执行**（如"写第3章""写正文"但无任何剧情描述或写作方向）。

1. 从用户消息中提取章节号（如"第3章"）
2. 检查 `大纲/剧情/Prompt.json`（优先）或 `outline/plot/Prompt.json` 是否存在
3. 若存在 → 读取该文件，查找目标章的 `prompt_text`：
   - 命中 → 提取该章的完整提示词，将其作为写作指令，跳过步骤 1 直接进入步骤 2（内容类型识别）
   - 未命中 → 询问用户：是否调度「提示词增强」先生成提示词，或由用户直接提供写作方向
4. 若 `Prompt.json` 不存在 → 同上，询问用户是否先生成提示词

**由提示词增强技能调用时**：收到的数据包中已包含完整提示词，跳过此步骤。

### 步骤 1：读取润色配置

从项目 `大纲/润色配置.json`（或对应语言的 `polish-config.json`）读取润色模式。该文件包含两类配置：

- `大纲.polish_mode` — 大纲类文本润色程度
- `正文.polish_mode` — 正文类文本润色程度

| 模式 | 加工策略 |
|------|---------|
| `轻度` | 仅书面化、规范化书写，保留用户原话结构与用词 |
| `中度` | 在用户原话基础上小幅优化表达，改动幅度 ≤45% |
| `重度` | 保留原意，完全改写润色，但须遵守本技能的降重率规范 |

### 步骤 1.5：正文润色程度确认

**仅当待处理内容为正文类（叙事文本、对话文本、描写文本）且将写入 `正文/` 文件夹时执行此步骤。**

读取到 `正文.polish_mode` 后，向用户确认：

```
✏️ 当前正文润色程度为「{正文.polish_mode}」，大纲润色程度为「{大纲.polish_mode}」。
   在正文书写阶段，是否沿用此润色程度？
   • 是 — 沿用当前正文润色程度
   • 否 — 重新选择润色程度
```

如用户选择"否"，则重新询问：
```
✏️ 请选择正文润色程度：
  • 轻度 — 保留用户原话，仅书面化、规范化书写
  • 中度 — 小幅优化用户原话（改动幅度 ≤45%）
  • 重度 — 仅保留原意，完全改写、润色、扩写内容
```

用户重新选择后，更新 `润色配置.json` 中 `正文` 的 `polish_mode`、`mode_description` 和 `last_updated` 字段。

### 步骤 2：识别内容类型

判断待处理文本属于哪一类别，并据此确定使用的润色配置：

| 内容类型 | 润色配置 | 应用规范 |
|---------|---------|---------|
| **叙事文本** | `正文.polish_mode` | 故事推进、事件描述 → 应用全部正文适用规范（1/2/2.2/3/4/5） |
| **大纲文本** | `大纲.polish_mode` | 剧情大纲、章节规划 → 应用规范 1.5，其余规范酌情 |
| **对话文本** | `正文.polish_mode` | 人物对白 → 重点应用规范 4 |
| **描写文本** | `正文.polish_mode` | 人物描写、场景描写 → 重点应用规范 2、3 |
| **专项内容** | 按需 | NSFW、言情等 → 调度对应专项技能 |

#### 步骤 2.1：NSFW 内容检测（三级扫描）

检测到以下**任一条件**时，标记为 NSFW 专项内容并调度 NSFW 技能处理：

**一级 — 显性性词汇（直接命中）：**
文本中出现性器官直称、性行为动词、性相关体液词汇（如：阴茎、阴道、做爱、高潮、精液、爱液、操、干等及其同义词/代称），直接判定为 NSFW。

**二级 — 性场景描写（场景命中）：**
文本不出现显性词汇但描写了以下场景：
- 床戏/亲密接触场景（接吻以上尺度的身体接触描写）
- 自慰场景（涉及性器官触碰的描写）
- 性暗示场景（脱衣、抚摸、喘息呻吟等前戏/边缘行为描写）
- 情色幻想/性幻想（角色脑内明确的情色想象内容）

**三级 — 语境渗透（语境命中）：**
- 文本整体虽为一般叙事，但包含连续的性挑逗/性暗示对话（≥3轮）
- 角色互动以性吸引力为核心驱动力（如勾引、诱惑场景）
- 用户在上文已明确指示当前章为 NSFW 章节

**不触发条件（避免过度调度）：**
- 仅出现"胸"/"腿"/"臀"等身体部位词且上下文为正常描写（穿衣、走路、外貌），非情色语境 → 不触发
- 接吻描写如无进一步身体接触暗示 → 不触发
- 医学/生理卫生语境下的器官名称 → 不触发

#### 步骤 2.2：混合内容处理

当文本中仅**部分段落**为 NSFW 内容时：

1. **按段落分割**：以段落为单位，将文本拆分为「一般段落」和「NSFW 段落」
2. **标记边界**：记录 NSFW 段落的起止位置
3. **分轨处理**：
   - 一般段落 → Core 直接按对应规范处理
   - NSFW 段落 → 调度 NSFW 技能处理
4. **统一整合**：NSFW 技能返回处理后，按原位置拼合，Core 做最终全篇一致性过检（步骤 4）

### 步骤 3：按规范逐条优化

依据内容类型，按下方规范应用矩阵逐条过检（✓=强制应用 / △=酌情应用 / ✕=不适用 / ◇=专项技能决定）：

| 规范 | 叙事文本 | 大纲文本 | 对话文本 | 描写文本 | NSFW返回文本 |
|------|---------|---------|---------|---------|------------|
| 规范 1（段落节奏） | ✓ | △ | ✓ | ✓ | ✓ |
| 规范 1.5（大纲特殊） | ✕ | ✓ | ✕ | ✕ | ✕ |
| 规范 2（间接描写） | ✓ | ✕ | ✕ | ✓ | ◇（NSFW判定豁免） |
| 规范 2.2（性格间接化） | ✓ | ✕ | ✕ | ✓ | ◇（NSFW判定豁免） |
| 规范 3（风景穿插） | ✓ | ✕ | ✓ | ✓ | ✓ |
| 规范 4（对话增强） | ✓ | ✕ | ✓ | ✕ | ✓ |
| 规范 5（降重率） | ✓ | △ | ✓ | ✓ | ✓ |

**NSFW 返回文本**整合时：Core 依据 NSFW 返回的 `exempted_norms` 跳过对应规范，其余规范照常过检（详见下方「写作规范」章节）。

### 步骤 4：整合与最终输出

**4.1 NSFW 返回整合**（如步骤 2 调度了 NSFW 技能）：

1. **段落拼合**：将 NSFW 返回的 `processed_text` 按原位置拼回全文中
2. **豁免跳过**：依据 `exempted_norms`，在后续过检中跳过规范 2 和规范 2.2（NSFW 全档豁免间接描写与性格间接化）
3. **全篇一致性过检**：对其余规范（1/3/4/5）做最终全篇扫描——确保 NSFW 段落与一般段落的段落节奏、换气频率保持协调，不出现"一段密密麻麻、一段稀疏空洞"的节奏断层
4. **OOC 确认**：如 NSFW 返回 `ooc_warnings` 非空，在输出前向用户展示标注并询问确认

**4.2 输出优化结果：**

返回优化后的文本，附带简要说明做了哪些调整。如调度了专项技能，将专项技能的元数据（`nsfw_tier_used` / `sexy_value` / `key_changes`）一并返回。

## 写作规范

以下七项规范是此技能的核心处理标准（含大纲专用规范 1.5 和性格间接化规范 2.2）。优化文本时**逐条过检**，不可跳过。

### 规范 1：段落节奏控制

**原则**：非必要不使用长段文字。短段落提升阅读节奏，长段落仅在必要时出现。**禁止短句、超短句、长句之间使用句末标点链接**——彼此衔接时应使用逗号或直接换行。

**"句子"的定义**：本规范中的"句子"指以任意标点符号（。！？… ~ 等）收尾的**完整自然句**。无论是陈述句、疑问句、感叹句、省略句，只要语义完整、以标点收束，均受本规范约束。例如"这是什么？""这怎么可能呢！""为什么会这样呢？"——三者均为独立自然句，不得以句末标点串联。

**具体规则**：

- 一段至多容纳 2~3 个以句末标点（。！？… 等）收尾的完整自然句，超过则拆分段落
- 一段一句为常态，至多两句一段；极少数需要密集叙事时放宽至三句
- 写长句时优先使用逗号（，）连接，非必要不用句末标点切分
- 句号（。）仅在段落收束、语义完整形成章节感时使用
- 感叹号（！）和问号（？）收尾的句子情感强烈，**不得合并**——必须以换行独立成段

**核心禁令：禁止句末标点链接三类句子**

短句、超短句、长句之间**不得**使用句末标点（。！？…等）彼此串联。三类句子的衔接一律使用逗号（，）或直接换行分段，不允许出现"X{标点}Y{标点}"的链式结构。

| 违规形态 | 说明 |
|---------|------|
| 短句 + 标点 + 短句 | 两个 6~15 字的短句不得用句号/问号/感叹号相连 |
| 超短句 + 标点 + 任意句 | 超短句（≤5字）后方不得跟句末标点再接其他句子 |
| 长句 + 标点 + 短句 | 长句收尾标点后不得紧跟一个短句并用标点收束 |
| 任意句 + 标点 + 超短句 | 超短句前方不得有句末标点——超短句应单独成行或用逗号并入前句 |

**纠正方式**：遇到句末标点链接时，按句末标点类型分路径处理：

| 句末标点 | 纠正路径 | 原因 |
|---------|---------|------|
| 句号（。） | 合并为逗号，或拆段换行 | 陈述语气中性，两种路径均可 |
| 问号（？） | **仅拆段换行**，禁止合并 | 疑问句情感独立，换行强化追问感 |
| 感叹号（！） | **仅拆段换行**，禁止合并 | 感叹句情感强烈，换行保留冲击力 |
| 省略号（…） | **仅拆段换行**，禁止合并 | 留白/余韵需独立空间呼吸 |

**超短句处理规则**：

- 超短句（≤5字）在没有必要的情况下，不与其他超短句用句末标点相连，各自单独成行
- 有必要时（同一意群、快速动作序列等），使用逗号（，）相连，不用句末标点
- 超短句成段时不得出现连续两个及以上的句末标点

**反例 1**（短句间句号链接）：
> 她走进房间。房间很暗。窗帘拉着。她打开灯。然后看到了桌上的信。

**正例 1**（合并+拆段混合）：
> 她走进房间——窗帘紧拉着，光线昏暗，空气里浮着一层薄灰。
>
> 打开灯后，她看到了桌上的信。

**反例 2**（超短句堆叠——句号链接）：
> 他停下。回头。皱眉。没说话。

**正例 2**（拆段——各自独立）：
> 他停下，
>
> 回头，
>
> 皱眉。
>
> 没说话。

**反例 3**（超短句撞句号）：
> 跑了。追。没追上。算了。

**正例 3**（有必要时逗号相连）：
> 跑了，追，没追上——算了。

**反例 4**（长句+句号+短句链）：
> 他将手中的信纸翻来覆去看了三遍，每一个字都像针一样扎进眼睛里，窗外的雨声渐渐大了起来。他放下信。叹了口气。

**正例 4**（拆段——短句独立成段）：
> 他将手中的信纸翻来覆去看了三遍，每一个字都像针一样扎进眼睛里，窗外的雨声渐渐大了起来。
>
> 他放下信，
>
> 叹了口气。

**反例 5**（短句+句号+超短句）：
> 她推开门走进客厅，沙发上坐着一个陌生男人。是他。

**正例 5**（合并——句号改逗号）：
> 她推开门走进客厅，沙发上坐着一个陌生男人——是他。

**反例 6**（问号链接——连续追问挤在同一段）：
> 这是什么？这怎么可能呢？为什么会这样呢？

**正例 6**（问号强制拆段）：
> 这是什么？
>
> 这怎么可能呢？
>
> 为什么会这样呢？

**反例 7**（感叹号链接——情感堆叠消解冲击力）：
> 他做到了！他真的做到了！所有人都不敢相信！

**正例 7**（感叹号强制拆段）：
> 他做到了！
>
> 他真的做到了！
>
> 所有人都不敢相信。

**反例 8**（混合标点链接——问号+感叹号挤在同一段）：
> 你疯了吗？快停下！这会害死你的！

**正例 8**（逐句拆段）：
> 你疯了吗？
>
> 快停下！
>
> 这会害死你的！

### 规范 1.5：大纲类文本特殊处理

**仅适用于大纲/剧情/设定类文件。**

- 允许使用大段连接的文字
- 减少句号使用，以分号（；）分隔意群
- 保持条目式的清晰结构，不强制短段分行

**示例**：
> 主角在此阶段经历三次关键转折：首次遭遇敌对势力，在逃亡中意外获得秘宝；秘宝引发出租体内的潜藏血脉，导致外貌与性格发生微妙变化；最终在一次街头冲突中暴露能力，被路过的宗门长老注意到并收为记名弟子

### 规范 2：人物描写的间接化

**原则**：避免直接的、长段的人物外形与行动叙述。多用间接手法让描写生动。人物特征不必在初登场时一次性交代完毕——没有人一见面就盯着别人的胸、腿、头发看，那很不礼貌。好的描写像剥洋葱，一层一层来。

**具体规则**：

- **借物喻人**：通过物品、环境来折射人物特征
  - 反例：她长得很美，身材纤细。
  - 正例：风一吹，那件旧旗袍在她身上晃荡得像挂在了衣架上。
- **借镜喻人**：通过他人视角/反应来映衬人物
  - 反例：他走进酒馆，所有人都注意到了他的高大身材。
  - 正例：他弯腰钻进酒馆门框时，靠门那桌的酒客下意识往后挪了半寸椅子。
- **借他人之口（借喻）**：不直接叙述特征，而是让另一个角色在对话或内心戏中点出
  - 反例：她有一双惊人的长腿。
  - 正例：身边的闺蜜扫了一眼，嘀咕了句"腿玩年啊。" / 身后的男生压低声："这腿比我命都长。"
- **打趣俏皮话**：用轻松、略带调侃的笔调描写，不板着脸叙述
- **短篇白描**：短段落可直接用白描，但不堆砌形容词
  - 正例：她瘦，白，走路没声。

#### 手法 2A：延迟揭示——特征不必在初登场时交代

**原则**：角色的一些外形特征不必在第一次出场时就全部抛出。现实中没有人会一照面就把对方从头到脚扫描一遍——那是 AI 的写法，不是人的写法。

**操作规则**：
- 初登场时，仅描写对当下场景有意义的特征（如：打架场景写体型，对话场景写表情，搜索场景写视力）
- 其余特征在后续章节中，在**该特征被看见的时机**自然带出
- 特征第一次被提及时，优先使用**借镜喻人**或**借他人之口**，而非叙述者直接陈述

| 特征 | 初登场写不写？ | 什么时候写？ |
|------|-------------|------------|
| 胸部/身材 | ✕ 不写（谁上来就盯胸？） | 角色进入亲密关系、换衣服、或他人偷瞄时 |
| 长腿 | △ 如角色正走路/跑步可写 | 他人内心戏、或她的动作中体现（"一步两个台阶"） |
| 长发/发型 | ✓ 可写（视觉第一印象） | — |
| 身高 | ✓ 可写（空间关系有意义） | — |
| 伤疤/纹身 | ✕ 不写（非当下可见） | 露出时写——脱衣服、挽袖子、风吹起衣角时 |
| 手/手指 | ✕ 不写 | 角色用手做事时——弹琴、握住东西、递物品时 |

#### 手法 2B：多角度轮换——突出特征不可死盯一个角度写

**原则**：当一个特征足够突出、让人想不注意都难，确实需要在不同场景中多次描写时，**每次必须换一个描写角度**。盯着同一个角度反复写等于告诉读者"这个作者只会这一招"。

**轮换角度清单：**

| 轮次 | 描写方式 | 示例（特征：腿长） |
|------|---------|------------------|
| 第 1 次 | 他人内心戏/口述 | 闺蜜瞟了一眼："腿玩年。" |
| 第 2 次 | 功能/动作后果 | 她一步两个台阶走得飞快，后面的人要跑着才跟上。 |
| 第 3 次 | 环境互动 | 沙发对她来说太矮了，膝盖几乎弯到了胸口。 |
| 第 4 次 | 对比/参照物 | 站在一排女生中间，她的腰线比别人高出整整一个头的位置。 |
| 第 5 次 | 穿搭/衣物 | 那条普通牛仔裤穿在她身上，裤脚只到脚踝上方——不是七分裤。 |
| 第 N 次 | …继续轮换上述五个维度 | 不重复此前已用过的角度 |

**适用特征**：
- 本规则不仅适用于生理特征，同样适用于：**性格特质**（如暴脾气——一次写摔东西、一次写脸涨红、一次写旁人躲开）、**能力特征**（如力大无穷——一次写举重物、一次写捏碎杯子、一次写别人推不动她）、**声音特征**（如嗓音沙哑——一次写电话里被误认成男人、一次写唱歌时的颗粒感、一次写小声说话反而更清晰）

**核心约束**：
- 同特征同角度在同一章节中最多出现一次
- 同特征同角度在不同章节中最多出现两次（第二次必须与其他角度组合，不能纯重复）
- 出现第三次同角度描写 → 违规，必须重写

**适用范围**：外在造型描写、人物行动描写、性格特质表现、能力特征展示。内心活动不在此限。

### 规范 2.2：人物性格描写的间接化

**原则**：性格描写与外貌描写遵循同一套间接化逻辑。直接给角色贴性格标签（"他是一个莽撞冒失的人"）是 AI 的写法——现实中没有人能一眼看透另一个人的全部性格，这种话只会出现在他人的评价中，不会出现在叙述者的口中。

#### 为什么需要这条规范

叙述者直接告诉读者"这个人很善良""这个人脾气暴躁"是在剥夺读者的判断权。读者应该在角色的行为、对话、选择中**自己得出结论**。一个写了三章都没发过火的人，叙述者说他"脾气暴躁"，读者不会信。一个一开头就救了路边小猫的人，不需要叙述者说他"善良"，读者自己会看到。

**核心链路：**
```
禁止：叙述者贴标签 → "他是一个莽撞、冒失的人。"
允许：他人评价中出现 → "我妈总说我莽撞——她没说错。"
要求：用行为和情节让读者自己得出这个结论
```

#### 两个主要描写方向

**方向 A：与故事结合——性格随情节展开**

性格不是一张表格，是一个过程。不同性格侧面在不同类型的事件中被激活，读者通过角色**做了什么**来认识他。

| 写法 | 例（性格：莽撞冒失） |
|------|---------------------|
| ✕ 直接贴标签 | "张三是个莽撞冒失的人。" |
| ✓ 初登场用一个小事件激活 | 张三撞开门冲进来，才发现走错了教室——满屋子的人转头看他，他挠挠头又撞上了门框。 |
| ✓ 后续用更大的事件深化 | 别人都趴下了，就他还站着往前冲。李四拽住他："你不要命了？"他说："刚才没想那么多。" |
| ✓ 用后果反写 | 医生看着片子叹气："上个月叫你静养，你倒好，又去爬山。这条腿再断一次就接不上了。" |

**方向 B：与外貌结合——外貌暗示性格**

伤疤、纹身、体态、眼神、穿衣风格——这些都是性格的视觉锚点。不直接说"他很凶"，而是让外貌自己开口。

| 外貌特征 | 暗示的性格方向 |
|---------|--------------|
| 满脸横肉 + 寸头 + 脖子上的旧刀疤 | 不好惹、有暴力过往、经历过事 |
| 满臂纹身但戴着银边眼镜 | 外表粗犷/反叛 + 内在细腻/斯文（冲突复合型） |
| 永远把衬衫扣到最上面那颗 | 严谨、保守、可能有不想让人看到的伤 |
| 走路时右脚微跛但不减速 | 有旧伤但不服输、倔强 |
| 手指甲永远有洗不掉的机油渍 | 动手能力强、蓝领背景、不讲究外表 |
| 笑容永远停在嘴角不到眼睛 | 表面友好实则疏离、有故事/有心结 |

**操作规则**：外貌写完立即接一个行为/情节，让外貌暗示的性格落地——否则外貌只是摆设。

> 例（纹身+镜框——冲突型）：
> 他推了推银边眼镜，一只满臂纹身的手翻开了面前的文件。坐在对面的客户明显不知道该看他的纹身还是眼镜，目光来回跳了三趟。
>
> ↑ 外貌暗示了"粗犷+斯文"的冲突性格，但读者是通过客户的反应（不是叙述者的标签）感受到的。

#### 性格描写的四项技法

**技法 1：借行为写性格（替代贴标签）**

叙述者不评价，只写角色做了什么。读者自己判断。

| 标签（禁止） | 行为（正确） |
|------------|------------|
| "他很善良" | 雨里遇到一只纸箱里的猫，他脱了自己的外套盖上去。 |
| "她很小气" | 吃完饭她拿着账单算了三遍，最后说了句"你那份多了两块钱。" |
| "他胆子大" | 别人都在往后退，就他往前走了一步——这一步很小，但没人在意大小。 |

**技法 2：借他人之口写性格**

性格标签是允许出现的——但只能出现在**他人的评价**中。不同人对同一角色的评价可以互相矛盾，这正是塑造立体性格的好机会。

> 正例（他人评价——立场不同、说法不同）：
> 李四对王五说："张三那个人就是一根筋，你别跟他计较。"
>
> 但赵六私下跟钱七说："张三不是一根筋，他是看准了就不放手——你以为他能忍三年是蠢？他比谁都精。"
>
> ↑ 两个评价互相矛盾，读者开始好奇张三到底是什么人。这才是有效的性格写作。

**技法 3：性格的延迟揭示——浅层在前，深层在后**

初登场时读者只能看到性格的**表层**（行为方式、说话语气），深层性格（动机、价值观、软肋）随着情节推进逐步揭露。三个层次：

| 层次 | 揭示内容 | 揭示时机 |
|------|---------|---------|
| 表层（初登场） | 行为习惯、说话方式、情绪反应 | 角色第一次出现的场景 |
| 中层（发展期） | 价值判断、做人底线、对重要事件的态度 | 面临选择/冲突的场景 |
| 深层（高潮/关键章） | 动机根源、最大软肋、性格成因 | 重大危机/坦白/闪回 |

> 例（三层递进——性格：表面冷漠实则心软）：
> 
> 表层（初登场）：他路过那只受伤的狗时脚步没停，连看都没看一眼。
>
> 中层（第5章）：师妹发现他在后院给那只狗上药，手法很轻。见师妹来，他起身走了，丢下一句："别跟别人说。"
>
> 深层（第15章，闪回）：六岁那年他养过一条狗，被父亲在他面前吊死了——因为"男孩子不能有软肋"。此后他没再摸过任何一只动物。

**技法 4：性格的多角度轮换——同一特质不同情境轮换**

与规范 2B 同理，同一性格特质在不同章节中出现时，必须轮换情境/表现方式。

| 轮次 | 描写方式 | 示例（性格：倔强） |
|------|---------|------------------|
| 第 1 次 | 行为冲突 | 妈妈叫他往东他偏往西，最后摔门出去了。 |
| 第 2 次 | 身体/生理反应 | 他咬着牙不哭，嘴唇都咬出血了——但眼泪就是不掉下来。 |
| 第 3 次 | 他人评价 | "这孩子，跟我年轻时候一模一样。"父亲指着他对母亲说。 |
| 第 4 次 | 后果展现 | 他在雨里站了四个小时等她回来——第二天发了高烧，但她看到了。 |
| 第 5 次 | 情境反转 | 这次他让步了。所有人都愣住了——这个倔了二十年的人，居然让了。 |

**硬约束**：
- 禁止在初登场时用任何形式的性格标签（包括"他看起来是个很XX的人"——叙述者没有权利"看起来"）
- 前 3 章内，同一性格特质必须至少用一次**行为**来展现，纯靠他人评价不算数
- 同性格特质同情境下同表现方式，跨章最多出现两次

#### 与规范 2 的衔接

规范 2.2 是规范 2（人物描写间接化）在性格维度的专项扩展：
- 规范 2 管**外貌怎么写** → 借物喻人、借镜喻人、延迟揭示、多角度轮换
- 规范 2.2 管**性格怎么写** → 借行为写性格、借他人之口、三层递进、多角度轮换
- 两者共享同一核心逻辑：**禁止叙述者贴标签，让读者自己看**

### 规范 3：风景穿插

**原则**：在对话之间与长段叙事之间适当插入风景/环境描写，打破文本单调感。

**具体规则**：

- 对话来回超过三轮时，中间插入一句环境/风景描写
- 长段白描叙事（超过 200 字）中途加入环境细节
- 风景描写不求多，一句即可——作用是"换气"
- 风景应与当下场景/情绪呼应，不为写景而写景

**示例**：
> "你确定要这么做？"
>
> "没有别的办法了。"
>
> 窗外梧桐叶落了一片，贴着玻璃滑下去。
>
> "那就走吧。"

### 规范 4：对话增强

**原则**：对话常态搭配神情、动作或内心活动以增强表现力，但白描（纯对白不加修饰）在特定场景中是有效技法，不应一律禁用。

**具体规则**：

- 对话时优先搭配以下之一：神情描写 / 身体动作 / 内心闪念
- 神情与动作应服务于对话情绪，不做冗余堆砌
- 内心想法可用括号注记或短句并入叙事流
- **白描适用场景**：以下情况可仅用纯对白，不加神情/动作修饰：
  - 沉闷压抑的氛围（对话双方情绪低沉，留白反而加重压迫感）
  - 简短快速的应答（嗯。/ 好。/ 知道了。——单字成段有力量）
  - 冷对峙/冷战（刻意不说话外之音，靠台词本身传递疏离感）
  - 信息交代（功能性对话，不做冗余表演）
- 白描对话同样遵守规范1的超短句规则

**反例**（该加但没加——重要情绪对话缺乏表现力）：
> "你为什么不说一声就走了。"
> "我说了你也不会懂。"
> "你不说我怎么懂。"

**正例**（对话增强）：
> 她停了一下，手指无意识地卷着发尾。"我知道了。"
>
> ——至少现在知道了。

**正例**（白描——沉闷场景，纯对白反而更有力）：
> "什么时候走。"
>
> "明天。"
>
> "不回来了？"
>
> "嗯。"

### 规范 5：降重率规范

**核心原则：大纲/设定文件提供的是合法性验证，不是写作素材。正文必须对原始设定进行二次加工后输出——直接引用、近义复述、跨章重复使用同一描述角度，均属违规。**

#### 为什么需要这条规范

大纲文件（人物存档、剧情大纲、设定文件）存在的意义是让 LLM 知道"这个角色有什么特征、这个世界有什么规则"——即验证一段描写的合法性。如果正文直接照搬大纲中的描述语句、数据、比喻，甚至在不同章节反复使用同一套措辞，那么这套技能系统就失去了存在价值——用户自己复制粘贴即可，不需要 AI 创作。

**大纲 → 正文的正确链路：**
```
大纲中的原始数据
    │
    ▼
合法性验证（"这个角色确实有 B 罩杯"）── ✓ 允许
    │
    ▼
禁止 ── 直接引用原句（"底盘紧致、乳峰高翘挺立"）
禁止 ── 近义改写原句（"底盘紧致，乳峰挺翘，即便放松也保持上翘"）
禁止 ── 跨章反复使用同一组描述词
    │
    ▼
要求 ── 换角度、换感官、换语境、换精度，二次创作后输出
```

#### 四条禁令

**禁令 1：禁止完全引用（照搬原文）**

不得将大纲文件中的描述语句原封不动或仅调换语序后用于正文。

> 反例（大纲原句 → 正文照搬）：
> 大纲：`乳房并不丰硕，B 罩杯——胜在形态近乎完美：底盘紧致、乳峰高翘挺立`
> 正文：`乳房的轮廓在烛光中半明半暗——B 罩杯，底盘紧致，乳峰挺翘，即便在完全放松的状态下也保持着向上翘的形态`
>
> ↑ 违规：底盘紧致、乳峰挺翘、B 罩杯——三个数据点完全复刻，仅加了一句"烛光中半明半暗"做包装。

> 正例（二次加工——换感官+换语境）：
> 大纲：`乳房并不丰硕，B 罩杯——胜在形态近乎完美：底盘紧致、乳峰高翘挺立`
> 正文：`他解开她衣襟时，掌侧擦过一处——不大，刚好盈满手心。那团柔软在他指间微微上挑，像一瓣被晨露压弯后又弹起的花。`

↑ 合规：保留了"不大/不丰硕"的核心事实（合法性验证通过），但完全换了描写角度（触感而非视觉）、换了语境（互动场景而非静态描述）、换了比喻（花瓣而非几何形态）。

**禁令 2：禁止近义复述（换皮不换骨）**

不得将大纲中的描述换几个同义词后当作新内容输出。判断标准：如果原文和大纲在同一个特征维度上使用了**相同的数据、相同的比喻方向、相同的描写器官/部位**，即视为近义复述。

> 反例：
> 大纲：`阴茎粗长，约18cm，龟头饱满呈紫红色`
> 正文：`他的那根东西又粗又长，目测接近二十公分，前端那个蘑菇头鼓鼓的，颜色偏深`
>
> ↑ 违规：粗长→又粗又长，18cm→接近二十公分，龟头→蘑菇头，紫红→颜色偏深。每一个数据点都找到了同义词，但没有新增任何角度。

> 正例（换角度——从视觉换为触觉/感受）：
> 正文：`她两只手才勉强握住。顶端蹭过她小腹时，她才发现那处的皮肤比想象中烫——像一块被太阳晒了一下午的石头。`

↑ 合规：保留了"粗/大"的事实，但换成了触感（两手握住）、温度（烫）、视角（她的感受），没有重复大纲中任何一个具体数据或比喻。

**禁令 3：禁止跨章重复（同一角度反复使用）**

同一人物/事物的同一特征，在不同章节中**不得**从同一角度使用同一组词汇重复描写。每次出现该特征时，必须换一个描述维度。

| 章节 | 描述同一特征"她身材娇小" | 判定 |
|------|------------------------|------|
| 第1章 | "她个子小小的，站在人群中只到别人肩膀" | ✓ 视觉/对比 |
| 第3章 | "她踮起脚尖还是够不到最上面那格" | ✓ 动作/功能后果 |
| 第5章 | "她的身形娇小，在人群中格外显眼" | ✕ 回到了第1章的同一角度 |
| 第8章 | "别人三步的距离她要走四步" | ✓ 行为节奏 |
| 第10章 | "她个子不高，但每次抬头看人时眼神从不落下风" | ✓ 视觉+性格（新组合） |

**禁令 4：禁止感官单一（始终用一种感官描写同一特征）**

同一特征的多次描写必须轮换感官通道，不能每次都用同一感官（如始终是视觉描述）。

| 感官通道 | 可用描写角度 |
|---------|------------|
| 视觉 | 形状、颜色、光影、对比 |
| 触觉 | 温度、质地、压力、重量 |
| 听觉 | 声音、节奏、呼吸、布料摩擦 |
| 动作/后果 | 该特征导致的行为后果（够不到、塞不进、被挡住） |
| 他人反应 | 他人的目光、动作、回避或靠近 |

#### 合法二次加工手法

将大纲数据转化为正文描写时，以下手法视为合规加工：

| 手法 | 操作 | 示例（大纲"身高180cm"） |
|------|------|------------------------|
| 换感官 | 从视觉换为触觉/听觉/动作 | "他进门时低头躲了下门框" |
| 换语境 | 嵌入互动场景而非静态陈述 | "她仰头看他，脖子酸了" |
| 换精度 | 用模糊感受替代精确数据 | "他比周围所有人都高出大半个头" |
| 换视角 | 从他人眼中看，而非客观叙述 | "站他旁边说话，总觉得自己像被一面墙罩着" |
| 换时间 | 不同时间/光线/状态下的不同呈现 | "晨光从他背后打过来时，影子把她整个人吞了进去" |
| 换隐喻 | 不同的比喻体系 | 一次用建筑比喻（"像面墙"），一次用自然比喻（"像棵树"） |

#### 该条规范的检验标准

写完一段涉及人物特征的正文后，逐条自检：

1. 这段描写中，有没有大纲文件中出现过的**原词或原数据**？
2. 这个特征在之前的章节中是否**已经用同样的感官通道**写过？如果写过，这次换了吗？
3. 这段描写去掉之后，大纲文件中的那条数据能否被**独立还原**出来？（如果能还原，说明正文太接近大纲原文）

如果问题 1 或 3 答"是"，必须重写。如果问题 2 答"是"，必须换感官/换语境。

#### 补充规则（保留原防过度润色规则）

以下规则承自原"防过度润色"规范，在降重率框架下仍然有效：

- **克制情感用词**：避免堆砌"心痛如绞"、"泪如雨下"等高度饱和的情感表达。情感靠情节与动作传递，不靠形容词堆叠
- **相近角度扩写**：从相邻语义维度展开扩写，而非原地叠加同义词。如已写"小巧玲珑" → 可从"因此走路轻快""在人群中容易被忽略""总被误认为比实际年龄小"等后果与表现角度扩写

## 专项调度机制

当检测到以下内容类型时，不自行处理，转而调度对应专项技能：

| 内容特征 | 调度技能 | 判断依据 |
|---------|---------|---------|
| NSFW / 成人内容 | NSFW 写作技能 | 按步骤 2.1 三级扫描命中（显性词汇/性场景/语境渗透） |
| 言情专项 | 言情写作技能 | 文本以恋爱关系为核心推动力 |
| 其他专项 | 按需查找 | 根据内容特征搜索已安装技能 |

### NSFW 调度协议（Core ↔ NSFW）

**Core → NSFW 传递数据包：**

```
{
  "text": "{待处理的 NSFW 段落文本}",
  "context": {
    "chapter": "{当前章号/章名}",
    "scene_type": "{场景类型：床戏/自慰/前戏/幻想/对话挑逗}",
    "detection_level": "{一级/二级/三级}",
    "involved_characters": ["{角色名}"],
    "surrounding_text": "{前后各一段非NSFW文本，供语境参考}"
  },
  "polish_mode": "{正文.polish_mode 值}",
  "content_rating": "{项目信息.json 中的 content_rating}"
}
```

**NSFW → Core 返回数据包：**

```
{
  "processed_text": "{处理后的 NSFW 段落文本}",
  "nsfw_tier_used": "{NSFW档位：大众级/限制级/开放级}",
  "sexy_value": "{使用的色色值挡位：N1-N5}",
  "exempted_norms": ["规范2", "规范2.2"],
  "key_changes": "{关键替换/调整说明}",
  "ooc_warnings": "{OOC 边界标注，如有}"
}
```

**Core 收到返回后的整合步骤：**
1. 将 `processed_text` 按原位置拼回全文中
2. 根据 `exempted_norms` 跳过对应规范的二次检查（如 NSFW 已豁免规范 2 和 2.2）
3. 对其余规范（1/3/4/5）做最终全篇一致性过检
4. 如 `ooc_warnings` 非空，向用户展示标注并确认

**调度方式**：识别到专项内容后，向用户说明并调用对应技能处理，处理结果返回后纳入本技能的最终输出。

## 注意事项

- 优化时保留用户的叙事意图和关键信息，不擅自增删核心情节
- 全部适用规范逐条过检，不可跳过——尤其是规范 5（降重率）在重度模式下最容易被忽略：LLM 倾向于直接复述大纲原文，必须逐段自检
- 如文本本身已是优化后的结果，检查是否仍有可改进项，无则原样返回并说明"已合规"
- 大纲类文件识别依据：文件路径包含 `大纲/`、`outline/`、`剧情/`、`plot/`，或文件名含"大纲"、"剧情"、"章"等关键词
- 此技能处理后的文本方可写入目标文件——**不经处理直接写入视为流程违规**
