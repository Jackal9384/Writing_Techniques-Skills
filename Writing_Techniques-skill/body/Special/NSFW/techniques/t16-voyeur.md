# 技法 t16：偷窥视角与无意识暴露

**适用**：幻想 / 通用

角色在完全不知道被观看的状态下，以最私密的姿态暴露在第三者的视野中——她的毫无防备与画面被"击穿"的观看者之间，形成性张力的第二层。读者同时代入暴露者与观看者。

**写作要点**：

- 暴露方的状态必须是"完全不知道"：她趴在桌上大口喘息平复呼吸，不知道自己正对着窗外的他——任何一丝"她可能感觉到了"都会破坏这个视角的冲击力
- 暴露的姿势要有"构图感"：上半身压在石面上 → 乳房紧贴冰凉的大理石 → 双腿分开站地上 → 臀部高高翘起 → 小穴门户大开正对窗外——这个姿势是一帧一帧搭出来的画面
- 观看者的反应是色情感的放大器：不是写"他硬了"，而是写他**被画面击穿**——拳头攥在石沿上指节发白、转身就跑、蹲在树下大口喘气、脑子里那幅画面反复回放——他的失控证明了画面的杀伤力
- 月光/灯光作为"照明"：月光毫不吝啬地照在她湿润的、微微张开的、还在轻轻收缩的小穴上——光源让画面可见，也让观看者的"偷窥"变得有凭有据
- 偷窥后的心理后坐力：蹲在树下很久很久没站起来、心跳如鼓、喉咙发干、某种从未有过的混杂着震惊、怜惜与强烈占有的情绪——这不是单纯的性冲动，而是一种被画面永久改变的心理冲击
