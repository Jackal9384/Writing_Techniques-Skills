# 技法 t12：道具掌控

**适用**：自慰 / 床戏

用性玩具（振动棒、跳蛋、按摩棒等）作为支配工具，剥夺角色对自己身体快感的自主权——玩具的开关、节奏、深浅全由支配者控制，被支配者连"什么时候到"都无法自己决定。

**核心机制**：从"自己玩"到"被他用她的东西玩"——道具来源的翻转是心理冲击的关键。

**写作要点**：

- 道具的出场要有"来源翻转"：不是他掏出一个振动棒，而是他掏出了**她藏在石板下面的那根**——她以为那是只属于自己的秘密，此刻却成了他手中的工具
- 道具操控的三个控制维度：
  - **节奏控制**：快慢由他——时而缓慢抽插摩擦入口褶皱，时而猛地顶到最深
  - **强度控制**：振动档位由他——低频嗡鸣时她还能忍，高频振动一开直接溃堤
  - **终点控制**：什么时候拔出来由他——她不需要自己决定，只需要服从
- 道具与手指/阴茎的区别：道具的**非人感**（硅胶的冰凉、机械的持续振动、不会累）本身就是一种刺激——它不是人，它不会心软，它会一直震
- 事后道具的状态描写：拔出来后棒身上裹满她的淫水，在光线下闪着水光，他随手塞回口袋——道具的回收与她的狼藉形成反差
- 道具掌控中的命令-服从闭环：递袍子这个动作——他在"用完她"之后把袍子递给她，不是帮她穿，是让她自己穿——支配的边界很清晰
