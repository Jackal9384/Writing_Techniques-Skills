# 技法 t03：延迟满足与等待煎熬

**适用**：前戏 / 自慰 / 床戏

在性行为发生之前插入**长时间的等待/煎熬**，让角色的身体在期待中自我折磨——越等越湿、越等越硬、越等越空虚。

**写作要点**：

- 给等待一个明确的时间锚点（"十一点整"→"整整半小时"）
- 等待期间反复切换三个视角的描写，循环递进：
  - **外部威胁**：头顶的人影、声音、时间的流逝
  - **身体反应**：乳尖越来越硬、小穴收缩越来越频繁、春水越流越多
  - **心理回放**：脑中反复回放对方刚才的淫秽话语（"用你的骚穴。或者屁眼。"），每回放一次下身就紧一下
- 等待结束时的身体状态要"蓄满"：湿透、胀痛、空虚收缩——为即将到来的插入做足铺垫
- 等待不是静止的——身体的变化曲线要明确（从"微微湿润"到"双腿内侧一片滑腻"到"脚边积起小滩"）
