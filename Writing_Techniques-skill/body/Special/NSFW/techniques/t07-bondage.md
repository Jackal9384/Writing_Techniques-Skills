# 技法 t07：束缚与行动限制

**适用**：床戏 / 通用

用物理束缚（绳子、皮带、手铐、铁环）限制角色的行动能力，使其无法挣扎、躲避或并拢双腿——身体被迫敞开，快感无处可逃。

**写作要点**：

- 束缚的具体化：不要只写"被绑住了"，要写出绑在什么东西上（木柱、床架）、用什么绑的（旧皮带、粗麻绳）、绑的姿势（手腕绕柱两圈、脚踝连在铁环上、双腿被迫M形分开）
- 束缚物件的质感：老旧却结实的木头、表面布满擦痕和铁锈斑、皮带扣得死紧——这些细节让束缚有重量感和不可挣脱感
- 行动限制的后果：她无法夹紧双腿来缓解快感、无法推开他、无法躲避——只能承受，每一次刺激都必须完整吞下
- 束缚后的身体反应是**被迫敞开**的直接结果：淫水顺着大腿内侧往下滴，她连并拢腿都做不到
- 束缚不是虐待描写，是限制→暴露→被迫承受的递进逻辑
