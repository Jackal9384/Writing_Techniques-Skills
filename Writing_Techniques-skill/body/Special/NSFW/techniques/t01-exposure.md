# 技法 t01：强制暴露与羞耻张力

**适用**：前戏 / 床戏 / 通用（`techniques/index.json` → `scenes` 映射）

让角色在非私密空间（户外、半公开场所、可能被发现的室内）被迫暴露身体，以"随时可能被发现"的恐惧与羞耻感作为性张力的放大器。

**核心机制**：羞耻感 → 身体应激反应（心跳加速、体温上升、皮肤泛红）→ 欲望放大 → 身体变得更敏感

**写作要点**：

- 先建立空间威胁：头顶是某人的窗户、巷口可能有人路过、隔壁有人随时会进来
- 暴露的时间维度：不是一瞬间脱光，而是**持续暴露**——角色裸身站在威胁下度过漫长的时间（如"整整半小时"）
- 外部威胁的锚定：用具体的声音（咳嗽声、翻纸声、脚步声）反复提醒读者"威胁就在头顶"
- 身体反应跟随威胁波动：窗外人影晃动一次 → 角色的心猛跳 → 私处不受控制收缩
- 羞耻感**只点到一次**——"羞耻感如潮水般涌来"一句带过，立刻转入身体反应描写，不犯"注水肉"

**正例**：

> 她赤身裸体地站在巷子中央。头顶二楼的窗户亮起了灯光，人影晃动。她一动不敢动——万一塔季扬娜低头看一眼窗外……小穴不受控制地收缩，春水顺着大腿内侧一路往下淌。

**反例**（注水肉式羞耻堆砌）：

> 她感到无地自容，羞耻得想找个地缝钻进去。这种被看光的恐惧让她浑身发抖，但同时又让她兴奋不已。她一边唾弃自己的下流反应，一边又沉溺在这种背德的刺激中……
