# 技法 t11：事后温柔反差

**适用**：事后 / 通用

粗暴的性行为结束后，插入一个**反差式温柔动作**——这个动作越笨拙、越不熟练、越不像这个人平时的样子，反差的情感力量越强。

**写作要点**：

- 温柔动作的选择：解皮带时动作难得地轻柔、拨开被汗浸湿的头发、一颗颗系回袍子的扣子——这些不是性行为，是**照顾行为**，却比性行为更能击中读者
- 笨拙感是反差的关键：铁匠的手指粗大笨拙，却在一颗颗系修女袍的小扣子——"动作笨拙却认真"七个字的情感分量远超一段温柔对白
- 反差的核心是"不像他"：前文中的粗暴命令、掐乳、强行分开双腿 → 此时的系扣子、拨头发 → 读者读到的不是温柔，而是"他只对她这样"
- 事后温柔≠角色性格转变——他仍然是那个冷酷的人，只是在这一刻、对她、做了这一件事。不要写"他其实是个温柔的人"，写"他的动作笨拙却认真"
