# 技法 t02：脱衣仪式化

**适用**：前戏 / 床戏

将脱衣过程拆解为**层级递进的仪式**，每脱一件衣服释放一个身体部位，让读者逐层"解锁"角色的裸体。

**写作要点**：

- 逐件命名：牛角扣一颗一颗解开 → 粗麻布袍子滑落 → 贴身束衣 → 内裤（顺序不可跳）
- 每层描写对应身体变化：袍子脱下后暴露肩颈线条 → 束衣解开后乳房弹跳出来 → 内裤脱下时已有湿润痕迹
- 衣物处理的动作赋予意义：不是随手扔在地上，而是**叠好、递交给对方**——这个动作既是服从的仪式，也是"交出最后防线"的象征
- 全部脱完后给一个**全裸定格**：用一段完整的身体扫描（肤色/腿/腰腹/乳尖/私处）让读者"看清"此刻的画面
