# 技法 t09：着装反差

**适用**：床戏 / 通用

让角色在性行为中**部分穿着衣物**——尤其是制服/圣职装/正装等带有身份象征的衣物——制造"半圣洁半淫靡"的视觉与心理反差。

**写作要点**：

- 衣物保留的程度要明确：修女袍从领口一直扣到下摆，一颗扣子都没解开——只是下摆被撩起堆叠在膝盖两侧
- 衣物的身份象征是关键：修女袍 = 圣洁、禁欲、不可侵犯 → 袍子完整穿着但下身裸露被侵犯 = 反差拉满
- 布料摩擦身体的触感是额外刺激：修女袍的粗麻布摩擦着挺立的乳尖——衣物本身成了性刺激的来源
- 事后衣物回归也是一种仪式：他把扣子一颗颗系回去，袍子重新包裹住狼藉的身体——衣物的"穿回"与"脱下"是反向的张力循环
- 适用身份符号对照：
  - 修女袍/祭司袍 → 宗教禁欲感
  - 女仆装/执事服 → 侍奉与服从
  - 军装/警服 → 权力被反转
  - 校服 → 纯真被侵蚀
