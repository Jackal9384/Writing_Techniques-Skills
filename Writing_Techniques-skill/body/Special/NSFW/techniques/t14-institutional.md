# 技法 t14：制度化支配

**适用**：通用

将性支配关系**嵌入制度/职业/日常框架**中——不再是偶然的暗巷相遇，而是通过排班表、巡逻申请、任务分派等正式渠道安排的"合法碰面"。制度的外壳让支配关系获得了持续性和不可抗拒性。

**写作要点**：

- 制度化的具象动作：填一张合作巡逻申请表、"与当值修女协同巡逻，增补后巷巡视范围"——用公文语言包装性目的
- 制度信息的预谋感：他早就查过排班表，知道今天当值的是她——申请表只是走个形式，支配早已有计划
- 制度赋予的"正式感"与"私下行为"的反差：穿着护卫军灰蓝制服正式地走在她身旁 → 走到巷子深处 → 命令她把衣服全脱了——制度是外壳，支配是内核
- 制度化带来的时间持续性：不再是偶发事件，而是"明天这个时候，还在这里"——支配关系被固定为日程
- 制度化支配的三个递进阶段：
  1. 偶然相遇（暗巷撞见）——不可控、随机
  2. 制造相遇（巡逻申请）——可控、有计划
  3. 固定日程（每天这个时候）——制度化、不可抗拒
