# 技法 t15：多轮连续高潮的递进层次

**适用**：床戏 / 自慰

写多次连续高潮时，每一次必须有**不同的质地**——不是"她又高潮了"重复三遍，而是三次不同形状、不同速度、不同深度的浪潮。

**三次高潮的经典递进模板**：

- **第一次 — 猛烈炸裂型**：来得快、撞得猛、反应大——身体猛地弓起、小穴连续痉挛、大股暖流涌出、叫出声来。这次是"被刺激推上去的"
- **第二次 — 安静深沉型**：来得慢、渗透深、反应小——不像第一次那样剧烈挣扎，而是安静的颤抖和低低的呜咽。暖流从核心处缓缓溢出，"像一道温泉慢慢淹过整个下腹"。这次是"从内部自己浮上来的"
- **第三次 — 绵长溃堤型**：在最疲倦的时候涌上来，没有力气剧烈反应，反而最绵长——不是炸裂而是从深处缓缓压出的大浪。快感"绵延不绝，像永无止境的潮汐"。这次是"身体被榨到极限时的最后一波"

**递进的写作要点**：

- 每次高潮之间给喘息但不给平静：道具档位调低但不关掉、换一边乳尖继续震——"休息本身就是一个新的起点"
- 每次高潮后的身体状态描写递进：第一次后跪着喘息 → 第二次后身体轻轻颤抖 → 第三次后眼前发黑、意识空白
- 第三次之后的身体极限感：腿打颤、膝盖发软、站起来站不稳、说话断片、"脑子里除了色色什么都想不到了"——用身体崩溃的程度反推高潮的强度
