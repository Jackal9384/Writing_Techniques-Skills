# NSFW专项写作

此技能是 Write-Router 调度体系下的 NSFW 专项扩展，提供三档分级写作模式，覆盖从隐晦隐喻到直白刺激的成人内容写作全尺度。

## 核心定位

- **三调度源**：
  - **Write-Router**：检测到正文 NSFW 内容后自动调度，处理 NSFW 段落
  - **创建阶段技能**：创建人物填写 NSFW 字段（XP/三维/性特征/人物X能力）时调度，做词汇选择和档位匹配
  - **用户直接触发**：/nsfw-config、独立 NSFW 写作、色色值调整
- **三档模式**：大众级 / 限制级 / 解限级，逐级放开尺度。限制级和解限级均内置三列语气分档（保守/中性/放荡）
- **叠加核心规范**：在基础写作辅助的核心规范之上叠加 NSFW 专项规则，不替代、不冲突
- **人物感知**：限制级模式下必须读取角色文件，依据角色性格选择用词尺度，绝不 OOC

## 触发条件

### 由 Write-Router 调度（正文 NSFW 段落）

Write-Router 在步骤 2（内容检测）检测到 NSFW 内容时，自动调度此技能处理，处理结果返回后纳入最终输出。

### 由创建阶段技能调度（NSFW 字段词汇选择）

创建人物技能在用户填写 NSFW 字段（XP/三维/性特征/人物X能力）时，调度此技能做词汇选择：

- 根据 `项目信息.json` 中的 `nsfw_output_level` 和 `nsfw_character_tone` 匹配用词级别
- 如项目未配置 NSFW 偏好 → 按 2.5.1 流程询问用户并写入配置
- NSFW 字段词汇选择完成后返回创建人物技能，不直接写入文件

#### 2.5.1 首次配置流程（NSFW 偏好未配置时）

当项目 `项目信息.json` 不存在或不含 NSFW 配置字段（`nsfw_output_level`/`nsfw_character_tone`/`nsfw_tier_range`）时，按 `data/nsfw-config.json` 中的模板执行配置询问与写入（模板外置存储，防止本技能文档臃肿——**按需读取，不常驻本文件**）。

**流程概要**（模板原文见 `data/nsfw-config.json`）：

1. **首次配置**（`first_time_setup_prompt`）——两项询问：① 全书色色值域（N1-N5 区间，可指定章节区域）；② 输出词级别（限制级/解限级）。可部分回答或全部跳过
2. **条件追问**（`conditional_followup`）——② 选择限制级/解限级时追问角色语气（保守/中性/放荡），大众级不追问
3. **写入规则**——跳过则不写数据；提供数据则按 `templates/project-info.schema.json` 组装（仅触碰 `nsfw_output_level`/`nsfw_character_tone`/`nsfw_tier_range`/`last_updated` 四字段）→ 调度成品输出校验落盘；文件已存在绝不覆盖已有字段
4. **章节色色值确认**（`sexy_value_prompt`）——每章涉及 NSFW 内容时先确认挡位；`chapters` 覆盖 > `global` > LLM 自行判断
5. **重配置提示**（`reconfigure_prompt`）——连续两次以上不满时提示；已有配置仍不满则询问修改
6. **档位选择**（`tier_selection_prompt`）——一般向默认大众级；NSFW 询问限制级/解限级；按角色性格推断建议

> 字段定义见 `templates/project-info.schema.json`（V1.0 起 NSFW 字段 schema 唯一来源）。

## 三档模式定义

### 大众级 —— 隐晦隐喻

**适用场景**：

- 一般向作品中的轻度 NSFW 暗示
- 需要公开发布、通过公众平台内容审查的场景
- 项目 `项目信息.json` 中 `content_rating` 为 `一般向`

**核心原则**：极其隐晦，只可意会不可言传。用日常物品/概念隐喻 NSFW 内容，表面读起来完全无害。

**词汇替换示例**：

**词汇表**：读取 `data/nsfw-vocabulary.json` → `terms[]` 中 `levels.大众级.words`（数据外置，防止文档臃肿——完整词表见数据文件，结构校验见 `templates/nsfw-vocabulary.schema.json`）。

示例：`跳蛋 / 震动棒` → 跳舞的鸡蛋、电子男友、嗡嗡、小马达；`做爱` → 亲密、在一起、云雨、温存

**写作要求**：

- 整段读起来像正常叙事，只有"懂的人懂"
- 不直接出现任何性器官/性行为词汇
- 用动作的省略和留白代替直接描写
- 用环境/物品的异常状态暗示发生了什么
  - 示例：不写"她用跳蛋自慰"，写"她把那个会跳舞的鸡蛋塞进枕头底下，蒙上被子，过了很久才安静下来"

### 限制级 —— 优雅代称

**适用场景**：

- 明确为 NSFW 向作品，但追求文学质感
- 需要根据人物性格调整用词尺度
- 项目 `项目信息.json` 中 `content_rating` 为 `NSFW`

**核心原则**：用优雅的代称替代医学术语/粗俗词汇。**必须感知人物性格**——保守角色用更文雅的说法，放荡角色可稍直接，但总体保持文学性。

**词汇代称表**：读取 `data/nsfw-vocabulary.json` → `terms[]` 中 `levels.限制级.columns`（三列：保守/中性/放荡，数据外置）。

示例：`阴茎` → 保守「玉茎、昂藏」/ 中性「肉棒、阳物」/ 放荡「那根东西、大肉棒」

**OOC 判断规则（关键）**：

限制级最大的约束是绝不 OOC（Out of Character）。在选词前必须：

1. **读取角色语气**：优先从 `写作配置.json` → `角色语气.{角色名}` 读取：
   - 若 `nsfw_tone` 存在 → 直接使用（保守/中性/放荡），跳至步骤 3
   - 若不存在 → 回退到步骤 2
2. **回退 — 全局 + 推断**（角色未设语气时）：
   - 读取 `项目信息.json` → `nsfw_character_tone`（全局默认）
   - 若无全局默认 → 从角色 MD 文件读取性格，推断开放度：
     - 保守/内向/矜持角色 → 使用「保守角色用词」列
     - 中性/普通角色 → 使用「中性用词」列
     - 放荡/外向/主动角色 → 可使用「放荡角色可用」列
3. **情节语境判断**：
   - 初夜/初次亲密 → 偏保守用词
   - 热恋期 → 可用中性用词
   - 激情/主动求欢 → 可用放荡用词
4. **不越级**：保守角色在初次亲密场景中突然说"操我"是严重 OOC

### 解限级 —— 刺激升级

**适用场景**：

- NSFW 向作品，作者希望色情感明显提升但不想沦为粗俗
- 限制级"不够刺激"时的升级选择
- 项目 `项目信息.json` 中 `content_rating` 为 `NSFW`，且用户希望

**核心原则**：色情感大幅提升，但阅读观感不会明显下降。汲取限制级中"中性用词"和"放荡角色可用"两列中更有刺激感的词汇，并上探到直白词汇（归入放荡列），覆盖从优雅到直白的全尺度。

- 比限制级更刺激：可使用的词汇范围比限制级更广，可写的内容更露骨
- 
- 是过渡档位："优雅"到"直白"全尺度覆盖

**词汇表**：读取 `data/nsfw-vocabulary.json` → `terms[]` 中 `levels.解限级.columns`（三列：保守/中性/放荡，数据外置）。

示例：`阴道` → 保守「蜜穴、秘处」/ 中性「小穴、花穴」/ 放荡「骚穴、骚逼、肉洞」

**词汇选择策略**：

- 来自限制级中性用词：唇瓣、敏感点、交合、欢好、缠绵、湿润、释放、精华、白浊 等
- 来自限制级放荡角色可用：花唇、小豆豆、小穴、那根、大肉棒、蛋蛋、奶子、奶头、屁股、干、去了、淫水
- 词汇范围覆盖限制级中性列+放荡列，并上探到直白粗俗词汇（归入放荡列）
- ****

**写作要求**：

1. 词汇可突破限制级的优雅代称约束，引入有性暗示和刺激感的词汇
2. 但仍有底线：不使用解限级放荡列之外的粗俗词汇
3. OOC 判断放宽但不废弃：仍需读取角色文件，保守角色可适当突破但幅度不宜过大——保守角色说"小穴""肉棒"可接受，但说"鸡巴""骚逼"仍属 OOC
4. 肉体感受优先原则同限制级
5. NSFW桥段篇幅同限制级：可更详细描写性行为过程，但每一轮描写之间保留换气节奏
6. 角色语气分化：
   - 保守角色：选词的刺激度控制在中低段（如"花唇""蜜穴""阳具""交合"）
   - 中性角色：选词居中（如"小穴""肉棒""干""去了"）
   - 放荡角色：可拉到解限级的上限（如"小豆豆""大肉棒""去了""淫水"）

**OOC 判断规则（放宽版）**：

解限级的 OOC 约束比限制级宽松，但仍有底线：

1. 读取角色语气（同限制级）：优先 `写作配置.json` → `角色语气.{角色名}.nsfw_tone` → 回退全局 → 回退推断
2. 确定角色用词档位：
   - 保守/矜持角色 → 解限级偏保守词汇（下限=限制级中性，上限=解限级中段）
   - 中性/普通角色 → 解限级中段词汇
   - 放荡/主动角色 → 解限级上限词汇，但不越界到解限级放荡列
3. 确定情节语境（初次/热恋/激情）
4. 铁律：不越界到解限级放荡列——保守角色在任何场景中说"鸡巴""骚逼"仍属严重 OOC

## NSFW 核心写作技法（限制级 & 解限级）

以下技法适用于**限制级**、**解限级**。大众级以隐晦为首要目标，不受此节约束。

### 核心原则：肉体感受 ＞ 精神思考

NSFW 写作的第一要务是**传递肉体感受**，而非铺陈角色的精神活动、道德反思或情感内涵。

**精神思考不能放弃，但绝对不是主角。** 它只作为肉体感受的辅助调味——点缀一两句即可，绝不占据大段篇幅，更不应在同一个场景中反复出现。

### 反"注水肉"规则

一般向作品中，角色在背德感、羞耻感下产生别样/异样感觉时，作者常通过多次提及、反复强调、大篇幅描述来渲染氛围。**这在 NSFW 写作中是致命的。**

- 同一场景中，同一种精神感受（如背德感、羞耻感、罪恶感）**最多提及一次**
- 提及方式应**简短**——一句话带过即可，不展开、不反复、不回扣
- 精神感受提及后，立刻回到肉体描写上

**反例（注水肉）**：

> 她知道自己不该这样，这违背了她从小受到的教育。可是那种背德感反而让她更加兴奋了。她一边唾弃着自己，一边又沉溺在这种禁忌的快感中。这种负罪感像毒药一样，让她一边痛苦一边快乐着……

**正例**：

> 她知道自己不该这样，但这个念头只闪了一瞬。
> 
> 下一秒，他的手探进来时，她已经什么都顾不上了。

### 写作重心分配

NSFW 场景中，各类内容的合理占比：

| 内容类型 | 限制级 | 解限级 |
|---------|--------|--------|
| 动作描写（身体动作、互动、节奏） | ≥30% | ≥30% |
| 对话（含喘息、呻吟等） | ≥15% | ≥12% |
| 肉体感受（触感、温度、呼吸、生理反应） | ≤30% | ≤30% |
| 精神思考（内心活动、道德反思） | ≤10% | ≤7% |
| 环境/风景穿插 | ≤5% | ≤5% |

**肉体感受优先描写角度**：

1. **触感**：温度（滚烫/微凉）、质地（坚硬/柔软/湿滑）、压力（轻抚/用力/撞击）
2. **生理反应**：呼吸变化、心跳、体温上升、肌肉紧绷/松弛、体液分泌
3. **声音**：喘息声、水声、布料摩擦声（不是对话，是身体发出的声音）
4. **视觉**：身体的视觉变化（泛红、颤抖、紧绷）、而非对形貌的审美评价

**精神思考使用的约束**：

- 每次出现不超过一句
- 必须紧贴肉体反应——是"因为这种触感让她想起……"而不是"她陷入了对人生的沉思……"
- 同一场景中禁止精神思考连续出现两次以上

### NSFW 白描许可（限制级 & 解限级）

基础写作辅助的规范 2（人物描写间接化）在 NSFW 场景中**不适用**。NSFW 内容恰恰需要直接、详细的白描来传递肉体感受，这是提升色气感的核心手法。

**原则**：NSFW 场景中的性描写，优先使用直接白描——写清楚谁碰了哪里、怎么碰的、感受到了什么。长篇白描在此不仅是允许的，是推荐的。

- 不绕弯子、不借物喻人、不借镜喻人——直面身体与动作
- 允许长段落连续白描性行为过程，写出节奏与递进
- 白描的重点是动作+感受，不是堆砌形容词

**示例（直接白描——自慰场景）**：

> 她坐在地上靠着床边，左手缓慢地抚摸到自己的小穴上，右手抚在胸前，不断挑逗着乳首。左手手指试探着，一根手指就带来不少快感，只可惜自己的手指有点短……随着浑身一阵剧烈的颤抖，她蜷起身子，去了。

**示例（直接白描——交合场景）**：

> 张三将自己雄壮的肉棒抵在李四的小穴上摩挲，而后噗呲一声插入。
> 
> "啊——"李四仰起脖子，手指抓紧了床单。

**NSFW桥段篇幅控制**：

- 色色值挡位越高，NSFW桥段篇幅越长
- N1 挡位：NSFW桥段 ≤ 全文 1/4，一笔带过
- N2 挡位：NSFW桥段可占全文一半，充分展开
- N3 挡位：NSFW桥段为主，叙事为辅

## 性器与行为描写要则

> 此节不涉及情节/场景技法，专注**怎样写性器和性行为本身才色**。以下要则适用于限制级、解限级三档。

### 原则〇：画面优先于过程

NSFW 描写的篇幅应该花在**让读者看见画面**上，而不是花在**解释动作的力学过程**上。

这是 NSFW 写作中最容易犯的错位：花费大量篇幅描写"骨盆如何旋转""胸腔如何传导""快感如何从脊椎末梢传递到下腹"——这些解剖学的传递链、力学的因果分析，是过程的辅助说明，不是色情的核心。

读者要看见的是：

- 身体的**姿态**——她趴在石桌上，雪白的臀部高高翘起，双腿分开
- 皮肤的**状态**——冷白色的皮肤在月光下近乎透明，汗珠顺着脊背滑落
- 体液的**轨迹**——晶莹的液体从穴口缓缓溢出，顺着大腿内侧往下淌，在石板地上积成一小滩反光
- 器官的**样子**——粉嫩精致的花瓣微微张开，淡粉色从边缘一直延伸到深处
- 身体的**微变化**——乳尖在空气中越来越硬、小穴入口还在轻微收缩

**辅助手段（服务于画面，不可喧宾夺主）**：

- 力学传导（"骨盆带动腰椎，腰椎传导到胸腔"）——只作为身体姿态变化的骨架，一笔带过即可
- 神经传递（"快感从末梢神经一路传导到中枢"）——只作为感受来源的交代，不应展开为长篇分析
- 抽象心理推演（"她感到一种混杂着羞耻与欲望的复杂情绪在胸中翻涌"）——这句只需要最后六个字

力学和神经是画面的骨架，但它们不是画面本身。读者需要看见的是"乳房在月光下的样子"，而不是"快感怎么从第四胸椎传递到第三腰椎"。

**判断标准**：写完一段 NSFW 描写后问自己——这段文字里有几成是读者能"看见"的画面，几成是读者看不见的"过程/原理/分析"？画面应占据绝大部分篇幅，力学和神经只在需要交代身体变化时露一面就退场。

### 原则一：静态画面与动态反应并重

性器官的描写分两类：**静态画面**和**动态反应**。两者各有用途，缺一不可。

**静态画面**：写器官"此刻的样子"——定格一个视觉画面，让读者看清这个身体。作用在场景的开始、身体初次暴露、高潮后的残留定格。

静态描写的关键在于**用修辞手法层层铺开，而非下结论**（结论式/画面式对照示例 3 组见 `data/nsfw-principles-data.json` → `static_dynamic_examples.static_contrast`）：

**静态画面常用的修辞手法**：

- **光线**：月光下泛着湿润的光泽、在月光下近乎透明——光源给裸露的身体一个"为什么被看见"的理由

## 处理流程

NSFW 技能收到 Write-Router 的数据包（`text` + `nsfw_tier` + `sexy_value` + `character_profiles`）后，按以下分支处理。

### 大众级处理

1. 扫描文本中的 NSFW 直称词汇
2. 逐一替换为大众级隐喻（读取 `data/nsfw-vocabulary.json` → `terms[]` 中 `levels.大众级.words` 选词）
3. 将直接的动作描写改为隐晦的暗示/省略
4. 用环境、物品、对话弦外之音代替直接性描写
5. 通读：确保替换后文本表面完全无害、叙事流畅自然

### 限制级处理

1. 从数据包的 `character_profiles` 中获取涉及角色的性格
2. 从 `写作配置.json` → `角色语气.{角色名}` 读取角色语气（优先 `nsfw_tone` → 回退全局 → 回退推断），确定角色开放度（保守⚫/中性🟡/放荡🔴）
3. 确定情节语境（初次/热恋/激情）
4. 扫描文本中的 NSFW 词汇
5. 依据角色开放度+情节语境，从 `data/nsfw-vocabulary.json` → `terms[]` 中 `levels.限制级.columns` 的对应列选择代称（三列：保守/中性/放荡）
6. 通读：确保角色语言风格统一、不 OOC
7. 标注 —— 若某处用词可能处于 OOC 边界，向 Write-Router 返回警告

### 解限级处理

1. 从 `character_profiles` 获取角色性格（保守/中性/放荡）
2. 确定情节语境
3. 扫描 NSFW 词汇
4. 在解限级词汇范围内取位——保守取偏雅端，放荡取偏烈端（无需询问语气）
5. 在 `data/nsfw-vocabulary.json` → `terms[]` 中 `levels.解限级.columns` 的三列范围内选择
6. 通读：确保色情感提升但观感不粗俗
7. 越界标注
