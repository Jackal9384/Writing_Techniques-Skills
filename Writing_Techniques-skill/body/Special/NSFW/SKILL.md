# NSFW专项写作

此技能是 Write-Router 调度体系下的 NSFW 专项扩展，提供四档分级写作模式，覆盖从隐晦隐喻到完全开放的成人内容写作全尺度。

## 核心定位

- **三调度源**：
  - **Write-Router**：检测到正文 NSFW 内容后自动调度，处理 NSFW 段落
  - **创建阶段技能**：创建人物填写 NSFW 字段（XP/三维/性特征/人物X能力）时调度，做词汇选择和档位匹配
  - **用户直接触发**：/nsfw-config、独立 NSFW 写作、色色值调整
- **四档模式**：大众级 / 限制级 / 解限级 / 直白级，逐级放开尺度
- **叠加核心规范**：在基础写作辅助的核心规范之上叠加 NSFW 专项规则，不替代、不冲突
- **人物感知**：限制级模式下必须读取角色文件，依据角色性格选择用词尺度，绝不 OOC

## 触发条件

### 由 Write-Router 调度（正文 NSFW 段落）

Write-Router 在步骤 2（内容检测）检测到 NSFW 内容时，自动调度此技能处理，处理结果返回后纳入最终输出。

### 由创建阶段技能调度（NSFW 字段词汇选择）

创建人物技能在用户填写 NSFW 字段（XP/三维/性特征/人物X能力）时，调度此技能做词汇选择：
- 根据 `项目信息.json` 中的 `nsfw_output_level` 和 `nsfw_character_tone` 匹配用词级别
- 如项目未配置 NSFW 偏好 → 按 2.5.1 流程询问用户并写入配置
- NSFW 字段词汇选择完成后返回创建人物技能，不直接写入文件

### 用户直接触发

- "写 NSFW 内容"、"写成人内容"、"写色情场景"
- "这段要写床戏"、"写个吻戏/床戏"、"写个 H 场景"
- "切换到 NSFW 模式"、"用 NSFW 模式写"
- "这段改得再色情一点"、"尺度再大一点"
- "色色值"、"调整色色值"、"这章色色值设多少"
- "/nsfw-config"、"NSFW配置"
- 任何表达需要写作成人/色情/性相关内容的表述

## 关联文件

| 文件 | 位置 | 用途 | 读写 |
|------|------|------|------|
| `项目信息.json` | `大纲/` | NSFW 偏好（`nsfw_output_level`/`nsfw_character_tone`/`nsfw_tier_range`）+ `content_rating` + **分卷信息（`volumes.*`）** | 读写 |
| `润色配置.json` | `大纲/` | 润色模式（读 `正文.polish_mode` + `分卷` 覆盖项；分卷时按当前卷取对应润色配置） | 只读 |

## 执行模式

**由 Write-Router 调度时**：跳过计划模式，直接按步骤执行。

**由创建阶段技能调度时**：跳过计划模式，仅执行词汇选择（步骤 1 确定档位 + 步骤 2 读取上下文 + 词汇表匹配），不执行完整写作流程。返回选定的词汇给调用方。

**用户直接触发时**：进入计划模式（EnterPlanMode），列出处理步骤和将使用的 NSFW 档位后执行。

## 四档模式定义

### 大众级 —— 隐晦隐喻

**适用场景**：
- 一般向作品中的轻度 NSFW 暗示
- 需要公开发布、通过公众平台内容审查的场景
- 项目 `项目信息.json` 中 `content_rating` 为 `一般向`

**核心原则**：极其隐晦，只可意会不可言传。用日常物品/概念隐喻 NSFW 内容，表面读起来完全无害。

**词汇替换示例**：

| 原词 | 大众级隐喻 |
|------|-----------|
| 跳蛋 / 震动棒 | 跳舞的鸡蛋、电子男友、嗡嗡、小马达 |
| 假阳具 / 按摩棒 | 假男友、硅胶朋友、替代品 |
| 飞机杯 | 斐济杯、手工杯、练习杯 |
| 润滑液 | 滑滑水、护肤液、透明胶 |
| 乳房 / 胸部 | 起伏的曲线、柔软处、胸前 |
| 阴茎 | 那话儿、小兄弟、那东西 |
| 阴道 | 私处、那里、深处 |
| 做爱 / 性交 | 亲密、在一起、云雨、温存 |
| 高潮 | 那一刻、顶点、空白 |
| 自慰 | 自我安慰、独处时光、手动模式 |

**写作要求**：
- 整段读起来像正常叙事，只有"懂的人懂"
- 不直接出现任何性器官/性行为词汇
- 用动作的省略和留白代替直接描写
- 用环境/物品的异常状态暗示发生了什么
  - 示例：不写"她用跳蛋自慰"，写"她把那个会跳舞的鸡蛋塞进枕头底下，蒙上被子，过了很久才安静下来"

- 项目 `项目信息.json` 中 `content_rating` 为 `NSFW`

**核心原则**：用优雅的代称替代医学术语/粗俗词汇。**必须感知人物性格**——保守角色用更文雅的说法，放荡角色可稍直接，但总体保持文学性。

**OOC 判断规则（关键）**：

1. **读取角色文件**：从对应类别角色文件（`主要角色.md` / `次要角色.md` / `龙套角色.md`）中读取涉及角色的性格与简介；分卷多文件时读取对应卷目录下的角色文件

- 来自限制级放荡角色可用：花唇、小豆豆、小穴、那根、大肉棒、蛋蛋、奶子、奶头、屁股、干、去了、淫水

2. 但仍有底线：不使用直白级中的纯粗俗/脏话类词汇
3. OOC 判断放宽但不废弃：仍需读取角色文件，保守角色可适当突破但幅度不宜过大——保守角色说"小穴""肉棒"可接受，但说"鸡巴""骚逼"仍属 OOC
4. 肉体感受优先原则同限制级和直白级

6. 角色语气分化：
   - 保守角色：选词的刺激度控制在中低段（如"花唇""蜜穴""阳具""交合"）
   - 中性角色：选词居中（如"小穴""肉棒""干""去了"）

**OOC 判断规则（放宽版）**：

1. 读取角色文件（同限制级）
2. 评估角色开放度：
   - 保守/矜持角色 → 解限级偏保守词汇（下限=限制级中性，上限=解限级中段）
   - 中性/普通角色 → 解限级中段词汇
   - 放荡/主动角色 → 解限级上限词汇，但不越界到直白级
3. 确定情节语境（初次/热恋/激情）
4. 铁律：不越界到直白级——保守角色在任何场景中说"鸡巴""骚逼"仍属严重 OOC

### 直白级 —— 完全放开

**适用场景**：
- NSFW 作品中的放荡角色写作
- 纯粹的情色/色情场景
- 用户明确表示"不用收敛"、"怎么色情怎么来"

**核心原则**：无任何词汇限制。直白、露骨、粗俗均可。怎么写最色情、最刺激就怎么写。

**写作要求**：
- 不避讳任何词汇：操、干、鸡巴、骚逼、奶子、淫水等均可直接使用
- 可详细描写性器官外观、触感、反应
- 可详细描写性行为过程、体位、节奏
- 可描写角色在被操时的心理活动与生理反应
- 但**仍需遵守基础写作辅助的核心规范**（段落节奏、间接描写、性格间接化、风景穿插、对话增强、降重率）
- 即使直白级，也不建议整段整段连续写"啊啊啊"——有节奏、有呼吸的色情比堆砌词汇更有效

## NSFW 核心写作技法（限制级 & 解限级 & 直白级）

以下技法适用于**限制级**、**解限级**和**直白级**。大众级以隐晦为首要目标，不受此节约束。

### 核心原则：肉体感受 ＞ 精神思考

NSFW 写作的第一要务是**传递肉体感受**，而非铺陈角色的精神活动、道德反思或情感内涵。

**精神思考不能放弃，但绝对不是主角。** 它只作为肉体感受的辅助调味——点缀一两句即可，绝不占据大段篇幅，更不应在同一个场景中反复出现。

### 反"注水肉"规则

一般向作品中，角色在背德感、羞耻感下产生别样/异样感觉时，作者常通过多次提及、反复强调、大篇幅描述来渲染氛围。**这在 NSFW 写作中是致命的。**

- 同一场景中，同一种精神感受（如背德感、羞耻感、罪恶感）**最多提及一次**
- 提及方式应**简短**——一句话带过即可，不展开、不反复、不回扣
- 精神感受提及后，立刻回到肉体描写上

**反例（注水肉）**：
> 她知道自己不该这样，这违背了她从小受到的教育。可是那种背德感反而让她更加兴奋了。她一边唾弃着自己，一边又沉溺在这种禁忌的快感中。这种负罪感像毒药一样，让她一边痛苦一边快乐着……

**正例**：
> 她知道自己不该这样，但这个念头只闪了一瞬。
>
> 下一秒，他的手探进来时，她已经什么都顾不上了。

### 写作重心分配

NSFW 场景中，各类内容的合理占比：

| 内容类型 | 限制级 | 解限级 | 直白级 |
|---------|--------|--------|--------|
| 肉体感受（触感、温度、呼吸、生理反应） | ≥50% | ≥55% | ≥60% |
| 动作描写（身体动作、互动、节奏） | ≥20% | ≥22% | ≥25% |
| 对话（含喘息、呻吟等） | ≤15% | ≤12% | ≤10% |
| 精神思考（内心活动、道德反思） | ≤10% | ≤7% | ≤5% |
| 环境/风景穿插 | ≤5% | ≤5% | 酌情 |

**肉体感受优先描写角度**：
1. **触感**：温度（滚烫/微凉）、质地（坚硬/柔软/湿滑）、压力（轻抚/用力/撞击）
2. **生理反应**：呼吸变化、心跳、体温上升、肌肉紧绷/松弛、体液分泌
3. **声音**：喘息声、水声、布料摩擦声（不是对话，是身体发出的声音）
4. **视觉**：身体的视觉变化（泛红、颤抖、紧绷）、而非对形貌的审美评价

**精神思考使用的约束**：
- 每次出现不超过一句
- 必须紧贴肉体反应——是"因为这种触感让她想起……"而不是"她陷入了对人生的沉思……"
- 同一场景中禁止精神思考连续出现两次以上

### NSFW 白描许可（限制级 & 解限级 & 直白级）

基础写作辅助的规范 2（人物描写间接化）在 NSFW 场景中**不适用**。NSFW 内容恰恰需要直接、详细的白描来传递肉体感受，这是提升色气感的核心手法。

**原则**：NSFW 场景中的性描写，优先使用直接白描——写清楚谁碰了哪里、怎么碰的、感受到了什么。长篇白描在此不仅是允许的，是推荐的。

- 不绕弯子、不借物喻人、不借镜喻人——直面身体与动作
- 允许长段落连续白描性行为过程，写出节奏与递进
- 白描的重点是动作+感受，不是堆砌形容词

**示例（直接白描——自慰场景）**：
> 她坐在地上靠着床边，左手缓慢地抚摸到自己的小穴上，右手抚在胸前，不断挑逗着乳首。左手手指试探着，一根手指就带来不少快感，只可惜自己的手指有点短……随着浑身一阵剧烈的颤抖，她蜷起身子，去了。

**示例（直接白描——交合场景）**：
> 张三将自己雄壮的肉棒抵在李四的小穴上摩挲，而后噗呲一声插入。
>
> "啊——"李四仰起脖子，手指抓紧了床单。

**白描长度控制**：
- 色色值挡位越高，白描篇幅越长
- N1 挡位：白描 ≤ 全文 1/4，点到为止
- N2 挡位：白描可占全文一半，场景可充分展开

## 性器与行为描写要则

> 此节不涉及情节/场景技法，专注**怎样写性器和性行为本身才色**。以下要则适用于限制级、解限级、直白级三档。

### 原则〇：画面优先于过程

NSFW 描写的篇幅应该花在**让读者看见画面**上，而不是花在**解释动作的力学过程**上。

这是 NSFW 写作中最容易犯的错位：花费大量篇幅描写"骨盆如何旋转""胸腔如何传导""快感如何从脊椎末梢传递到下腹"——这些解剖学的传递链、力学的因果分析，是过程的辅助说明，不是色情的核心。

读者要看见的是：
- 身体的**姿态**——她趴在石桌上，雪白的臀部高高翘起，双腿分开
- 皮肤的**状态**——冷白色的皮肤在月光下近乎透明，汗珠顺着脊背滑落

- 身体的**微变化**——乳尖在空气中越来越硬、小穴入口还在轻微收缩

**辅助手段（服务于画面，不可喧宾夺主）**：
- 力学传导（"骨盆带动腰椎，腰椎传导到胸腔"）——只作为身体姿态变化的骨架，一笔带过即可
- 神经传递（"快感从末梢神经一路传导到中枢"）——只作为感受来源的交代，不应展开为长篇分析

**判断标准**：写完一段 NSFW 描写后问自己——这段文字里有几成是读者能"看见"的画面，几成是读者看不见的"过程/原理/分析"？画面应占据绝大部分篇幅，力学和神经只在需要交代身体变化时露一面就退场。

| 结论式（无效） | 画面式（有效） |

### 步骤 0：确定调用来源与文本范围

NSFW 技能有两种被调用方式，文本范围不同：

**A. 由 Write-Router 调度（预分割）：**
Write-Router 已完成段落分割，NSFW 收到的数据包中 `text` 字段仅包含 NSFW 段落。直接进入步骤 1。

**B. 用户直接触发（全文未分割）：**
用户提供了完整文本（可能混合一般叙事与 NSFW 内容）。此时 NSFW 需自行完成内容识别与切分：

1. **逐段扫描**：以段落为单位遍历全文
2. **按三级检测判定**（同 Core 步骤 2.1 的三级扫描规则）：
   - 命中一级（显性词汇）→ 标记 NSFW 段落

4. **边界合并**：两个 NSFW 段落组之间如果仅隔 ≤2 个一般段落，合并为一个 NSFW 段落组（避免因一句换气话把同一场床戏拆成两段）

## 与 Write-Router 的协作

```
用户输入文本
    │
    ▼
Write-Router（步骤 2-3：内容检测 + 段落预分配）
    │
    ├── 一般段落 → Core 直接处理
    │
    └── NSFW 段落 → 打包数据发送 ───────────────────────┐
          ↑                                                 │
          │  {text, context:{volume, chapter,               │
          │   scene_type, ...}, polish_mode,                │
          │   content_rating}                               │
          │                                                 ▼
          │                                        NSFW专项写作
          │                                            │
          │                                   步骤 0：确认文本范围
          │                                   步骤 1：确定四档
          │                                   步骤 2：读取上下文
          │                                   步骤 2.5：确认色色值
          │                                   步骤 3：按档位处理
          │                                   步骤 4：规范叠加过检
          │                                   步骤 5：输出+返回元数据
          │                                            │
          │  {processed_text, nsfw_tier_used,            │
          │   sexy_value, exempted_norms,                │
          │   key_changes, ooc_warnings}                 │
          └────────────────────────────────────────────┘
                    │
                    ▼
              Write-Router（步骤 5：整合）
              • 按原位置拼合段落
              • 依 exempted_norms 跳过规范 2 和 2.2
              • 全篇一致性过检（规范 1/3/4/5）
                    │
                    ▼
              长篇专项（如需要）
              • 伏笔登记 / 剧情回忆
                    │
                    ▼
              成品输出校验
              • 第一轮：CPS.json 标点合规扫描
              • 第二轮：Core规范 段落/字句结构扫描
              • 通过 → 落盘 / 不通过 → 修正→重检
                    │
                    ▼
              最终输出
```

**协议要点：**
- Write-Router 负责检测、分割和整合，NSFW 负责处理 NSFW 段落的专项优化和豁免
- NSFW 自行完成 **NSFW 专项校验**（步骤 4）：档位色色值合规、白描篇幅控制、精神思考比例、NSFW 降重率（同器官/同触感段落内重复）——这些校验**不出现在成品输出校验中**
- NSFW 处理后返回的 `exempted_norms` 告知 Write-Router 跳过规范 2/2.2 的二次检查，Write-Router 透传给成品输出校验技能
- Write-Router 做全篇一致性过检，确保 NSFW 段落与一般段落的节奏/呼吸保持协调
- Write-Router 整合完成后按流水线自动调度：长篇专项（如需要）→ 成品输出校验→ 落盘输出
- 如 NSFW 返回 `ooc_warnings`，Write-Router 在输出前向用户展示并确认

## 注意事项

- 大众级的关键是"只可意会"——如果读者一眼能看出在写什么，说明隐喻还不够隐晦
- 限制级的关键是"人物一致性"——词汇选择必须从角色性格推导，不能为色情而 OOC
- 解限级的关键是"色情感足但优雅不降"——词汇选择在限制级上限和直白级下限之间精确取位；保守角色可小幅破格但不越界到直白级词汇
- 直白级不是"放弃写作规范"——核心规范在直白级仍然适用，防止色情场景变成词汇垃圾场
- **限制级、解限级、直白级铁律**：肉体感受 ＞ 精神思考。精神思考每次出现不超过一句，同场景禁止连续出现两次以上。背德感/羞耻感等同类型精神感受同一场景最多提及一次
- **NSFW 白描许可**：核心规范 2（间接描写）在 NSFW 场景中不适用——直接白描是提升色气感的核心手法；长篇白描允许且推荐，长度由色色值控制
- 四档之间不可混用：同一场景中不能一句话大众级、下一句直白级，保持档位统一
- **色色值询问**：每章涉及 NSFW 内容时**必须**先确认色色值挡位（N1-N5），不同挡位对应不同的白描篇幅与节奏控制；如已配置全书值域（`项目信息.json`），则在该范围内微调
- **项目数据推荐**：首次调用时询问全书值域与输出词级别并持久化至 `大纲/项目信息.json`，此项为非必须但强烈推荐——配置后可大幅提升 LLM 输出准确性；如用户连续两次以上对输出不满意，主动推荐配置
- 如用户对自动选择的档位不满意，允许随时切换并重新处理
- 大众级替换不改变原文叙事结构和关键信息
- 始终以 Markdown 格式输出文本内容
