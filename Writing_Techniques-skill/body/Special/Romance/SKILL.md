# 言情写作专项

此技能是 Write-Router 调度体系下的言情专项扩展，专注于人与人之间情感互动场景的写作优化。不含 NSFW 性内容——言情注重的是心动、试探、拉扯、确认的心理互动，而非肉体层面的描写。

## 核心定位

- **被调度技能**：通常由「Write-Router」检测到言情内容后自动调度，用户也可直接触发
- **情感互动限定**：仅处理非 NSFW 的恋爱/浪漫场景——暧昧、表白、约会、争吵和好、思念、暗恋、确认关系等。NSFW 性内容由 NSFW 专项写作处理
- **叠加核心规范**：在 Core 的五项核心规范之上叠加言情专项规则，不替代、不冲突
- **人物感知**：必须读取角色文件，依据角色性格、情感经历、关系阶段决定其在言情场景中的行为模式和心理活动

## 触发条件

### 由 Write-Router 调度

Write-Router 在步骤 2（内容检测）检测到言情内容时，自动调度此技能处理，处理结果返回后纳入最终输出。

### 用户直接触发

- "写言情场景"、"写感情戏"、"写恋爱场景"
- "写一段暧昧"、"写表白"、"写约会"
- "这段感情戏不够动人"、"帮我优化这段互动"
- "写暗恋"、"写吃醋"、"写冷战和好"
- "写心动瞬间"、"写两人的初次见面（恋爱向）"
- 任何表达需要写作/优化恋爱/言情/浪漫互动场景的表述

## 言情场景类型识别

处理言情内容前，首先判定情感场景类型——不同类型适用不同的技法侧重：

### 类型 A：暧昧/试探

互有好感但未挑明阶段的互动。重点：眼神、小动作、言外之意、距离感的微妙变化。

**技法侧重**：暧昧与张力 > 心理描写 > 互动细节 > 对话情感层次

### 类型 B：表白/确认关系

一方或双方表达心意的关键场景。重点：情绪铺垫、对话节奏、表白后的反应空白、肢体语言。

**技法侧重**：心理描写 > 对话情感层次 > 情感节奏控制 > 氛围营造

#### 被表白后的反应模式（按性格分类）

表白不是单向的"说出→接受/拒绝"。**被表白者的性格**决定了她在听到表白那一刻的反应——而这个反应往往比表白本身更有戏剧张力。

| 性格类型 | 被表白后的第一反应 | 心理内核 | 典型表现 |
|---------|------------------|---------|---------|
| **直率型** | 惊喜、兴奋、立刻回应 | 情感外放，喜欢就是喜欢，不藏 | 眼睛亮了，嘴角压不住笑，可能直接扑上去或者大声说"我也喜欢你" |
| **防御型** | 不确定、质疑、反问 | 确实喜欢对方，但不习惯暴露软肋——"你说的真的假的？""为什么是我？"——用问题拖延情绪暴露 | 后退半步，抱臂，皱眉，嘴上说"你在开玩笑吧"，手指却在发抖 |
| **进攻反问型** | 反客为主，用进攻姿态回应 | 两种子类——傲娇型：外表高冷、嘴硬心软，被戳穿后恼羞成怒，用攻击性语言掩盖心动（"你脑子坏了？""谁说我喜欢你了？"），但耳尖通红、眼神闪躲出卖了她；理性型：喜欢是真的，但需要逻辑自洽——"你什么时候开始喜欢我的？""你喜欢我哪一点？""你怎么确定这是喜欢而不是别的？"——不是在拒绝，是在**做评估**，回答满意后会认真点头 | 傲娇型：音量不自觉提高，语速变快，身体往后但眼睛没移开，说完"胡说八道"之后安静了——安静比反驳更有说服力。理性型：视线锁定对方，表情认真甚至严肃，像是在做一个重大决策前做风控——每个问题都问得真诚，每个回答都认真听 |
| **责任型** | 沉默、思考、需要时间 | 喜欢是真的，但"在一起"三个字太重——需要考虑现实因素、担心能否承担、怕辜负 | 长时间安静，眼神落在地面某处，最后说"让我想想"——这四个字本身就是一种告白 |
| **慢热型** | 回避、转移话题、佯装没听懂 | 情感是震撼的，但处理系统跟不上——需要独处慢慢消化 | 突然开始忙别的事，语速变快说些无关的话，但耳尖通红，做事手忙脚乱 |
| **自保型** | 退缩、甚至拒绝 | 喜欢但更怕受伤——过往经历让她把"被爱"等同于"将会失去" | 摇头，往后退，声音很轻："我不值得。"眼眶却在发红 |

**关键约束**：
- 同一个人在不同关系阶段可能有不同反应——防御型在足够信任后也会变成直率型
- 反应必须是**该角色性格的自然延伸**，不是为戏剧效果硬贴的标签
- 被表白后的"沉默"（责任型/慢热型）本身是强有力的回应——比立刻回答更有张力

#### 被拒绝后的反应模式

被拒绝 ≠ 伤心难过。角色对被拒绝的反应，同样由性格和表白动机决定。

| 拒绝后的真实心态 | 心理内核 | 典型表现 |
|----------------|---------|---------|
| **释然/放下** | "我知道不可能，表白只是让自己死心。"——表白是给自己的交代，不是给对方的选择题 | 长出一口气，笑了，可能是苦笑但确实是笑。"谢谢你听我说完。"转身走得很快，像是卸下了一块石头 |
| **平静接受** | 喜欢是真的，尊重对方的决定也是真的——不需要歇斯底里来证明爱得深 | 点点头，"我知道了。"短暂停顿后换话题，眼眶微红但不哭，留给对方一个体面的退场 |
| **受伤但不后悔** | "疼归疼，但不说出来更疼。"——宁愿被拒绝也不愿留遗憾 | 当场稳住情绪，笑着告别，转身后眼泪才掉下来——或者一直没掉，但那个下午什么都没做 |
| **崩溃/不甘** | 投入太深、期待太高、或性格本身就偏执——这是最"戏剧化"的反应，也最不推荐滥用 | 追问"为什么""我哪里不够好"，反复打电话/发消息——这类反应**仅适用于角色性格中存在偏执/不成熟/过度依赖特质时使用**，不可作为默认模板 |

**核心原则**：表白被拒后的反应，定义了这个角色的**情感成熟度**。一个能体面接受拒绝的角色，比一个歇斯底里的角色更有力量。

#### 表白并非恋情的必选项

言情写作中一个常见的误区是把"表白"当作恋情的唯一起点——必须有一个人说"我喜欢你"，另一个人同意，关系才算"开始"。但在现实的情感逻辑中：

**陪伴与经历大于仪式**。两个人一起经历过的事情、共度的时间、彼此之间不需要说就懂的默契——这些才是关系的实质。表白只是一个**确认**，不是**创造**。

| 关系开始的方式 | 适用情境 | 写法要点 |
|-------------|---------|---------|
| **自然过渡**（无明确表白） | 两个人从暧昧到在一起，中间没有谁说"我喜欢你"，但双方都清楚关系已经变了 | 通过行为变化暗示——开始自然地牵手、用更亲密的称呼、做出只有情侣才会做的事。读者通过"他们什么时候开始这样的"来感知关系升级 |
| **事件催化** | 某个外部事件（危险、离别、误会澄清）让一方或双方意识到"我不能失去这个人" | 事件是催化剂，不是替代品——事件之后的互动变化才是重点。拥抱比表白更有力 |
| **告白仪式** | 一方精心准备或一时冲动，明确说出心意 | 重点不在"说了什么词"，而在说之前的铺垫（紧张、犹豫、深呼吸）和说之后的反应空白（等待回答的那几秒） |
| **对方替你说** | 第三方（朋友、旁观者）戳破——"你看她的眼神不对劲""你们两个到底什么时候在一起" | 被戳破后的反应——否认？沉默？两个人同时脸红？——比主动表白更含蓄但同样有效 |

**仪式的作用**：表白仪式（无论谁发起）是对对方的**尊重和取悦**——"我愿意把自己最脆弱的部分摊给你看"。需要仪式的角色通常是：重视承诺的责任型、需要确定感的自保型、喜欢浪漫的直率型。不需要仪式的角色通常是：慢热型（觉得尴尬）、防御型（觉得多余）、或者两个人已经默契到不需要了。

### 类型 C：约会/日常甜蜜

确认关系后的日常浪漫互动。重点：细节中的亲密感、平淡中的深情、日常仪式感。

**技法侧重**：互动细节 > 氛围营造 > 心理描写 > 对话情感层次

### 类型 D：争吵/冷战/和好

感情冲突与修复。重点：争执中的真实情绪（嘴硬心软）、沉默中的心理活动、和好时刻的情感释放。

**技法侧重**：对话情感层次 > 心理描写 > 情感节奏控制 > 互动细节

### 类型 E：思念/暗恋/异地

单方面的情感体验或分隔两地的牵挂。重点：内心独白、触景生情、回忆与现实交织。

**技法侧重**：心理描写 > 氛围营造 > 互动细节 > 情感节奏控制

## 言情专项技法体系

以下六项技法是此技能的核心处理标准。优化言情文本时逐条过检，不可跳过。技法体系之上有总原则〇，统领全部技法。

### 原则〇：画面优先于过程

**让读者"看见"，而不是被"告知"。** 言情描写的篇幅应花在让读者看见人物此刻的样子——神情、小动作、身体的即时反应——而不是花在解释人物"为什么"有这种感受的心理过程上。与 NSFW 专项的原则〇同源：画面是读者能"看见"的部分，过程是读者看不见的"分析/解释"。

**读者要看见的五类画面**（言情版）：

- **神情**——眼神的躲闪与停留、嘴角的弧度、耳尖泛红
- **小动作**——指尖的犹豫、衣角的揉捏、杯沿的水痕
- **身体的即时反应**——心跳、呼吸变轻、手心的汗
- **距离与空间**——靠近的半步、退后的半步、两人之间那一点说不清的空隙
- **环境落点**——灯光、雨声、风，与人物状态的呼应

**辅助手段（服务于画面，不可喧宾夺主）**：

- **心理解读**（"她知道自己动心了"）——只作为画面的注脚，一笔带过
- **情感分析**（"这份心动源于三个月前的某次回眸"）——不可展开为长篇推演
- 心理是画面的骨架，但它不是画面本身

**判断标准**：写完后检查——几成是读者能"看见"的画面，几成是看不见的"心理过程/情感分析"？画面应占据绝大部分篇幅，心理解读只在需要交代动机时露一面就退场。

**对技法 1 的约束**：三层心理模型（表层/中层/深层）中，**表层（即时反应=画面）始终优先展开**；中层（自我解读）与深层（意义赋予）属于"过程分析"，展开必须适度——用具体的回忆画面而非抽象归纳，且要以行为/互动细节落地（技法 3/4 正可承接）。技法 1 反例"她很喜欢他。从第一次见面就喜欢。她觉得他长得很好看，性格也很好……"正是把心理过程写成清单的典型——心理占比再高，也不得以这种"过程清单"替代画面。

### 技法 1：心理描写——情感的内在风景

**原则**：言情写作的核心是心理——读者需要进入角色的内心世界，感受每一次心动、犹豫、期待和失落。好的言情心理描写让读者"成为"那个正在经历爱情的人，而不是"围观"一段爱情。

**三层心理模型**：

| 层次 | 内容 | 描写手法 | 时机 |
|------|------|---------|------|
| **表层（即时反应）** | 当下的情绪波动——心跳、脸红、手心出汗、语塞 | 生理反应 + 简短内心闪念 | 互动发生的瞬间 |
| **中层（自我解读）** | 角色对自己情绪的理解——"我为什么会有这种感觉？" | 第一人称内心独白或第三人称自由间接引语 | 互动后的独处时刻 |
| **深层（意义赋予）** | 将对方纳入自己的人生叙事——"从什么时候开始，这个人对我变得不一样了" | 回忆交织 + 对比（从前 vs 现在） | 情感转折点/关键场景 |

**正例（三层递进完整）**：

> 表层：他递过来那杯咖啡时，指尖碰了一下她的手背。她没抬头，但她知道自己接杯子的动作慢了半拍。
>
> 中层：后来她在自己的工位上盯着那杯咖啡看了很久。不就是碰到了一下手背？她跟自己说。但那个下午她什么都没做成。
>
> 深层：她想起三个月前第一次见他时的场景，那时候他只是一个名字，一个新同事。现在这个名字出现在她手机的输入法记忆里，打一个字母就能跳出来。

**心理描写在言情场景中的篇幅占比**：

| 场景类型 | 心理描写占比 |
|---------|------------|
| 暗恋/思念/异地 | ≥50%——内心世界是主角 |
| 表白/确认关系 | 30-40%——交替出现：互动→心理→互动→心理 |
| 暧昧/试探 | 25-35%——保持"猜"的感觉，心理不宜过多暴露 |
| 约会/日常甜蜜 | 15-25%——侧重互动和氛围 |
| 争吵/冷战/和好 | 25-35%——嘴硬 vs 心软之间的内心角力 |

**反例**（心理描写直白如说明书）：

> 她很喜欢他。从第一次见面就喜欢。她觉得他长得很好看，性格也很好，对她也很温柔。她希望他能注意到她。

**正例**（心理通过行为和细节传递）：

> 她每次经过他工位时都会绕远路，绕到茶水间，接一杯根本不需要的水。那杯水通常放在桌上，放到凉了也不喝。
>
> 她不知道他有没有注意过。她甚至不知道自己想不想让他注意。

### 技法 2：暧昧与张力——不说破的吸引力

**原则**：言情最动人的部分往往在"将说未说"的阶段。暧昧的核心是**信息不对称**——读者知道双方的感受，但角色彼此不知道；或者一方知道，另一方不知道。这种信息差制造了张力。

**五种暧昧张力手法**：

| 手法 | 操作 | 示例 |
|------|------|------|
| **距离的试探** | 身体距离的微小变化——靠近→保持→更靠近→退后 | "他说话时往前倾了一点。她没有后退，但也没有迎上去。就那么停在那里，像一根绷紧的弦。" |
| **触碰的未遂** | 想碰但没碰——伸手→收回→被对方注意到或没注意到 | "他的手抬了一下。她看到了，那只手在她肩膀上方停了不到一秒，然后收回去，插进了口袋。" |
| **视线游戏** | 看→被看到→移开→再看 | "她低头喝汤的时候，他才看她。她一抬头，他的目光已经移到了窗外：窗外什么都没有。" |
| **话语留白** | 话说一半，或说反话，或说了等于没说 | "'其实你……'她停住了。'算了，没什么。'但那个'没什么'比什么都重，压得两个人都没再开口。" |
| **独处时刻的沉默** | 两人独处时不说关键的话，用沉默制造张力 | "电梯从十五楼下到一楼。谁都没说话。但两个人的呼吸在狭小的空间里清晰可闻：像是某种不约而同的坦白。" |

**硬约束**：
- 同一场景中暧昧手法至少轮换两种——不能全程只用一种（如全程"视线游戏"会变成眼部抽筋）
- 暧昧手法的使用频率应与关系阶段匹配——刚认识时稀疏，暧昧期密集，确认关系后减少
- 一场暧昧场景中至少有一次"未遂"——未遂比完成更有张力

**反例**（暧昧写得太满，没有留白）：

> 他一直看着她，眼神里充满了爱意。她也看着他，两个人的目光在空气中交汇。她心里想：他是不是喜欢我？他也想：她是不是也喜欢我？

**正例**（留白制造张力）：

> 他帮她把那本书从书架最上层取下来。两个人的手同时碰到书脊。
>
> 谁都没有先缩手。
>
> 大约过了一秒，或者三秒，她不知道，他才松开。"给你。"
>
> 她把书抱在胸前，说了声谢谢。声音比平时轻了很多。

### 技法 3：互动细节——大情感藏在小动作里

**原则**：言情场景中，最能打动人的往往不是"我爱你"三个字，而是一个习惯性的小动作、一个下意识的反应、一个只有两个人才懂的细节。这些细节是建立"只属于他们两个人的世界"的关键。

**六类互动细节**：

| 类别 | 描写要点 | 示例 |
|------|---------|------|
| **习惯性照顾** | 一方对另一方无意识的照顾行为 | "每次过马路，他都会绕到她外侧。她问过一次，他说不记得了，大概是习惯了。" |
| **专属物品/动作** | 只对这个人做、只和这个人有关的东西 | "他从不喝奶茶。但每次路过那家店都会买一杯：三分糖，去冰，加珍珠。是她的口味。" |
| **记忆锚点** | 一方记住了对方随口说的话 | "'你上次说想吃这个。'她看着桌上那盘糖醋排骨：那是三个星期前她随口提的。" |
| **同步/镜像** | 两个人不自觉地同步行为 | "她放下杯子的时候，他也放下了。声音重叠在空气里，像两个人同时想说同一句话，又同时咽了回去。" |
| **破例/例外** | 为对方打破自己一贯的习惯 | "他不回短信是出了名的。但她的消息，他每条都回，有时候回得很快，像是手机本来就在手里。" |
| **沉默的理解** | 不需要说什么就懂的默契 | "她没说话，只是把纸巾盒推了过去。他接过来的时候也没说谢谢。有些话，他们之间已经不需要了。" |

**使用频率控制**：
- 同一对 CP（情侣配对），同一类互动细节在相邻两章中不重复
- 每场言情场景中至少有一个互动细节——细节是言情场景的"证据"
- 互动细节必须和角色性格一致——一个粗心的人不会突然给伴侣整理衣领（除非这是角色成长弧线的刻意安排）

**反例**（互动细节堆砌，像列清单）：

> 他给她夹菜，帮她倒水，帮她拿包，帮她开门，帮她拉椅子。

**正例**（一个细节，写出全部深情）：

> 她把包放在座位上起身去洗手间。回来的时候，发现包被挪到了靠墙那一侧，她说过一次，包挂在外侧容易被人碰掉。
>
> 她没说第二次。他也没问。但那个包，再也没有挂在外侧过。

### 技法 4：对话中的情感层次——台词之外的话

**原则**：言情场景的对话精髓在于**潜台词**——说出来的话和真正想说的话之间的差距，就是情感的深度。好的言情对话有三层：字面意思 → 情感暗示 → 未说出口的真心话。

**三层对话模型**：

```
字面："你吃饭了吗？"
  ├── 情感暗示：我关心你 / 我想和你说话 / 我在找借口联系你
  └── 未说出口：我想你了
```

**言情对话五项规则**：

| 规则 | 说明 | 反例 | 正例 |
|------|------|------|------|
| **话不说满** | 情感表达留三分，让读者自己填 | "我爱你" | "'你这个人……'她顿了顿，把后面的话咽了回去。他知道那是什么。她也知道他知道。" |
| **行动比语言响** | 用行动"说"出对话没说出的那部分 | "没事，我不在意"（嘴上说）+ 没有后续 | "'没事。'她说。但递茶给他的时候杯底磕了一下桌面，水洒了三分之一。" |
| **重复中有变化** | 同一句台词在不同章节出现时，意味必须不同 | 每次都说"早点休息"意思都一样 | 第一次见面："早点休息。"（客套）/ 暧昧期："早点休息。"（关心+不舍）/ 在一起后："早点休息。"（承诺，我会在明天等你）|
| **争执台词≠真话** | 吵架时角色说的不是真心话——真心话在行动和事后独白里 | 吵架时直接说"我不爱你了"（如果是真话） | "你走吧。'她背对着他说。手指却把门框攥得指节发白，她没有关门。" |
| **沉默也是台词** | 不说话的时刻是对话的一部分，用叙述填补 | 争吵后没有任何文字交代 | "他开口想说什么，又闭上了。空气在那几秒里变得很重。最后他拿起外套，门在他身后轻轻合上的声音，比她预想的要轻。" |

**与 Core 规范 4 的协同**：Core 规范 4（对话增强）要求对话搭配神情/动作/内心闪念——言情场景中此规范强制执行，且要求更高：神情/动作不能仅是"她笑了""他皱眉"式的简单标注，必须承载情感信息。

**反例**（对话神情空洞）：

> "我喜欢你。"
>
> 她脸红了。

**正例**（神情+动作承载情感）：

> "我喜欢你。"
>
> 她正在翻书的手停住了。那一页停在半空中，然后慢慢地，书被合上了。
>
> 她没有看他。但她的耳朵尖红得像被火烧过。

### 技法 5：氛围营造——环境是第三位角色

**原则**：言情场景中的环境不是背景板——它是第三个在场者。天气、光线、季节、空间——所有这些都可以承载和放大角色的情感状态。

**环境-情感的映射原则**：

| 情感基调 | 环境要素 | 示例 |
|---------|---------|------|
| 心动/甜蜜 | 暖光、微风、花开、日落、小雨（在室内） | "窗外的桂花开了。她每次推开窗，那股甜味就顺着风灌进来：像他说话的声音，不浓，但散不掉。" |
| 暧昧/紧张 | 狭小空间、昏暗光线、过近的距离、钟表声 | "电梯里的灯闪了一下。两个人的呼吸同时停了半秒，然后在黑暗里，她听到了他的心跳。或者也许是她自己的。" |
| 争吵/冷战 | 空旷、冷色调、刺耳的声音、关门的回声 | "餐厅的灯太亮了，亮得让两个人之间没有任何阴影可以藏。她突然觉得这种明亮很残忍。" |
| 思念/孤独 | 雨、深夜、空旷的街道、未回复的消息 | "窗外的雨下了三个小时。她的手机屏幕亮了三次，每一次都不是他。" |
| 离别/伤感 | 黄昏、车站/机场、落叶、未完成的对话 | "站台上的风吹得她的围巾一直在飘。他伸手帮她按住了。这是最后一次了。" |

**硬约束**：
- 环境描写必须与角色的情感状态有关联——不为写景而写景。如果换一个环境这段戏的情绪完全不受影响，说明环境描写是多余的
- 每场言情场景中至少一次环境切入——与 Core 规范 3（风景穿插）协同执行
- 同一情感基调在同一章节中不重复使用同一种环境映射（如写"心动"不能每次都写花开）

**反例**（环境与情感脱节）：

> 她心里难过极了。窗外阳光明媚，鸟语花香。

**正例**（环境承载情感）：

> 她没有哭。只是那天下午的太阳太大了，大得让所有人都眯着眼，没有人看到她眼眶里的那一点红。

### 技法 6：情感节奏控制——爱情的呼吸感

**原则**：言情场景的节奏不是匀速的——它像呼吸，有进有退，有紧张有松弛。好的情感节奏让读者跟着角色一起：屏息→喘息→再屏息→释放。

**四段节奏模型**：

```
靠近（情感/物理距离拉近）
  → 停顿（一个微小的障碍/犹豫——未遂、沉默、被打断）
    → 再靠近（更强的靠近——克服了障碍/不再犹豫）
      → 释放（情感确认/关系推进——但不是终点）
```

**正例（完整的四段节奏）**：

> 靠近：他朝她走了一步。很近，近到能看到她睫毛的弧度。
>
> 停顿：她往后退了半步。不是害怕，是本能。像突然被光照到眼睛时下意识的闭眼。
>
> 再靠近：他没有再往前。但他伸出了手，手心朝上，像在等她自己走过来。那只手很稳。他的声音更稳："不急。"
>
> 释放：她不知道自己在那一刻想了什么。也许什么都没想，因为她的手已经放上去了。

**不同关系阶段的节奏差异**：

| 关系阶段 | 靠近-停顿比例 | 节奏特征 |
|---------|------------|---------|
| 初识/暗恋 | 靠近 1 : 停顿 3 | 靠近微小而频繁，停顿长而沉默 |
| 暧昧期 | 靠近 2 : 停顿 2 | 靠近与停顿交替密集——"推拉"感最强 |
| 确认关系初期 | 靠近 3 : 停顿 1 | 靠近更多，停顿短暂（害羞而非犹豫） |
| 稳定期 | 靠近 1 : 停顿 0.5 | 靠近自然，停顿极短——亲密常态化 |

**硬约束**：
- 每场言情场景必须完成至少一个完整的四段节奏循环
- "释放"不一定是关系升级——可以是一个微小的确认（一次牵手、一句承诺、一个眼神的确认）
- 同一章节中最多两个完整循环——超过则节奏拖沓

## 言情内容与 NSFW 的边界判定

> 言情专项处理的是"心动的过程"，NSFW 处理的是"肉体的接触"。两者有明确边界——但暧昧场景到亲密场景的过渡地带需要精确判定。

**言情范围（本技能处理）**：
- 心动、暗恋、暧昧试探
- 牵手、拥抱、靠肩、整理头发/衣领
- 接吻（点到为止——嘴唇触碰、短暂停留，不涉及舌头/口腔描写）
- 穿着衣服的肢体接触（拥抱时的体温、牵手时的手指交扣）
- 穿睡衣/家居服的日常场景（无性暗示）

**NSFW 范围（调度 NSFW 处理）**：
- 接吻以上尺度的身体接触（抚摸身体、脱衣、涉及性器官/胸部等）
- 明显的性暗示/前戏描写
- 性幻想/情色想象
- 涉及性器官描写的任何场景

**边界地带处理**：
- 深吻（涉及舌头/口腔/呼吸交融的详细描写）→ 视文本整体语境判定：如果重点是情感交流而非身体感受 → 言情；如果以身体感受为主 → NSFW
- 裸体场景（非性行为，如洗澡/换衣服）→ 如果以情感/心理为重点且无性器官描写 → 言情；如涉及身体描写且有性暗示 → NSFW

## 与 Core 五项规范的协同矩阵

言情场景中，Core 五项规范的适用性按以下矩阵调整（✓=强制应用 / △=酌情 / ✕=豁免 / ★=言情专项覆盖）：

| 规范 | 暧昧 | 表白 | 约会 | 争吵 | 思念 | 说明 |
|------|------|------|------|------|------|------|
| 规范 1（标点正确性） | ★ | ★ | ★ | ★ | ★ | 由本技能技法 6（情感节奏控制）覆盖——情感节奏中的靠近与停顿通过逗号串联和句号换气来实现 |
| 规范 1.6（破折号禁令） | ✓ | ✓ | ✓ | ✓ | ✓ | 全技能不免 |
| 规范 1.8（对话衔接） | ★ | ★ | ★ | ★ | ★ | 由本技能技法 1（心理描写）+ 技法 4（对话情感层次）覆盖——言情场景中角色对话、内心独白、潜台词本身就是核心表达手段 |
| 规范 2（间接描写） | △ | △ | △ | △ | △ | 言情中的人物外貌在心动时刻可出现直接描写——"她觉得他好看"是角色的真实感受，不是叙述者贴标签。但禁止"他帅得惊天动地"等空洞形容 |
| 规范 2.2（性格间接化） | ★ | ★ | ★ | ★ | ★ | 由本技法技法 1（心理描写）+ 技法 3（互动细节）覆盖——情感反应本身就是性格的展现 |
| 规范 3（风景穿插） | ★ | ★ | ★ | ★ | ★ | 由本技法技法 5（氛围营造）覆盖——环境是情感的映射，不是随意穿插 |
| 规范 4（对话增强） | ★ | ★ | ★ | ★ | △ | 由本技法技法 4（对话情感层次）覆盖——言情对话增强要求高于 Core 基线 |
| 规范 5（降重率） | ✓ | ✓ | ✓ | ✓ | ✓ | 不同言情场次必须轮换互动细节类型/暧昧手法/环境映射——跨章重复使用同一套"心动描写"视为违规 |

**豁免说明**：
- 规范 2（间接描写）在言情场景中部分豁免——角色对心仪对象的外貌关注是真实的情感反应，允许适度的直接注视和感受描写。但禁止叙述者跳出来做空洞的审美评价（"她美得不可方物"）。
- 此豁免不传达给成品输出校验——由本技能在步骤 4 中随数据包标注 `exempted_norms`。

## 执行步骤

**由 Write-Router 调度时**：接收已分类的言情段落数据包（`text` + `polish_mode` + `content_rating` + `context`），跳过计划模式，直接执行。

**用户直接触发时**：进入计划模式（EnterPlanMode），确认场景类型后执行。

---

### 前置：言情场景类型判定

根据言情内容判定类型（暧昧/表白/约会/争吵/思念），确定技法侧重（见上方"言情场景类型识别"章节）。

如无法自动判定（如文本过短、信息不足），向用户确认场景类型。

---

### 步骤 1：按技法体系处理

逐条过检六项言情专项技法，过检顺序：技法 1（心理描写）→ 技法 2（暧昧张力）→ 技法 6（情感节奏）→ 技法 4（对话情感层次）→ 技法 3（互动细节）→ 技法 5（氛围营造）。

处理完成后立即自闭环校验，按「与 Core 五项规范的协同矩阵」逐条过检——校验完成后成品输出校验不再重复以下检查：

| 规范 | 过检动作 |
|------|---------|
| 规范 1（标点正确性） | 检查情感描写是否用逗号串联为逻辑流、句号是否仅用于换气收束、问号/感叹号是否独立成段 |
| 规范 1.6（破折号禁令） | 全量扫描 `——` 使用——非声音延长用途的按替代表修正 |
| 规范 2（间接描写） | 豁免外貌间接化要求——但检查是否有空洞的审美评价（"他帅得惊天动地"），有则替换为具体感受 |
| 规范 2.2（性格间接化） | 检查是否通过心理描写和互动细节展现性格——而非叙述者评价角色性格 |
| 规范 3（风景穿插） | 检查环境切入是否与情感状态映射——不为写景而写景 |
| 规范 4（对话增强） | 检查对话神情/动作是否承载情感信息——而非空洞标注 |
| 规范 5（降重率） | 检查相邻章节是否重复使用同一互动细节类型/同一暧昧手法/同一环境映射 |

### 步骤 2：输出结果与返回协议

**输出文本**：返回处理后的言情文本（仅言情段落组，不含一般段落）。

**附带元数据**：

```
{
  "romance_type": "{暧昧/表白/约会/争吵/思念/混合型}",
  "exempted_norms": ["规范2"],
  "key_changes": "{关键调整说明}",
  "romance_notes": "{跨章节持续性信息——如角色关系阶段变化、未说出口的情感等}"
}
```

| 字段 | 说明 |
|------|------|
| `romance_type` | 实际判定的言情场景类型 |
| `exempted_norms` | 告知 Write-Router 哪些规范已在言情端豁免，整合时无需二次检查 |
| `key_changes` | 对用户可读的调整摘要 |
| `romance_notes` | 跨章节持续性信息——关系阶段的推进、埋下的情感伏笔，供 Write-Router/长篇专项参考 |

```
              成品输出校验
              • 第一轮：CPS.json 标点合规扫描
              • 第二轮：Core 规范段落/字句结构扫描
              • 通过 → 落盘 / 不通过 → 修正→重检
                    │
                    ▼
              最终输出
```

**协议要点：**
- Write-Router 负责检测、分割和整合，言情技能负责处理言情段落的专项优化
- 言情技能自行完成**言情专项校验**（步骤 4）：心理描写层次、暧昧张力手法、情感节奏、对话情感层次、互动细节、氛围营造——这些校验不出现在成品输出校验中
- 言情技能返回的 `romance_notes` 中包含跨章节持续性信息（如关系阶段推进），Write-Router 应在后续章节写作中传递给相关技能
- Write-Router 整合完成后按流水线自动调度：长篇专项（如需要伏笔登记/剧情回忆）→ 成品输出校验（标点+结构双轨）→ 落盘输出

## 注意事项

- **言情 ≠ NSFW**：言情写的是"心动"，NSFW 写的是"身体"。暧昧场景到接吻为止属于言情；接吻以上尺度的身体接触属于 NSFW。边界判定见上文专节
- **非本技能范围的内容**：
  - 纯性描写/床戏 → NSFW 专项
  - 婚姻/家庭伦理剧（婆媳矛盾、育儿分歧等）→ 由 Core 处理（非恋爱互动）
  - 友情/兄弟情/姐妹情中的深厚情感 → 由 Core 处理（非恋爱向）
  - 单恋复仇/因爱生恨的行动线（如跟踪、报复）→ 视具体内容由 Core 或战斗专项处理
- **人物一致性**：言情行为必须从角色性格推导——一个内向害羞的人不会突然在人群中大声表白（除非经过铺垫和情感累积）；一个理性克制的人不会为爱冲昏头脑（除非这是精心设计的性格突破点）
- **关系阶段一致**：两个角色的互动方式必须与他们当前的关系阶段匹配——刚认识不会说"我会等你一辈子"；热恋期不会冷淡如初识
- **技法不是公式**：六项技法是指导原则，不是填表。好的言情让人忘记技法——读者只感受到心跳，感受不到框架
- **情感留白**：言情最忌"写满"——把每一个心动、每一份犹豫、每一句潜台词都解释清楚，等于剥夺了读者的想象空间。相信自己描述的细节，相信读者能"懂"
- **始终以 Markdown 格式输出**文本内容
