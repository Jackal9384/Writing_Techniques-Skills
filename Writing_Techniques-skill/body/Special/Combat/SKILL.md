# 战斗描写专项

此技能是「Write-Router」的战斗专项扩展，专注于人与人之间直接对决场景的写作优化。不包含大场面战争（军队对冲、阵地战、大规模群战等）。

## 核心定位

- **被调度技能**：通常由「Write-Router」检测到战斗内容后自动调度，用户也可直接触发
- **对决限定**：仅处理人与人之间的直接对决——1v1 单挑、2v2 小团对战、一对多（≤5人），不涉及军队/阵法/大规模战争
- **叠加核心规范**：在 Core 的五项核心规范之上叠加战斗专项规则，不替代、不冲突
- **人物感知**：必须读取角色文件，依据角色战斗风格、实力层级、性格决定其在战斗中的行为模式

## 触发条件

### 由Write-Router调度

Write-Router在步骤 2（识别内容类型）检测到战斗内容时，自动调度此技能处理，处理结果返回后纳入最终输出。

### 用户直接触发

- "写一场战斗"、"写打斗场景"、"写对决"
- "这段打斗帮我优化一下"、"战斗描写不够精彩"
- "写一场XX和XX的对决"、"写单挑"
- "招式描写"、"动作戏"、"武打场景"
- "写个打戏"、"械斗"、"超能力对决"
- 任何表达需要写作/优化战斗对决场景的表述

## 战斗类型识别

处理战斗内容前，首先判定战斗类型——不同类型适用不同的技法侧重：

### 类型 A：冷兵器对决

刀、剑、枪、棍棒等冷兵器近身格斗。重点：招式的空间关系、兵器触感、攻防节奏。

**技法侧重**：动作节奏控制 > 打击感描写 > 招式体系 > 环境交互

### 类型 B：徒手格斗

拳脚、擒拿、摔投。重点：身体触感、力量传导、疼痛递进。

**技法侧重**：打击感描写 > 伤势递进 > 动作节奏控制 > 心理博弈

### 类型 C：超能力/法术对决

元素操控、能量对轰、念动力等。重点：视觉奇观与内在消耗的平衡、能力边界的清晰性。

**技法侧重**：招式体系规范 > 环境交互 > 心理博弈 > 打击感描写

### 类型 D：枪械/现代兵器对峙

枪战、狙击对决。重点：空间位置、时间压缩感、心理博弈。

**技法侧重**：心理博弈 > 动作节奏控制 > 环境交互 > 打击感描写

### 类型 E：混合型

以上类型的组合（如冷兵器+超能力、徒手夺枪等）。按主要冲突手段判定侧重，辅助手段酌情融入。

## 战斗专项技法体系

以下六项技法是此技能的核心处理标准。优化战斗文本时逐条过检，不可跳过。

### 技法 1：动作节奏控制

**原则**：战斗段落的节奏由"出招↔受击↔反应↔喘息"四拍构成。长段连续动作必须穿插短暂的停顿（呼吸、对峙、环境切入），让读者有时间"看见"每一击。

**四拍循环模型**：

```
出招（谁、用什么、打向哪里）
  → 受击（打中与否、打在哪里、什么效果）
    → 反应（受击者的身体反应 + 心理闪念）
      → 喘息（间隙——环境/呼吸/对峙/状态评估）
        → 下一轮出招…
```

**硬约束**：

- 连续动作描写（出招→击中→效果→追击）属同一逻辑链，应用逗号串联为一个完整的自然段，而非用句号截断为碎片
- 每轮四拍循环完成后，必须有一个"喘息拍"——可以是环境切入、呼吸描写、旁观者反应、或短暂对峙
- 战斗白热化阶段（决定性一击前后），喘息拍可缩减但不能完全取消——完全取消会导致动作堆叠、读者无法跟上节奏

**正例**（四拍循环完整）：

> 他一剑斜劈，剑锋直取对方左肩。
> 
> 剑刃切进皮肉的一瞬，对方闷哼了一声。
> 
> 血从裂开的袖口渗出来，顺着手肘往下滴。那人低头看了看伤口，又抬头看他。眼神变了。
> 
> 巷口的风灌进来，吹得灯笼晃了两晃。
> 
> 下一剑来得更快。这次是咽喉。

**反例**（动作堆叠、无喘息）：

> 他一剑劈下对方挡住反手又是一剑刺向胸口对方侧身躲过剑锋擦过衣襟他再进步横扫对方跃起躲开落地时一脚踢向他手腕……

**段落节奏在战斗中的特殊处理**：

Core 规范 1（标点正确性）在战斗场景中的具体应用：

| 战斗阶段 | 节奏特征 | 标点指引 |
|---------|---------|---------|
| 对峙/蓄势 | 紧张感由短段制造，段落偏短但不强制 | 静态描写可一句一段；句号用于收束对峙状态 |
| 交锋 | 出招+受击属同一逻辑链，逗号串联 | 一击→效果→反应为一个自然句，用逗号连接；句号仅在换气/拆段时使用 |
| 连击/压制 | 快速连续动作，逗号串联为一气呵成的长段 | 大量使用逗号连接击打动作；在连击结束时用句号收束 |
| 喘息/间隙 | 环境/呼吸/状态评估，节奏放缓 | 正常使用句号形成明确的"暂停感" |
| 决胜一击 | 视觉冲击力最强，独立成段 | 前后空行制造视觉停顿，段落本身可长可短 |

核心原则：连续的战斗动作（出招→击中→反应→下一个动作）属于同一逻辑链，应用逗号串联，而非用句号将其截断为碎片。一段极长的连续交锋描写，只要逗号使用正确、逻辑流转清晰，是完全合规的。

**禁止**：战斗中感叹号/问号链接。高潮处的"啊——""什么？！"等必须独立成段。

### 技法 2：打击感描写

**原则**：战斗的核心是"打到"——读者需要感受到每一击的力量、速度、和后果。打击感来自三个维度的叠加：触感 + 声音 + 后果。

**三维打击感模型**：

| 维度     | 描写内容                  | 示例                   |
| ------ | --------------------- | -------------------- |
| **触感** | 击中瞬间的感觉：震动、温度、硬度、疼痛级别 | "虎口一麻，剑险些脱手"         |
| **声音** | 击中发出的声音：骨骼、金属、肉体      | "砰的一声闷响，像是木棍砸在湿泥上"   |
| **后果** | 击中后的即时效果：伤口、位移、动作变形   | "他往后踉跄了两步，左臂已经抬不起来了" |

**打击感层级**（由轻到重）：

| 层级  | 伤害程度     | 描写重点         | 示例                               |
| --- | -------- | ------------ | -------------------------------- |
| 轻击  | 擦伤/瘀伤    | 触感为主，声音为辅    | "剑尖擦过手背，留下一道白印，随即渗出血珠"           |
| 中击  | 割裂/骨折/内伤 | 触感+声音并重      | "那一拳砸在肋骨上——咔嚓一声，他自己都听到了"         |
| 重击  | 致命/断肢/击飞 | 声音+后果为主，触感为辅 | "剑锋没入胸口时几乎没有声音。拔出来的时候才有，就像是开红酒。" |

**反例**（无打击感——只写动作不写效果）：

> 他一拳打过去，对方躲开了。他又踢了一脚，这次踢中了。对方退了两步。

**正例**（三维打击感）：

> 那一拳擦过他耳畔，拳风刮得耳廓生疼。
> 
> 他没等对方收拳，一脚蹬在对方的小腹上。
> 
> 那人弯下腰，捂着肚子退了三步，每一步都带着一声闷咳。

**打击感描写的频率控制**：

- 每一击至少覆盖三维中的两维
- 关键打击（改变战局的一击）三维全写
- 非关键击打（试探、佯攻）至少写一维
- 同一场战斗中，同一种打击后果（如"后退两步"）不重复使用超过两次——换后果类型（"手臂发麻""膝盖一软""视野一黑"）

### 技法 3：招式体系规范

**原则**：招式命名与描写必须在世界观框架内保持自洽。招式不是越华丽越好——好的招式体系让读者能"看见"这一招是怎么打的。

#### 3.1 招式命名规范

| 命名风格   | 适用世界观     | 示例                        |
| ------ | --------- | ------------------------- |
| 动作描述型  | 写实武侠/历史格斗 | "进步直刺""缠头裹脑""转身鞭拳"        |
| 意象型    | 东方玄幻/武侠   | "苍龙出水""落花拂柳""怒涛三叠"        |
| 功能型    | 西方奇幻/超能力  | "火球术·压缩""风刃·连斩""暗影步"      |
| 编号/等级型 | 学院/军事/系统流 | "基础剑术·第七式""S级雷击""战术动作-03" |

**命名约束**：

- 同一世界观中，招式命名风格必须统一（不能同时有"苍龙出水"和"S级火球"混搭，除非世界观本身存在多文化碰撞的设定）
- 招式名称在首次出现时，**必须**跟一句动作描写解释这一招到底是什么——读者不可能仅凭招名自行脑补
  - 反例："他使出一招'苍龙出水'。"
  - 正例："苍龙出水：剑尖由下至上斜挑，整个人随剑势前冲，像一条从水面下翻出的龙。"

#### 3.2 招式描写的递进（三阶段）

| 阶段     | 描写方式               | 适用时机            |
| ------ | ------------------ | --------------- |
| **首现** | 全描写：招名 + 动作轨迹 + 效果 | 招式首次在作品中出现      |
| **复用** | 简描写：招名 + 效果，动作轨迹略写 | 同一招式第二次及以后使用    |
| **变招** | 半描写：招名 + 变化点 + 效果  | 同一招式在特殊情境下的变化应用 |

**正例（三阶段递进）**：

> 首现："苍龙出水：剑尖由下至上斜挑，整个人随剑势前冲，像一条从水面下翻出的龙。对方没想到他会主动近身，被这一剑逼得连退三步。"
> 
> 复用（第5章）："又是苍龙出水。这次对方已有防备，侧身让过剑尖，但他要的就是对方侧身。"
> 
> 变招（第10章，左手出剑）："左手使出的苍龙出水角度完全不同，不是斜挑而是横削，像龙甩尾而非龙出水。这一下谁也想不到。"

#### 3.3 招式描写的空间关系

每写一招，读者需要知道三个空间要素：

| 要素     | 说明         | 示例                 |
| ------ | ---------- | ------------------ |
| **起点** | 武器/身体从哪里出发 | "剑尖自下而上"           |
| **路径** | 在空间中经过的路线  | "划过一道弧线，从左侧绕到对方背后" |
| **终点** | 落点——打向哪里   | "直取后颈"             |

**三项缺一不可**——缺失任何一项，读者无法在脑中形成画面。

**反例**（空间不明）：

> 他挥剑砍向对方。

**正例**（空间清晰）：

> 他双手握剑，从右上斜劈至左下，剑锋划过一道半弧，直取对方腰间。

### 技法 4：伤势递进

**原则**：伤势不是"满血→受伤→残血"的三段跳。好的伤势描写是一根逐渐绷紧的弦——每一次受伤都在削弱角色的战斗力，而每一次削弱都反过来增加紧张感。

#### 4.1 伤势层级（累积模型）

| 层级  | 伤势特征         | 对战斗的影响         | 描写重点             |
| --- | ------------ | -------------- | ---------------- |
| L0  | 无伤           | 正常发挥           | —                |
| L1  | 擦伤/瘀伤/小口子    | 无实质影响，但暗示危险    | 痛感（刺痛/火辣）        |
| L2  | 肌肉割裂/关节扭伤    | 受影响部位动作变形、力量衰减 | 动作变形 + 痛感加剧      |
| L3  | 骨折/深度刺伤/大量出血 | 核心战力明显下降，出现失误  | 功能性丧失（"左手握不住剑了"） |
| L4  | 致命伤/意识模糊     | 战力崩溃，但可能有最后一击  | 感官变化（视野变窄/声音变远）  |

**硬约束**：

- 同一场战斗中，伤势必须逐级递进——不能从 L0 直接跳到 L3
- 每次受伤后，必须在后续动作中体现该伤势的影响——伤了左腿不能下一句就"飞身跃起"
- L4 致命伤之后，角色的任何行动必须伴随严重的身体代价描写

**正例（伤势递进完整）**：

> L0→L1："第一剑只划破了袖子。他低头看了一眼，还好，没见血。"
> 
> L1→L2："第二剑他慢了半拍，剑尖从他右前臂划过，袖口裂开，血顺着手腕流进了手心，握剑的手开始打滑。"
> 
> L2→L3："他换左手持剑，但左手的剑法远不如右手，对方看准这一点，一剑刺进他右肩。这次他听到了自己骨头裂开的声音，右手彻底抬不起来了。"
> 
> L3→L4："血已经流了太多了，视野边缘开始发黑，有些看不清了，声音也有些听不到了。
>
> 最后他只看到一道寒光向他刺来。"

#### 4.2 伤势描写的感官轮换

同一场战斗中，伤势的描写必须轮换感官通道：

| 轮次  | 感官   | 示例                     |
| --- | ---- | ---------------------- |
| 第1次 | 触觉   | "伤口火辣辣的，像是有人拿烙铁贴着皮肤"   |
| 第2次 | 视觉   | "血从指缝间渗出来，在手背上凝成暗红色的线" |
| 第3次 | 功能后果 | "他试着握拳——手指不听使唤，只弯了一半"  |
| 第4次 | 他人反应 | "对方盯着他肩上的伤口，嘴角浮起一丝笑"   |

### 技法 5：胜负转折

**原则**：一场战斗最精彩的部分不是"谁赢了"，而是"为什么会赢"。胜负的转折点应该在战斗过程中有迹可循——不是"突然爆种"，而是"早已铺垫的那根稻草终于压下来了"。

#### 5.1 转折类型

| 转折类型  | 适用场景     | 写法要点                            |
| ----- | -------- | ------------------------------- |
| 技战术转折 | 技艺差距型对决  | 前期铺垫双方技术特点 → 关键时刻一方利用对方的技术习惯/弱点 |
| 心理转折  | 心理博弈型对决  | 一方的恐惧/轻敌/急躁被对方捕捉并利用             |
| 环境转折  | 地形/天候可利用 | 一方利用环境要素（光线、地形、障碍物）改变战局         |
| 消耗转折  | 体能/耐力差异  | 前期写双方消耗的不对等 → 最后一方体力崩溃          |
| 信息转折  | 隐藏实力/底牌  | 一方前期隐藏真正的实力/招式，关键时刻暴露           |

**转折铺垫规则**：

- 转折点依赖的条件（技术弱点、环境要素、体力差距等）必须在交锋**之前或之中**至少出现过一次——不能转折时读者才第一次知道"原来他左膝有旧伤"
- 铺垫与转折之间至少隔一轮四拍循环——铺垫→继续战斗→转折，不能铺垫完立刻转折

**反例**（无铺垫转折——"爆种"）：

> 他被打得节节败退，浑身是伤。眼看就要输了，他突然大吼一声，一剑刺穿了对方的心脏。

**正例**（有铺垫转折——技术型）：

> 铺垫（前期）：对方的剑法很快，但每一次出剑之前，右肩都会先微微耸起，那是他发力的前兆。主角注意到了，但装作没看见。
> 
> 继续战斗：他又硬接了十几剑，每一剑都比上一剑更吃力。但他在等。
> 
> 转折：对方右肩一耸。这一次他没有格挡。他的剑已经提前刺向那个空当。对方的剑还在半路，他的剑尖已经抵在了对方喉咙上。

#### 5.2 胜负后的收束

战斗结束后的描写不可潦草——胜负瞬间之后的身体反应、情绪释放、环境回归，是战斗场景完整闭环的一部分：

| 收束要素 | 描写内容                              |
| ---- | --------------------------------- |
| 身体反应 | 疼痛回流、肾上腺素消退后的颤抖、虚脱                |
| 情绪释放 | 胜利后的空虚/兴奋/冷静，失败后的不甘/释然/恐惧         |
| 环境回归 | 战斗结束后重新听到的风声/鸟鸣/远处的人声——世界的其他部分回来了 |
| 对手处理 | 补刀/放过/对话——胜负之后，胜者对败者的态度定义了这个角色    |

### 技法 6：战斗中的心理博弈

**原则**：战斗不仅是身体的对抗，更是心理的博弈。两方在交手过程中的判断、试探、误判、恐惧、自信——这些心理活动是让战斗"有智商的"关键。

#### 6.1 博弈层次

| 层次  | 内容                    | 描写时机       |
| --- | --------------------- | ---------- |
| 预判  | "他要出哪一招？"——对手意图的猜测    | 对峙/喘息间隙    |
| 诱导  | "我露出破绽引他进攻"——主动制造陷阱   | 出招前（闪念）    |
| 误判  | "我以为他要攻上盘"——猜错了的后果    | 受击后（结合打击感） |
| 适应  | "他的左手比右手慢"——在战斗中学习和调整 | 喘息间隙       |

**心理描写在战斗中的篇幅占比**：

| 战斗类型     | 心理描写占比               |
| -------- | -------------------- |
| 快节奏白刃战   | ≤15%——以动作和反应为主       |
| 对峙/试探阶段  | ≤30%——此时心理活动是主要的"动作" |
| 超能力/法术对决 | ≤25%——内在消耗与策略判断      |
| 狙击/枪械对峙  | ≤50%——枪战的本质是心理博弈     |

**反例**（心理描写阻断战斗节奏）：

> 他一剑刺来。她侧身躲过的同时，脑海中闪过无数念头：这一剑的角度比上次更刁钻了，看来他在这三天里没有闲着。她想起了师傅临别时说的话：剑是手臂的延伸，但最终决定胜负的是这里，师傅用手指点了点自己的太阳穴。她深吸一口气，决定用那招……

**正例**（心理闪念——短而到位）：

> 这一剑比上次更快。
> 
> 三天。才三天，他的剑为什么快了这么多？
> 
> 她没有时间想答案。第二剑已经到了。

#### 6.2 战斗中的人物性格展现

战斗风格是角色性格的直观投射。此技能与 Core 规范 2.2（性格间接化）协同执行——战斗中禁止叙述者直接贴性格标签，而是通过角色的战斗决策和行为让读者自己判断：

| 性格特质 | 战斗中的行为表现（不是标签）                                  |
| ---- | ----------------------------------------------- |
| 沉稳   | 他等对方先出手。三招之内只守不攻，每一招都在测对方的臂长和发力习惯。              |
| 急躁   | 没等对方站稳，她已经冲出去了。第一剑劈空，第二剑角度太偏，她在第三剑才逼自己停下来。     |
| 狡猾   | 他故意把左手垂在一侧，让对方以为那条手臂废了。对方每一剑都往他左边招呼。正中下怀。      |
| 骄傲   | 他看到了那个破绽。但那太明显了，像是在求他捅进去。他偏不。他要从正面，堂堂正正地击溃这个人。 |
| 残忍   | 那一剑已经可以致命了。他没有刺下去。他往左边偏了三寸，刚好避开要害，却又刚好让痛感最大化。  |

## 与 Core 五项规范的协同矩阵

战斗场景中，Core 五项规范的适用性按以下矩阵调整（✓=强制应用 / △=酌情 / ✕=豁免 / ★=战斗专项覆盖）：

| 规范            | 冷兵器 | 徒手  | 超能力 | 枪械  | 说明                                                                |
| ------------- | --- | --- | --- | --- | ----------------------------------------------------------------- |
| 规范 1（标点正确性） | ★ | ★ | ★ | ★ | 由本技能技法 1（动作节奏控制）覆盖——战斗中标点使用规范：连续动作用逗号串联，句号仅用于换气收束 |
| 规范 1.6（破折号禁令） | ✓   | ✓   | ✓   | ✓   | 全技能不免——战斗中非声音延长的破折号一律按规则替代                                        |
| 规范 2（间接描写）    | ★   | ★   | △   | △   | 战斗中的人物外貌不做间接化要求——战斗动作本身即是"展示"；但战斗能力不可直接贴标签（如"他是天下第一快剑"），须通过战斗行为体现 |
| 规范 2.2（性格间接化） | ★   | ★   | ★   | ★   | 由本技能技法 6.2（战斗中的人物性格展现）覆盖——禁止在战斗中贴性格标签                             |
| 规范 3（风景穿插）    | ★   | ★   | ★   | ★   | 由本技能技法 1（四拍循环中的"喘息拍"）覆盖——环境切入是喘息拍的核心手段                            |
| 规范 4（对话增强）    | ✓   | ✓   | ✓   | ✓   | 战斗中的对话（指令、挑衅、嘶吼、呻吟）仍须搭配神情或动作                                      |
| 规范 5（降重率）     | ✓   | ✓   | ✓   | ✓   | 不同场次的战斗必须更换描写角度——攻击方式、受伤部位、环境利用、胜负转折类型均不可重复                       |

**豁免说明**：

- 规范 2（间接描写）在战斗场景中豁免"间接描写人物外形"的要求——战斗中的动作描写本身就是"展示而非叙述"。但人物的战斗水平不可通过叙述者直接贴标签（如"他是天下第一高手"），必须通过战斗过程和结果让读者自己得出结论。
- 此豁免不传达给成品输出校验——由本技能在步骤 4 中随数据包标注 `exempted_norms`。

## 执行步骤

### 步骤 0：确定调用来源与文本范围

**A. 由 Write-Router 调度（预分割）：**
Write-Router 已完成战斗段落识别与分割，本技能收到的数据包中 `text` 字段仅包含战斗段落。直接进入步骤 1。

**B. 用户直接触发（全文未分割）：**
用户提供完整文本（可能混合一般叙事与战斗内容）。此时需自行完成战斗内容识别与切分：

1. **逐段扫描**：以段落为单位遍历全文
2. **战斗内容判定**（逐条命中即标记）：
   - 段落中出现攻击性动作动词（斩、刺、劈、踢、击、轰、射等）+ 明确的攻击目标
   - 段落描写了攻防交替（一方出招另一方格挡/闪避）
   - 段落中出现兵器碰撞/打击音效描写
   - 段落中出现伤势/战斗状态描写
   - **不触发条件**：单纯的"比试开始""双方摆开架势"等准备性描写（无实际交锋）→ 不单独标记，视上下文判定
3. **边界合并**：两个战斗段落组之间如果仅隔 ≤2 个一般段落（如一句环境/一句心理），合并为同一战斗段落组
4. **仅处理战斗段落组**：一般段落组原样保留不修改

### 步骤 1：判定战斗类型

根据战斗内容判定类型（冷兵器/徒手/超能力/枪械/混合型），确定技法侧重（见"战斗类型识别"章节）。

如无法自动判定（如文本过短、信息不足），输出：

```
⚔️ 请确认战斗类型：
  • 冷兵器对决（刀剑枪棍等）
  • 徒手格斗（拳脚擒拿）
  • 超能力/法术对决
  • 枪械/现代兵器
  • 混合型（请简要描述）
```

### 步骤 2：读取必要上下文

**由 Write-Router 调度时**：Write-Router 已通过数据包传入 `polish_mode`（已解析卷覆盖）+ `context.volume`（当前卷号）+ `context.chapter`，跳过文件读取，直接使用传入值。

**用户直接触发时**：

1. 读取 `大纲/项目信息.json` → 提取 `volumes` 分卷信息
2. 读取 `大纲/润色配置.json` → 润色模式取用（分卷优先 → 全局回退）
3. 读取角色文件（必须）：
   - 提取战斗中涉及角色的**战斗风格**（如有）、**实力层级**（如有）、**性格**（必须）
   - 不分卷 → `大纲/人物/主要角色.md` + `次要角色.md` + `龙套角色.md`
   - 分卷多文件 → `大纲/人物/卷{N}/` 下对应文件
4. 读取 `设定.md` → 提取世界观中的战斗规则约束（如有）

### 步骤 3：按技法体系处理战斗文本

逐条过检六项战斗专项技法：

**过检顺序**：技法 1（动作节奏）→ 技法 2（打击感）→ 技法 6（心理博弈）→ 技法 3（招式体系）→ 技法 4（伤势递进）→ 技法 5（胜负转折）

**过检方式**：

1. 将战斗文本按四拍循环拆分为"出招-受击-反应-喘息"四个节拍
2. 每个节拍对照技法规则逐项检查
3. 缺失的节拍（如连续出招无喘息）→ 补充
4. 违规的描写（如打击感缺失、伤势跳级）→ 修正
5. 全部修正完成后，再次通读确认节奏流畅

#### 3.1 逐项检查清单

- **技法 1**：段落是否每段 ≤2 句？连续动作是否超过 3 句？是否每个四拍循环后都有喘息？高潮处的感叹号/问号是否独立成段？
- **技法 2**：每击是否至少覆盖触感/声音/后果中的两维？关键打击是否三维全写？同种打击后果是否不重复出现 ≥3 次？
- **技法 6**：心理描写占比是否在合理范围内（按战斗类型）？是否有预判/诱导/误判/适应中的至少两种？心理描写是否阻断动作节奏？
- **技法 3**：招式命名风格是否统一？首次出现的招式是否有动作解释？空间关系（起点/路径/终点）是否清晰？
- **技法 4**：伤势是否按层级递进（不跳级）？每次受伤后后续动作是否体现伤势影响？伤势描写是否轮换感官通道？
- **技法 5**：胜负转折是否有前期铺垫？铺垫与转折之间是否有足够的战斗过程？战斗结束后的身体反应/情绪释放/环境回归是否完整？

### 步骤 4：叠加 Core 规范（战斗矩阵过检）—— 战斗自闭环校验

战斗处理完成后，按"CORE 规范协同矩阵"逐条过检。**此步骤为战斗自闭环校验**——校验完成后成品输出校验不再重复以下战斗专项检查：

| 规范            | 过检动作                                                         |
| ------------- | ------------------------------------------------------------ |
| 规范 1（标点正确性） | 检查战斗动作是否用逗号串联为逻辑流、是否出现句号截断连续动作、问号/感叹号是否各自独立成段 |
| 规范 1.6（破折号禁令） | 全量扫描 `——` 使用——非声音延长用途的按替代表修正                                 |
| 规范 2（间接描写）    | 豁免外貌间接化要求，但检查战斗能力是否通过叙述者直接贴标签（禁止）                            |
| 规范 2.2（性格间接化） | 检查战斗中是否出现"他是一个XX的人"式叙述者贴标签（通过技法 6.2 用行为替代）                   |
| 规范 3（风景穿插）    | 检查每个四拍循环是否有喘息拍（环境切入），喘息拍是否与战斗情绪呼应                            |
| 规范 4（对话增强）    | 检查战斗中的对话是否搭配神情/动作——如"小心！"后是否跟了动作                             |
| 规范 5（降重率）     | 检查同一场战斗的攻击方式/受伤部位/环境利用是否重复使用同一角度；跨章检查同一角色战斗描写是否换感官/换技法/换转折类型 |

### 步骤 5：输出优化结果与返回协议

**输出文本**：返回处理后的战斗文本（仅战斗段落组，不含一般段落）。

**附带元数据（Core 调度时必含，用户直接触发时可省略）：**

```
{
  "combat_type": "{冷兵器 / 徒手 / 超能力 / 枪械 / 混合型}",
  "exempted_norms": ["规范2"],
  "key_changes": "{关键调整说明}",
  "combat_notes": "{战斗中需要注意的持续性问题，如某角色的伤势将在后续章节中持续影响}"
}
```

**字段说明：**

- `combat_type`：实际判定的战斗类型
- `exempted_norms`：告知 Write-Router 哪些规范已在战斗端豁免，Write-Router 整合时无需二次检查。当前仅包含「规范 2」——规范 2.2 在战斗场景中通过技法 6.2 强制执行而非豁免
- `key_changes`：对用户可读的调整摘要（补充了哪些节拍、修正了哪些节奏问题、加强了哪些打击感）
- `combat_notes`：跨章节持续性信息——如角色的伤势将在后续写作中影响其行动能力，供 Core/长篇专项参考

```
          │                                    步骤 1：判定战斗类型
          │                                    步骤 2：读取上下文
          │                                    步骤 3：按六项技法处理
          │                                    步骤 4：叠加 Core 规范过检
          │                                    步骤 5：输出 + 返回元数据
          │                                              │

                    │

                    │
                    ▼

              • 第二轮：Core 规范段落/字句结构扫描

```

**协议要点：**

- Write-Router 负责检测、分割和整合战斗内容，战斗技能负责处理战斗段落的专项优化
- 战斗技能自行完成**战斗专项校验**（步骤 4）：动作节奏、打击感、招式规范、伤势递进、胜负转折、心理博弈——这些校验不出现在成品输出校验中
- 战斗技能返回的 `combat_notes` 中包含跨章节持续性信息（如伤势影响），Write-Router 应在后续章节写作中传递给相关技能
- Write-Router 整合完成后按流水线自动调度：长篇专项（如需要伏笔登记/剧情回忆）→ 成品输出校验（标点+结构双轨）→ 落盘输出

## 注意事项

- **对决限定**：此技能仅处理人与人之间的直接对决（1v1/小团对战 ≤5人）。大场面战争（军队对冲、阵法、大规模群战）不在本技能范围内——如检测到此类内容，告知用户此技能不适用
- **非本技能范围的战斗内容**：
  - 军队/阵营大规模战争（百人以上）
  - 魔兽/怪物狩猎（除非其中包含人与类人智慧生物的单挑对决）
  - 体育竞技（除非是格斗类竞技如拳击/MMA/击剑等直接对抗）
  - 暗杀/偷袭中一击致命的场景（无往复攻防，不算"对决"）→ 由 Core 的规范 2 间接描写处理
- **人物一致性**：战斗行为必须从角色性格推导——一个怯懦的人不会在战斗中突然变得英勇无敌（除非这是经过铺垫的性格弧光转折）
- **实力层级一致**：同一角色在不同场次中的实力表现应有合理的一致性——除非实力变化有明确的情节支撑（修炼、受伤、顿悟等）
- **技法不是公式**：六项技法是指导原则，不是填表。在确保基本质量的前提下，允许根据具体场景灵活调整
- **始终以 Markdown 格式输出**文本内容
