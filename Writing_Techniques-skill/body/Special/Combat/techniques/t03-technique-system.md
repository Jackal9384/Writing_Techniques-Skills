# 技法 t03：招式体系规范

**适用**：冷兵器 / 超能力 / 混合型（`techniques/index.json` → `groups` 映射）

**原则**：招式命名与描写必须在世界观框架内保持自洽。招式不是越华丽越好——好的招式体系让读者能"看见"这一招是怎么打的。

## 招式命名规范

| 命名风格   | 适用世界观     | 示例                        |
| ------ | --------- | ------------------------- |
| 动作描述型  | 写实武侠/历史格斗 | "进步直刺""缠头裹脑""转身鞭拳"        |
| 意象型    | 东方玄幻/武侠   | "苍龙出水""落花拂柳""怒涛三叠"        |
| 功能型    | 西方奇幻/超能力  | "火球术·压缩""风刃·连斩""暗影步"      |
| 编号/等级型 | 学院/军事/系统流 | "基础剑术·第七式""S级雷击""战术动作-03" |

**命名约束**：

- 同一世界观中，招式命名风格必须统一（不能同时有"苍龙出水"和"S级火球"混搭，除非世界观本身存在多文化碰撞的设定）
- 招式名称在首次出现时，**必须**跟一句动作描写解释这一招到底是什么——读者不可能仅凭招名自行脑补
  - 反例："他使出一招'苍龙出水'。"
  - 正例："苍龙出水：剑尖由下至上斜挑，整个人随剑势前冲，像一条从水面下翻出的龙。"

## 招式描写的递进（三阶段）

| 阶段     | 描写方式               | 适用时机            |
| ------ | ------------------ | --------------- |
| **首现** | 全描写：招名 + 动作轨迹 + 效果 | 招式首次在作品中出现      |
| **复用** | 简描写：招名 + 效果，动作轨迹略写 | 同一招式第二次及以后使用    |
| **变招** | 半描写：招名 + 变化点 + 效果  | 同一招式在特殊情境下的变化应用 |

**正例（三阶段递进）**：

> 首现："苍龙出水：剑尖由下至上斜挑，整个人随剑势前冲，像一条从水面下翻出的龙。对方没想到他会主动近身，被这一剑逼得连退三步。"
> 
> 复用（第5章）："又是苍龙出水。这次对方已有防备，侧身让过剑尖，但他要的就是对方侧身。"
> 
> 变招（第10章，左手出剑）："左手使出的苍龙出水角度完全不同，不是斜挑而是横削，像龙甩尾而非龙出水。这一下谁也想不到。"

## 招式描写的空间关系

每写一招，读者需要知道三个空间要素：

| 要素     | 说明         | 示例                 |
| ------ | ---------- | ------------------ |
| **起点** | 武器/身体从哪里出发 | "剑尖自下而上"           |
| **路径** | 在空间中经过的路线  | "划过一道弧线，从左侧绕到对方背后" |
| **终点** | 落点——打向哪里   | "直取后颈"             |

**三项缺一不可**——缺失任何一项，读者无法在脑中形成画面。

**反例**（空间不明）：

> 他挥剑砍向对方。

**正例**（空间清晰）：

> 他双手握剑，从右上斜劈至左下，剑锋划过一道半弧，直取对方腰间。
