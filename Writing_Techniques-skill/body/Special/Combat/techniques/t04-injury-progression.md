# 技法 t04：伤势递进

**适用**：徒手 / 混合型（`techniques/index.json` → `groups` 映射）

**原则**：伤势不是"满血→受伤→残血"的三段跳。好的伤势描写是一根逐渐绷紧的弦——每一次受伤都在削弱角色的战斗力，而每一次削弱都反过来增加紧张感。

## 伤势层级（累积模型）

| 层级  | 伤势特征         | 对战斗的影响         | 描写重点             |
| --- | ------------ | -------------- | ---------------- |
| L0  | 无伤           | 正常发挥           | —                |
| L1  | 擦伤/瘀伤/小口子    | 无实质影响，但暗示危险    | 痛感（刺痛/火辣）        |
| L2  | 肌肉割裂/关节扭伤    | 受影响部位动作变形、力量衰减 | 动作变形 + 痛感加剧      |
| L3  | 骨折/深度刺伤/大量出血 | 核心战力明显下降，出现失误  | 功能性丧失（"左手握不住剑了"） |
| L4  | 致命伤/意识模糊     | 战力崩溃，但可能有最后一击  | 感官变化（视野变窄/声音变远）  |

**硬约束**：

- 同一场战斗中，伤势必须逐级递进——不能从 L0 直接跳到 L3
- 每次受伤后，必须在后续动作中体现该伤势的影响——伤了左腿不能下一句就"飞身跃起"
- L4 致命伤之后，角色的任何行动必须伴随严重的身体代价描写

**正例（伤势递进完整）**：

> L0→L1："第一剑只划破了袖子。他低头看了一眼，还好，没见血。"
> 
> L1→L2："第二剑他慢了半拍，剑尖从他右前臂划过，袖口裂开，血顺着手腕流进了手心，握剑的手开始打滑。"
> 
> L2→L3："他换左手持剑，但左手的剑法远不如右手，对方看准这一点，一剑刺进他右肩。这次他听到了自己骨头裂开的声音，右手彻底抬不起来了。"
> 
> L3→L4："血已经流了太多了，视野边缘开始发黑，有些看不清了，声音也有些听不到了。
>
> 最后他只看到一道寒光向他刺来。"

## 伤势描写的感官轮换

同一场战斗中，伤势的描写必须轮换感官通道：

| 轮次  | 感官   | 示例                     |
| --- | ---- | ---------------------- |
| 第1次 | 触觉   | "伤口火辣辣的，像是有人拿烙铁贴着皮肤"   |
| 第2次 | 视觉   | "血从指缝间渗出来，在手背上凝成暗红色的线" |
| 第3次 | 功能后果 | "他试着握拳——手指不听使唤，只弯了一半"  |
| 第4次 | 他人反应 | "对方盯着他肩上的伤口，嘴角浮起一丝笑"   |
