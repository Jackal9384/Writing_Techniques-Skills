# 技法 t02：打击感描写

**适用**：全部战斗类型（`techniques/index.json` → `groups` 映射）

**原则**：战斗的核心是"打到"——读者需要感受到每一击的力量、速度、和后果。打击感来自三个维度的叠加：触感 + 声音 + 后果。

**三维打击感模型**：

| 维度     | 描写内容                  | 示例                   |
| ------ | --------------------- | -------------------- |
| **触感** | 击中瞬间的感觉：震动、温度、硬度、疼痛级别 | "虎口一麻，剑险些脱手"         |
| **声音** | 击中发出的声音：骨骼、金属、肉体      | "砰的一声闷响，像是木棍砸在湿泥上"   |
| **后果** | 击中后的即时效果：伤口、位移、动作变形   | "他往后踉跄了两步，左臂已经抬不起来了" |

**打击感层级**（由轻到重）：

| 层级  | 伤害程度     | 描写重点         | 示例                               |
| --- | -------- | ------------ | -------------------------------- |
| 轻击  | 擦伤/瘀伤    | 触感为主，声音为辅    | "剑尖擦过手背，留下一道白印，随即渗出血珠"           |
| 中击  | 割裂/骨折/内伤 | 触感+声音并重      | "那一拳砸在肋骨上——咔嚓一声，他自己都听到了"         |
| 重击  | 致命/断肢/击飞 | 声音+后果为主，触感为辅 | "剑锋没入胸口时几乎没有声音。拔出来的时候才有，就像是开红酒。" |

**反例**（无打击感——只写动作不写效果）：

> 他一拳打过去，对方躲开了。他又踢了一脚，这次踢中了。对方退了两步。

**正例**（三维打击感）：

> 那一拳擦过他耳畔，拳风刮得耳廓生疼。
> 
> 他没等对方收拳，一脚蹬在对方的小腹上。
> 
> 那人弯下腰，捂着肚子退了三步，每一步都带着一声闷咳。

**打击感描写的频率控制**：

- 每一击至少覆盖三维中的两维
- 关键打击（改变战局的一击）三维全写
- 非关键击打（试探、佯攻）至少写一维
- 同一场战斗中，同一种打击后果（如"后退两步"）不重复使用超过两次——换后果类型（"手臂发麻""膝盖一软""视野一黑"）
