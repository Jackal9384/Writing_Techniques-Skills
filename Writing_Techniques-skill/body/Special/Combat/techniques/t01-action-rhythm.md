# 技法 t01：动作节奏控制

**适用**：冷兵器 / 徒手 / 枪械 / 混合型（`techniques/index.json` → `groups` 映射）

**原则**：战斗段落的节奏由"出招↔受击↔反应↔喘息"四拍构成。长段连续动作必须穿插短暂的停顿（呼吸、对峙、环境切入），让读者有时间"看见"每一击。

**四拍循环模型**：

```
出招（谁、用什么、打向哪里）
  → 受击（打中与否、打在哪里、什么效果）
    → 反应（受击者的身体反应 + 心理闪念）
      → 喘息（间隙——环境/呼吸/对峙/状态评估）
        → 下一轮出招…
```

**硬约束**：

- 连续动作描写（出招→击中→效果→追击）属同一逻辑链，应用逗号串联为一个完整的自然段，而非用句号截断为碎片
- 每轮四拍循环完成后，必须有一个"喘息拍"——可以是环境切入、呼吸描写、旁观者反应、或短暂对峙
- 战斗白热化阶段（决定性一击前后），喘息拍可缩减但不能完全取消——完全取消会导致动作堆叠、读者无法跟上节奏

**正例**（四拍循环完整）：

> 他一剑斜劈，剑锋直取对方左肩。
> 
> 剑刃切进皮肉的一瞬，对方闷哼了一声。
> 
> 血从裂开的袖口渗出来，顺着手肘往下滴。那人低头看了看伤口，又抬头看他。眼神变了。
> 
> 巷口的风灌进来，吹得灯笼晃了两晃。
> 
> 下一剑来得更快。这次是咽喉。

**反例**（动作堆叠、无喘息）：

> 他一剑劈下对方挡住反手又是一剑刺向胸口对方侧身躲过剑锋擦过衣襟他再进步横扫对方跃起躲开落地时一脚踢向他手腕……

**段落节奏在战斗中的特殊处理**：

Core 规范 1（标点正确性）在战斗场景中的具体应用：

| 战斗阶段 | 节奏特征 | 标点指引 |
|---------|---------|---------|
| 对峙/蓄势 | 紧张感由短段制造，段落偏短但不强制 | 静态描写可一句一段；句号用于收束对峙状态 |
| 交锋 | 出招+受击属同一逻辑链，逗号串联 | 一击→效果→反应为一个自然句，用逗号连接；句号仅在换气/拆段时使用 |
| 连击/压制 | 快速连续动作，逗号串联为一气呵成的长段 | 大量使用逗号连接击打动作；在连击结束时用句号收束 |
| 喘息/间隙 | 环境/呼吸/状态评估，节奏放缓 | 正常使用句号形成明确的"暂停感" |
| 决胜一击 | 视觉冲击力最强，独立成段 | 前后空行制造视觉停顿，段落本身可长可短 |

核心原则：连续的战斗动作（出招→击中→反应→下一个动作）属于同一逻辑链，应用逗号串联，而非用句号将其截断为碎片。一段极长的连续交锋描写，只要逗号使用正确、逻辑流转清晰，是完全合规的。

**禁止**：战斗中感叹号/问号链接。高潮处的"啊——""什么？！"等必须独立成段。
