# 技法 w04：切片组合规则（以小见大核心）

**适用**：warfare 组（`techniques/index.json` → `groups.warfare`）

**核心**：战争的写法以小见大——指挥部讲解战线、参谋部制定计划、一线单位获得命令等多个场景切片组合起来，营造大场面的氛围。**没有切片能单独代表整场战争，组合才能。**

**写作要点**：

- **切片选择**：每个切片代表一个层级视角——指挥部（全局）/ 参谋部（计划）/ 一线单位（执行）——至少两个层级组合，大场面感才成立
- **组合顺序**：常见节奏——先全局（指挥部战况）→ 中景（参谋部计划）→ 微观（一线执行）；也可按时间穿插（计划章 → 执行章 → 战况章）
- **切片间衔接**：同一时间轴上的不同空间，用战况信息串联（指挥部收到"西线陷落"的消息时，读者已在一线看过西线怎么陷的）
- **篇幅分配**：指挥部/参谋部切片短（信息载体），一线切片长（读者代入）——比例大约 1:2:3 起
- **切片不必写满**：2-3 个切片足以营造大场面——战争是多章长镜头，切片分散在多章中，单章内不必齐
- **统一的时间锚点**：各切片共享同一个战役时间（"总攻第三日"），读者靠时间锚点拼出全景

**反例**（单一视角 + 无组合）：

> 双方大军在山谷中展开决战，喊杀声震天，血流成河，尸横遍野。我军奋勇冲杀，敌军节节败退，最终大获全胜。

**正例**（三切片组合示意）：

> 指挥部（短）："东军前锋已过河。"将军盯着沙盘，半晌没说话。
> 
> 参谋部（中）：推演棋子在河道拐弯处停了一夜。绕，还是赌？天亮时，棋子上多了一面小旗。
> 
> 一线（长）：赵七接到命令时天还没亮。撤到河西——他回头看了一眼那片黑沉沉的河谷，把家信往怀里按了按。

**软引导**：本技法定义切片的组合逻辑，不规定切片数量与顺序——按章节内容自然选择，不拦截不强制。
