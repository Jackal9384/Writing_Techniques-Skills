# 技法 w01：指挥部场景（全局视角切片）

**适用**：warfare 组（`techniques/index.json` → `groups.warfare`）

**核心**：通过指挥部场景呈现全局——将领讲解战线位置、情报汇总、态势判断。指挥部是读者俯瞰战场的"眼睛"，以小场景承载大信息量。

**写作要点**：

- **地图/沙盘具象化**：战线不是抽象名词，而是地图上的线、沙盘上的旗、报告里的地名——"左翼推进到河谷，右翼卡在青石关"比"我军推进顺利"可看见
- **对话驱动讲解**：将领讲解战线位置时，用对话而非旁白叙述（"西线三个军已经压上去了""南边那支人马不是我们的"）——讲解者的语气带出局势紧迫/从容
- **数字落地为画面**：兵力/伤亡数字必须通过具体画面呈现（"三营打光了，旗子还插在山头上"），不得纯数据汇报
- **时间压力**：军情急报、使者闯入、时限将至——指挥部场景天然带"决策时间窗"
- **视角限制**：指挥部的人只知道情报层面的战况，不知道一线的真实情况——为计划-现实落差（w05）留缝

**反例**（纯数据汇报，无画面）：

> 敌军第3集团军约两万人，我军第一军伤亡率约30%，弹药库存不足四成，建议后撤至第三道防线。

**正例**（地图画面 + 对话讲解）：

> 沙盘上，代表东军的黑色小旗插满了河谷两岸。将军用指挥棒点了点其中一面："这是他们的前锋，今天早上过了桥。"
> 
> "我们的人呢？"
> 
> "三营。"副将的声音低了下去，"旗还插在山上。"

**软引导**：战争场景大多是多章长镜头——本技法只提供指挥部切片的写法参考，不拦截、不强制每章必有指挥部。
