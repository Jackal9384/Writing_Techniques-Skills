# 技法 w06：战中个体时刻（引用 Combat 主项）

**适用**：warfare 组（`techniques/index.json` → `groups.warfare`）

**核心**：战争中的个体对决/英雄时刻——大场面中的"人"。个体对决是战争叙事的局部放大镜头，不改变全局但定格读者印象。

**写作要点**：

- **引用主项技法**：战争中出现个体对决/单挑/英雄时刻时，战斗细节写法引用 Combat 主项技法（t01 动作节奏 / t02 打击感 / t03 招式体系 / t04 伤势递进 / t05 胜负转折 / t06 心理博弈）——warfare 组不重复战斗细节规则
- **个体时刻的战争语境**：单挑发生在战乱中（阵前叫阵、遭遇战、突围战）——战争语境给单挑额外的重量（身后是败局或全军的目光）
- **个体时刻的代价**：英雄时刻不免费——一个英雄的倒下、胜利背后的损耗、战后无人记得的名字——个体时刻要带出战争的代价底色
- **时长的克制**：战争中个体时刻是"切片里的切片"，篇幅短于正常单挑——周围还有整场战争在进行（远处喊杀声不断）

**反例**（战争中插入完整竞技式单挑，与战局脱节）：

> 两军混战中，陈武与敌将姜亥相遇，两人列开架势，你来我往大战三百回合，围观众人纷纷喝彩……（战斗结束后战场自动让出空地）

**正例**（战争语境中的短促个体时刻）：

> 赵七看见对面那个扛旗的年轻人在人群里跌倒了三次，又爬起来三次。
> 
> 第四次跌倒的时候，赵七冲了过去。
> 
> 他没有时间想招式——冲、撞、按、夺。旗杆到手的时候，他的虎口已经震裂了，血顺着旗杆往下淌。
> 
> 远处，谁喊了一声什么。他没有听清。

**软引导**：个体时刻是否出现、出现几次，由章节内容自然决定——不强制每场战争都有单挑。
