# 技法 w05：计划-现实落差（变数）

**适用**：warfare 组（`techniques/index.json` → `groups.warfare`）

**核心**：作战计划 vs 战场现实的偏离——天气、地形、敌方变数、执行失误。计划越详细，落差越有冲击力；落差是战争"不可控感"的来源。

**写作要点**：

- **落差要呼应计划**：前面参谋部切片（w02）明确写过的计划要素，在落差发生时被打破——"绕三十里多走一天"的计划，败在第三天的暴雨
- **落差的呈现路径**：一线传回的坏消息 → 指挥部预期的崩塌 → 指挥官的反应（调整/固执/崩溃）——信息从一线向高层传递的路径本身就是戏
- **指挥官反应**：调整计划（有能之人）、固执执行（代价）、崩溃失态（人性）——落差点是战争人物弧光的位置
- **落差不只是坏消息**：也可以是意外之喜（敌方援军没来、天气帮了忙）——但喜通常短暂，随后是更大的变数
- **多次落差递进**：大战役中落差可以多次出现，一次比一次大——最终战局走向与计划完全不同的结局

**反例**（无铺垫的意外）：

> 总攻进行到一半，突然下起了大雨，道路泥泞，进攻受阻。指挥官决定停止进攻。

**正例**（呼应计划的落差）：

> 参谋部算过——绕三十里，多走一天，粮草刚好撑到河西。
> 
> 第三天的雨下了整整一夜。河滩的淤泥没过小腿，骡马陷在泥里嘶鸣，粮车动弹不得。
> 
> 赵七站在队伍里，听见前面传回来的话越来越短，越来越快。
> 
> 最后一句是："不绕了。"

**软引导**：落差是战争叙事的可选张力来源——需要时使用，不强制每场战争都有计划与落差结构。
