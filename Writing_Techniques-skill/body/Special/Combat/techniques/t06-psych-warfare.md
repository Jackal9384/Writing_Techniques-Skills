# 技法 t06：心理博弈

**适用**：徒手 / 超能力 / 枪械 / 混合型（`techniques/index.json` → `groups` 映射）

**原则**：战斗不仅是身体的对抗，更是心理的博弈。两方在交手过程中的判断、试探、误判、恐惧、自信——这些心理活动是让战斗"有智商的"关键。

## 博弈层次

| 层次  | 内容                    | 描写时机       |
| --- | --------------------- | ---------- |
| 预判  | "他要出哪一招？"——对手意图的猜测    | 对峙/喘息间隙    |
| 诱导  | "我露出破绽引他进攻"——主动制造陷阱   | 出招前（闪念）    |
| 误判  | "我以为他要攻上盘"——猜错了的后果    | 受击后（结合打击感） |
| 适应  | "他的左手比右手慢"——在战斗中学习和调整 | 喘息间隙       |

**心理描写在战斗中的篇幅占比**：

| 战斗类型     | 心理描写占比               |
| -------- | -------------------- |
| 快节奏白刃战   | ≤15%——以动作和反应为主       |
| 对峙/试探阶段  | ≤30%——此时心理活动是主要的"动作" |
| 超能力/法术对决 | ≤25%——内在消耗与策略判断      |
| 狙击/枪械对峙  | ≤50%——枪战的本质是心理博弈     |

**反例**（心理描写阻断战斗节奏）：

> 他一剑刺来。她侧身躲过的同时，脑海中闪过无数念头：这一剑的角度比上次更刁钻了，看来他在这三天里没有闲着。她想起了师傅临别时说的话：剑是手臂的延伸，但最终决定胜负的是这里，师傅用手指点了点自己的太阳穴。她深吸一口气，决定用那招……

**正例**（心理闪念——短而到位）：

> 这一剑比上次更快。
> 
> 三天。才三天，他的剑为什么快了这么多？
> 
> 她没有时间想答案。第二剑已经到了。

## 战斗中的人物性格展现

战斗风格是角色性格的直观投射。此技能与 Core 规范 2.2（性格间接化）协同执行——战斗中禁止叙述者直接贴性格标签，而是通过角色的战斗决策和行为让读者自己判断：

| 性格特质 | 战斗中的行为表现（不是标签）                                  |
| ---- | ----------------------------------------------- |
| 沉稳   | 他等对方先出手。三招之内只守不攻，每一招都在测对方的臂长和发力习惯。              |
| 急躁   | 没等对方站稳，她已经冲出去了。第一剑劈空，第二剑角度太偏，她在第三剑才逼自己停下来。     |
| 狡猾   | 他故意把左手垂在一侧，让对方以为那条手臂废了。对方每一剑都往他左边招呼。正中下怀。      |
| 骄傲   | 他看到了那个破绽。但那太明显了，像是在求他捅进去。他偏不。他要从正面，堂堂正正地击溃这个人。 |
| 残忍   | 那一剑已经可以致命了。他没有刺下去。他往左边偏了三寸，刚好避开要害，却又刚好让痛感最大化。  |
