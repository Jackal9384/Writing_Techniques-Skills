# 校验维度六：叙事质量（增强维度）

维度〇-五管"对错"（防错），本维度管"好坏"（防短浅无波动）。规则数据见 `data/plot-wave-spec.json`（张力等级/四要素/冲突双类型/悬念/代价豁免定义）。

## 规则 6.1：波动曲线（软引导——不满足不拦截，仅输出波动建议）

按 `plot-wave-spec.json` → `wave_guidance` 检查阶段张力序列：

- 相邻阶段张力差 ≥1（连续同张力 → 建议"该阶段与上一阶段张力持平，可考虑升温或留白"）
- 全本至少 2 个波峰（L4+）→ 不足时建议补转折/大事件
- 波峰阶段包含代价事件 → 缺失时建议添加
- 低谷阶段埋新伏笔 → 缺失时建议（与 foreshadowing 联动）

**软引导性质**：输出"波动建议"标注即可，不进入违规处理流程（防止硬约束逼迫 LLM 复用素材）。

## 规则 6.2：剧情点四要素（强制——辅助/自动生成必填，手动校验必查）

每个剧情点必须携带四要素，缺一不可：

| 要素 | 定义 | 缺失处理 |
|------|------|---------|
| 冲突 | 谁与谁的对抗（人物/环境/内心）——无冲突的剧情点 = 无效点 | 标记缺失（强制） |
| 代价 | 达成/推进目标付出的代价（失去/受伤/妥协/道德污点） | 连续 2 个剧情点无代价 → 违规 |
| 变化 | 该点之后人物状态/关系/世界状态的不可逆变化 | 转折点无变化 → 违规 |
| 悬念 | 该点埋下或回收的悬念（与伏笔体系联动） | 整阶段无悬念 → 违规 |

## 规则 6.3：冲突双类型（有伏笔 / 无伏笔）

冲突分为两类，各司其职（定义见 `plot-wave-spec.json` → `conflict_types`）：

- **有伏笔冲突**：由既有伏笔/前期线索引发的冲突——兑现伏笔、深度感、因果闭环（联动 long-skill 的 foreshadowing）
- **无伏笔冲突**：直接对抗/突发事件（无预埋）——打破预期、节奏变量

约束：
- **每阶段至少 1 个有伏笔冲突**（四要素"冲突"标注类型，缺则违规）——强制
- 无伏笔冲突不得连续 ≥3 阶段主导（防"事故流水账"）——软引导

## 规则 6.4：悬念密度

- 每阶段 ≥1 悬念（埋或收）
- 全书伏笔有去有回（沿用 long-skill foreshadowing 诊断——未回收 ≥5 条或跨越 ≥10 章提醒）

## 规则 6.5：代价平衡（豁免机制）

- **默认强制代价**：主角的成长/胜利必须伴随代价（失去/受伤/妥协/道德污点）
- **豁免**：用户明确声明"爽文/无代价"偏好时豁免——记录于项目信息或写作偏好库（`user_style_enabled` 启用时优先读写作偏好）
