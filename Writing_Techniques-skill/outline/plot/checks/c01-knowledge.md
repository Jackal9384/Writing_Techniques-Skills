# 校验维度一：知识边界

角色的认知必须限制在其可合理知晓的范围内。

## 规则 1.1：信息来源可追溯

角色知晓的任何信息，必须存在合理的获取途径。逐一检查每个剧情点中角色表现出的"认知"：

| 信息获取途径 | 判定条件 | 示例 |
|------------|---------|------|
| 亲眼所见 | 角色在事件现场 | ✓ 角色在门外看到了凶手的面孔 |
| 亲耳所闻 | 角色在可听范围内 | ✓ 角色在隔壁听到了争吵内容 |
| 他人告知 | 知情角色与该角色有交流场景 | ✓ 角色B事后告诉了角色A |
| 书信/物证 | 存在传递或发现的场景 | ✓ 角色发现了抽屉里的信件 |
| 推理得出 | 角色掌握推理所需的全部线索 | ✓ 角色根据已有线索推断出真相 |
| 公开信息 | 事件为众所周知 | ✓ 全城都在讨论的新闻 |

**违规示例**：

> ✕ 李四独自在密室里销毁了证据，没有任何人看见。第三章张三却准确指认"李四那天在密室里烧了一封信"。
> → 张三没有合理的获知途径。需补充：有人在密室附近看到了李四进出 / 灰烬被他人发现 / 张三通过推理串联了碎片信息。

## 规则 1.2：秘密边界

被角色刻意隐藏、或仅在极少数人之间发生的事件，应标记为"秘密"。后续剧情中若其他角色表现出知晓该秘密，必须校验：

1. 秘密的知情圈有哪些人？
2. 当前角色是否在知情圈内？
3. 若不在 → 是否有合理的信息泄露路径？
4. 若无泄露路径 → **违规**，角色不应知晓

**校验输入补充（模板库 V1.0）**：角色条目中的「隐藏设定」字段（`templates/character.schema.json` 定义）是秘密的结构化来源——该字段描述的秘密/身世/动机，知情圈默认仅限角色本人（或字段内声明的知情者）；剧情中其他角色知晓该隐藏设定时，必须按上述 1-4 步校验。隐藏设定同时已由创建人物技能预登记为 `foreshadowing` 伏笔（见长篇专项「人物伏笔预登记」），可交叉校验回收时机。

## 规则 1.3：时空在场约束

- 角色不能同时出现在两个不同地点
- 角色不能知晓未来发生的事件
- 角色不能恰好出现在每一个关键对话的"门外"——累计 ≥3 次巧合在场，标记为"过度巧合"并警告
