# 设定编辑

此技能用于辅助用户进行作品设定的全方位编辑，支持从"新书"技能创建的 `设定.md` 出发，对各板块逐一引导填写。

## 关联文件

按以下优先级定位设定文件：

1. 当前工作目录下 `大纲/设定/设定.md`（由"新书"技能创建）
2. 当前工作目录下 `outline/settings/settings.md`（English 路径）
3. 用户手动指定的路径
4. 若以上均不存在，提示用户先运行"新书"技能创建项目

## 设定模板

最终的设定文件应遵循以下结构（`[]` 为必填，`{}` 为说明）：

```markdown
# {书名} — 作品设定

> 最后更新：{YYYY年MM月DD日}

## 基本信息

- **书名**：{书名}
- **传播范围**：{传播向 / 个人向}
- **内容分级**：{一般向 / NSFW}
- **篇幅长度**：{随笔 / 短篇 / 短篇（连载） / 中篇 / 长篇}
- **书籍种类**：{用户填写的种类}

---

## 简介

{对外展示的作品简介或自己对作品的基本描述，可同时存在}

### 对外简介

{面向读者的宣传简介}

### 个人描述

{作者自己对作品的理解和定位}

---

### 核心设定 [必选]

{包含会出场的人物、世界、故事走向的基本描述}

**人物**：{主要出场人物及角色定位}

**世界**：{世界观一句话概括}

**故事走向**：{主线故事的基本方向和核心冲突}

---

### 世界观 [必选]

{描述这个世界的方方面面。以下各项使用加粗标题，不使用 ### 或更深标题，保持大纲等级 ≤2}

**{分类项1}**：
{内容}

---

**{分类项2}**：
{内容}

---

### 次要设定 [可选]

{分类收纳其他次要设定，便于人类查看和后续扩展}

#### {分类1}

{内容}

#### {分类2}

{内容}
```

## 模板规则

- **基本信息**：与"新书"技能关联，若项目由新书技能创建则直接读取已有信息
- **简介**：可同时保留"对外简介"和"个人描述"，用户可选择只填一个
- **核心设定**：必须填写，不可跳过。至少需要人物、世界、故事走向三要素
- **世界观**：必须填写。所有子项大标题使用 `**{项}**：` 加粗格式，不使用 `###` / `####` 标题，保持在 ≤ h3 结构层级下
- **次要设定**：完全可选，用户不需要时可注明"暂不填写"并跳过

## 工作流程

### 步骤 0：定位并读取设定文件

1. 按关联文件优先级查找设定文件
2. 若找到，读取全部内容，进入步骤 1
3. 若未找到，询问用户：
   > 未找到已有的设定文件。要怎么做？
   > • 在当前目录创建新设定文件
   > • 指定已有设定文件的路径
   > • 先创建新书项目（调用"新书"技能）
4. 若选择创建新文件，以当前工作目录名或用户指定的书名为准，新建 `设定.md`

### 步骤 1：展示状态并询问编辑目标

读取文件后，向用户展示各板块完成情况：

> 📋 「{书名}」设定状态：
>   • 基本信息 — ✅ 已填写 / ⬜ 待填写
>   • 简介 — ✅ 已填写 / ⬜ 待填写
>   • 核心设定 — ✅ 已填写 / ⬜ 待填写 🔴必选
>   • 世界观 — ✅ 已填写 / ⬜ 待填写 🔴必选
>   • 次要设定 — ✅ 已填写 / ⬜ 待填写 ⭕可选
>
> 你想编辑哪个部分？可输入编号或名称，如"全部"则按顺序逐一引导。

### 步骤 2：按板块引导编辑

根据用户选择，逐一引导。每次只处理一个板块，完成后回到选择界面（除非用户选了"全部"连续模式）。

#### 2.1 编辑基本信息

若信息来自"新书"技能，先展示已有内容：

> 📌 当前基本信息：
>   • 书名：{值}  • 传播范围：{值}  • 内容分级：{值}
>   • 篇幅长度：{值}  • 书籍种类：{值}
>
> 需要修改哪一项？输入项名或"全部"逐项修改，或"跳过"维持现状。

逐项修改：书名 → 传播范围 → 内容分级 → 篇幅长度 → 书籍种类。

- 传播范围选项：`传播向` / `个人向`
- 内容分级：默认`一般向`，仅用户主动提及时可改为 `NSFW`
- 篇幅长度选项：`随笔（＜5万字）` / `短篇（≤20万字）` / `短篇连载（≤35万字）` / `中篇（≤60万字）` / `长篇（＞60万字）`
- 书籍种类：自由输入

修改完成后更新基本信息列表。

#### 2.2 编辑简介

简介支持双轨：对外简介（读者面向）和个人描述（作者面向）。逐一询问：

1. **对外简介**：先问「是否需要填写对外简介（面向读者的宣传语）？」若需要，让用户自由输入
2. **个人描述**：再问「是否需要填写个人描述（你自己对这本书的理解）？」若需要，让用户自由输入

至少填写一个。若两个都跳过，在对外简介处写入 `（待填写）`。

#### 2.3 编辑核心设定 [必选]

核心设定是必填项，至少包含三个要素。逐一提问，用户可自由输入或选择跳过单项（但三项不能全空）：

1. **人物**：
   > 👤 核心人物 — 请描述主要出场人物及其角色定位。
   > （例如：主角是XXX，配角包括YYY，反派为ZZZ）

2. **世界**：
   > 🌍 世界概括 — 请用一两句话概括这个世界的基本设定。
   > （例如：一个魔法与科技并存的近未来都市）

3. **故事走向**：
   > 📖 故事走向 — 请描述主线故事的基本方向和核心冲突。
   > （例如：主角从平凡到伟大的成长之路，最终对抗XXX势力）

每项填写后即时更新。若用户三项全空，提醒"核心设定为必选，至少概括性填写一项"，并要求至少补填一项。

#### 2.4 编辑世界观 [必选]

世界观是必填项，由多个分类子项组成。整体结构为：

```
### 世界观

**{分类项}**：
{内容}

---

**{分类项}**：
{内容}
```

编辑流程：

1. 展示当前已有世界观分类项列表（如有）
2. 询问用户：
   > 🌌 世界观编辑 — 请选择操作：
   > • 添加新分类 — 新增一个世界观子项
   > • 修改已有 — 修改某个已有分类的内容
   > • 删除分类 — 删除某个已有分类
   > • 完成 — 世界观部分暂定，回到板块选择

3. **添加新分类**：先问分类名称（如"地理"、"魔法体系"、"政治格局"等），再让用户自由输入内容。可连续添加多个。
4. **修改已有**：列出已有分类，用户选择后重新输入内容
5. **删除分类**：列出已有分类，确认后删除

世界观至少需要 **一个分类项**（必选约束）。

所有子项使用 `**{分类名}**：` 格式（大纲等级 ≤2，即不加 `###` 等标题符号）。

条目之间使用 `---` 分割。

#### 2.5 编辑次要设定 [可选]

次要设定完全可选，结构类似世界观但使用 `####` 小标题分类：

1. 询问用户：「是否需要填写次要设定？」若不需要，写入 `（暂不填写）` 并跳过
2. 若需要，按分类管理：添加 → 修改 → 删除 → 完成的循环，与世界观编辑一致
3. 次要设定分类示例：道具设定、组织设定、历史年表、文化习俗等

#### 2.6 润色加工（贯穿全流程）

每次用户输入内容后，遵循项目润色配置：

1. 检查 `大纲/润色配置.json`（或 `outline/polish-config.json`）
2. 根据 `polish_mode` 值决定加工深度：
   - `轻度`：保留用户原话，仅规范书面表达
   - `中度`：小幅优化（改动 ≤45%），适度润色
   - `重度`：仅保留原意，完全改写扩写
3. 若未找到润色配置文件，默认采用**轻度**模式
4. 润色后向用户展示修改结果，并询问「这样可以吗？」确认后再写入

### 步骤 3：保存文件

每次板块编辑完成后即时保存至设定文件，防止数据丢失。

保存后简要反馈：`✅「{板块名}」已更新至 {文件路径}`

### 步骤 4：完成确认

全部编辑完成后，输出设定摘要：

> ✅ 作品设定编辑完成！
>
> 📋 「{书名}」设定总览：
>   • 基本信息：{书名} / {传播范围} / {篇幅长度} / {种类}
>   • 简介：{对外简介前30字}...
>   • 核心设定：人物 {N} 位 / 世界概括 / 故事走向
>   • 世界观分类：{分类列表}
>   • 次要设定：{分类列表 或 未填写}
>
> 需要进一步调整哪个部分？或者要完善其他大纲内容？

## 其他规则

- 用户随时可说"回到板块选择"或"换一个"返回步骤 1
- 用户可随时指定跳转到任意板块（如"直接编辑世界观"）
- 保持友好、引导式的语气，每次只问一个问题
- 必选板块（核心设定、世界观）不允许完全空白，至少需有占位内容
- 若用户长时间不操作，可简要提醒当前进度
- 若基本信息中书名未知，优先在步骤 2.1 中询问
- 文件路径中的特殊字符自动处理（`/` `\` `:` `*` `?` `"` `<` `>` `|` 替换为 `_`）
