# 设定编辑

此技能用于辅助用户进行作品设定的全方位编辑，支持从"新书"技能创建的 `设定.md` 出发，对各板块逐一引导填写。

## 核心定位

- **板块驱动编辑**：将作品设定拆为基本信息/简介/核心设定/世界观/次要设定五个板块，每次只处理一个，编辑完成后即时写回文件
- **计划模式入口**：所有操作必须先进入计划模式（EnterPlanMode），列出各板块当前完成状态与编辑目标，用户批准后执行
- **多源数据感知**：自动读取 `项目信息.json` 获取书名/分级/NSFW 偏好，读取 `润色配置.json` 确定加工深度，不重复询问已有信息
- **NSFW 协调**：编辑基本信息时若用户切换内容分级为 NSFW，自动触发 NSFW 偏好配置询问并写入 `项目信息.json`

## 关联文件

| 文件 | 位置 | 用途 | 读写 |
|------|------|------|------|
| `设定.md` | `大纲/设定/` 或 `outline/settings/` | 作品设定的唯一输出文件 | 读写 |
| `项目信息.json` | `大纲/` 或 `outline/` | 书名、分级、NSFW 偏好——基本信息区直接引用 | 读写 |
| `润色配置.json` | `大纲/` 或 `outline/` | 润色模式（使用 `大纲.polish_mode`） | 只读 |

**文件定位优先级**：
1. 当前工作目录 → `大纲/设定/设定.md`
2. 当前工作目录 → `outline/settings/settings.md`
3. 用户手动指定的路径
4. 以上均不存在 → 提示用户先运行"新书"技能创建项目

## 执行模式：计划模式

**调用此技能后，必须首先进入计划模式（EnterPlanMode）。**

1. 使用 `EnterPlanMode` 工具进入计划模式
2. 在计划中列出：
   - 目标设定文件路径
   - 当前各板块完成状态（已填写/待填写/必选/可选）
   - 本次将编辑的板块和询问内容
   - 润色模式（从 `大纲.polish_mode` 读取）
3. 等待用户批准计划后执行
4. 不要在进入计划模式前直接开始询问或写入

## 触发条件

当用户表达以下意图时，立即调用此技能：

- "编辑设定"、"修改设定"、"完善设定"、"写设定"
- "世界观设定"、"编辑世界观"、"完善世界观"、"开始设定"
- "补充核心设定"、"修改基本信息"、"补充简介"、"编辑次要设定"
- "打开设定"、"做设定"、"设定编辑"、"填写设定"、"更新设定"、"调整设定"
- 任何表达"编辑/完善作品世界观或设定文件"的类似表述

## 设定文件模板

最终的设定文件应遵循以下结构（`[]` 为必填，`{}` 为说明）：

```markdown
# {书名} — 作品设定

> 最后更新：{YYYY年MM月DD日}

## 基本信息

- **书名**：{书名}
- **传播范围**：{传播向 / 个人向}
- **内容分级**：{一般向 / NSFW}
- **篇幅长度**：{随笔 / 短篇 / 短篇（连载） / 中篇 / 长篇}
- **书籍种类**：{用户填写的种类}

---

## 简介

{对外展示的作品简介或自己对作品的基本描述，可同时存在}

### 对外简介

{面向读者的宣传简介，50-100字为宜}

### 个人描述

{作者自己对作品的理解和定位，可随意写}

---

### 核心设定 [必选]

{包含会出场的人物、世界、故事走向的基本描述}

**人物**：{主要出场人物及角色定位}

**世界**：{世界观一句话概括}

**故事走向**：{主线故事的基本方向和核心冲突}

---

### 世界观 [必选]

{描述这个世界的方方面面。以下各项使用加粗标题，不使用 ### 或更深标题，保持大纲等级 ≤2}

**{分类项1}**：
{内容}

---

**{分类项2}**：
{内容}

---

### 次要设定 [可选]

{分类收纳其他次要设定，便于人类查看和后续扩展}

#### {分类1}

{内容}

#### {分类2}

{内容}
```

## 模板规则

| 板块 | 必填 | 标题格式 | 内容格式 |
|------|------|---------|---------|
| 基本信息 | 是 | `## 基本信息` | 无序列表（`- **字段**：值`） |
| 简介 | 至少填一个 | `## 简介` + `### 对外简介`/`### 个人描述` | 自由文本 |
| 核心设定 | 是（三要素至少一个） | `### 核心设定 [必选]` | 粗体子标题 `**人物**：`/`**世界**：`/`**故事走向**：` |
| 世界观 | 是（至少一个分类项） | `### 世界观 [必选]` | 子项用 `**{分类}**：` 格式，不加 `###`，保持在 ≤ h2 层级 |
| 次要设定 | 否 | `### 次要设定 [可选]` | `#### {分类}` 小标题收纳 |

**核心规则**：
- 世界观子项大标题使用 `**{项}**：` 加粗格式，不使用 `###` / `####` 标题——保持在 ≤ h2 结构层级下，与剧情大纲保持同级
- 子项之间以 `---` 分割线分隔
- 基本信息与 `项目信息.json` 保持同步——修改基本信息时同步更新 JSON

## 工作流程

### 步骤 0：定位并读取设定文件

**0.1 定位文件**

按关联文件优先级查找设定文件：

```
大纲/设定/设定.md  →  outline/settings/settings.md  →  用户手动指定
```

**0.2 文件状态处理**

| 文件状态 | 处理 |
|---------|------|
| 文件存在 | `Read` 读取全文，进入步骤 1 |
| 文件不存在 | 询问用户：在当前目录新建 / 指定已有路径 / 先创建新书项目 |
| 文件存在但为空 | 视为"待填写"状态，按模板注入初始骨架后进入步骤 1 |

**0.3 新建设定文件**

若用户选择新建：
1. 以当前工作目录名或用户指定的书名为准
2. 按上述设定文件模板写入初始骨架
3. 各板块内容写为 `（待填写）`

**0.4 同步读取上下文**

读取设定文件后，同步读取 `项目信息.json` 和 `润色配置.json`：
- 从 `项目信息.json` 提取：`book_name`、`distribution`、`content_rating`、`length`、`genre`、`volumes`
- 从 `润色配置.json` 提取：`大纲.polish_mode`、`正文.polish_mode`、`分卷` 覆盖项
- 如设定文件中的基本信息与 JSON 不一致 → 以 JSON 为准，标注差异供用户确认

### 步骤 1：展示状态并询问编辑目标

读取文件后，向用户展示各板块完成状态：

```
📋 「{书名}」作品设定状态

| 板块 | 状态 | 约束 |
|------|------|------|
| 基本信息 | ✅ 已填写 / ⬜ 待填写 | — |
| 简介 | ✅ 已填写 / ⬜ 待填写 | 至少填一个 |
| 核心设定 | ✅ 已填写 / ⬜ 待填写 | 🔴 必选 |
| 世界观 | ✅ 已填写 / ⬜ 待填写 | 🔴 必选（≥1 分类项） |
| 次要设定 | ✅ 已填写 / ⬜ 待填写 | ⭕ 可选 |

你想编辑哪个部分？
  • 输入编号 1-5 选择单个板块
  • 输入"全部"按顺序逐一引导
  • 输入"跳过"结束编辑
```

### 步骤 2：按板块引导编辑

根据用户选择，逐一引导。每次只处理一个板块，完成后回到选择界面（除非用户选了"全部"连续模式）。

**用户可随时说**："回到板块选择"、"换一个"、"直接编辑世界观"——支持自由跳转。

#### 2.1 编辑基本信息

**2.1.1 读取现状**

从 `项目信息.json` 读取当前基本信息：

```
📌 当前基本信息（来源：项目信息.json）
  • 书名：{book_name}
  • 传播范围：{distribution}
  • 内容分级：{content_rating}
  • 篇幅长度：{length}
  • 书籍种类：{genre}

需要修改哪一项？输入项名 / "全部"逐项修改 / "跳过"维持现状
```

**2.1.2 逐项修改**

修改顺序：书名 → 传播范围 → 内容分级 → 篇幅长度 → 书籍种类。

**传播范围选项**：
```
📡 传播范围：
  • 传播向 — 公开发布，面向广泛读者
  • 个人向 — 自娱自乐，仅个人/小圈子阅读
```

**内容分级规则**：
- 默认保持 `一般向`
- 用户主动提及 NSFW/成人内容时才切换为 `NSFW`
- **切换为 NSFW 时**：自动触发 NSFW 偏好配置询问（色色值域/输出词级别/角色语气），组装 JSON 后调度 `成品输出校验` → 校验后写入 `项目信息.json`

```
🔞 检测到内容分级切换为 NSFW。推荐配置 NSFW 写作偏好：

① 全书色色值域？（如 N3-N4）
   N1—点到为止  N2—情色剧情并重  N3—情色为主
   N4—纯情色驱动  N5—纯情色不间断

② NSFW 输出词级别？
   A. 词汇开放度：优雅级（优雅代称）→ 直白级（直白露骨）
   B. 角色语气：保守（文雅含蓄）→ 中性（自然直白）→ 放荡（粗俗刺激）

（均可跳过，后续 /nsfw-config 随时配置）
```

**篇幅长度选项**：
```
📏 篇幅长度：
  • 随笔 — ＜5万字
  • 短篇 — ≤20万字
  • 短篇（连载） — ≤35万字
  • 中篇 — ≤60万字
  • 长篇 — ＞60万字
```

**2.1.3 双写同步**

基本信息修改后，必须同步更新两个位置：
1. `设定.md` 中的 `## 基本信息` 区块
2. `项目信息.json` 中对应的 JSON 字段 + `last_updated`

```
✅ 基本信息已更新
  • 设定.md ── 基本信息区块已同步
  • 项目信息.json ── {修改项} 已更新
```

#### 2.2 编辑简介

简介支持双轨：对外简介（读者面向）和个人描述（作者面向）。

**2.2.1 状态检查**

展示当前状态后逐一处理：

```
📝 简介板块
  • 对外简介：{当前内容 / （待填写）}
  • 个人描述：{当前内容 / （待填写）}
```

**2.2.2 编辑对外简介**

```
📝 是否需要填写/修改「对外简介」？
  （面向读者的宣传语，50-100字为宜。输入内容 / "跳过"）

✏️ 请描述：
```

用户输入后，按 `大纲.polish_mode` 润色后展示确认：
```
润色后：
{润色后文字}

这样可以吗？（"可以"写入 / "修改"重新输入）
```

**正反例对照**：

| ✕ 不合适的对外简介 | ✓ 合适的对外简介 |
|-------------------|-----------------|
| `这是一个关于主角成长的故事，他经历了很多事情最后成功了` | `少年背负灭门之仇踏入江湖，却在追寻真相的路上发现——敌人可能不是人。一部融合悬疑与仙侠的复仇之旅。` |
| `好看，冲就完了` | `轻松日常向甜宠文。冷面王爷×话痨医女，先婚后爱，日常互怼。` |

**2.2.3 编辑个人描述**

```

  （你自己对这本书的理解和定位，可随意写。输入内容 / "跳过"）
```

处理流程同 2.2.2。

**2.2.4 空值检查**

两个子项均跳过时，在对外简介处写入 `（待填写）`。

#### 2.4 编辑世界观 [必选]

世界观是必填项，由多个分类子项组成。至少需要一个分类项。

```
**{分类项名称}**：
```

- 不使用 `###` / `####` 标题符号——保持大纲等级 ≤ h2
- 条目之间以 `---` 分割

```

  • 添加 — 新增一个世界观分类项

```

```
   → {用户输入内容}
```

**修改已有**：
```
🌌 要修改哪个分类？
  1. {分类名1}
  2. {分类名2}
```

**删除分类**：
```
⚠️ 确定要删除「{分类名}」吗？此操作不可撤销。
```

**重命名**：

**2.4.3 空值约束**

#### 2.5 编辑次要设定 [可选]

次要设定完全可选，结构类似世界观但使用 `####` 小标题分类。

**2.5.1 状态展示**

```
⭕ 次要设定 — 可选板块

当前状态：{已填写 N 项 / （暂不填写）}

需要编辑吗？
  • 是 — 进入管理循环
  • 否 — 保持现状，回到板块选择
```

**2.5.2 管理循环**

与世界观 2.4.2 管理循环一致：添加 / 修改 / 删除 / 重命名 / 完成。

分类示例：道具设定、组织设定、历史年表、文化习俗、货币体系、交通方式等。

**2.5.3 空值处理**

用户选择不填写或全部删除：
```
⭕ 次要设定已清空，在设定文件中标注为「（暂不填写）」。
   后续随时可说"编辑次要设定"重新打开。
```

#### 2.6 润色加工（贯穿全流程）

每次用户输入内容后，遵循项目润色配置：

1. 读取 `大纲/润色配置.json`（或 `outline/polish-config.json`）
2. **润色模式取用优先级**：先查 `分卷.{当前编辑所属卷号}` → 无覆盖项则用 `大纲.polish_mode`
3. 根据有效 `polish_mode` 值决定加工深度：

| 模式 | 加工策略 | 适用板块 |
|------|---------|---------|
| `轻度` | 保留用户原话结构与用词，仅书面化、规范化 | 全部板块 |
| `中度` | 在用户原话基础上小幅优化表达，改动幅度 ≤45% | 全部板块 |
| `重度` | 保留原意，完全改写润色——对简介/核心设定可扩写，对世界观/次要设定保留结构仅优化表达 | 简介/核心设定可扩写；世界观/次要设定保留结构 |

4. 润色后向用户展示修改结果：
```
✏️ 润色后（{polish_mode}模式）：
{润色后文字}

这样可以吗？
  • 可以 — 写入设定文件
  • 修改 — 重新调整
  • 用原文 — 不做润色，直接写入原话
```

5. 用户选择"用原文"时尊重原话，仅做标点和基本格式修正

### 步骤 3：保存文件

**保存流程**：
1. 定位目标板块在文件中的起止位置
2. 替换该板块的内容为编辑后的版本
3. 更新文件顶部的 `> 最后更新：{日期}`
4. 确认写入成功后简短反馈：`✅「{板块名}」已更新`

**去重保护**：同一板块连续编辑时，以最后一次确认为准。

## 注意事项

- **必选约束不可绕过**：核心设定和世界观不允许完全空白。用户跳过后再次回到板块选择时继续提醒
- **双写同步**：基本信息修改时必须同步更新 `设定.md` 和 `项目信息.json`——两者不一致会导致后续技能读取错误
- **文件即时保存**：每完成一个板块编辑立即调度 `成品输出校验`（`type: "structured_md"`, `md_category: "设定"`, `file_path`；如同时修改了 `项目信息.json` 则另传 JSON 数据包）→ 校验后落盘。禁止自行 Write，防止连续编辑多个板块后崩溃丢失全部数据
- **NSFW 触发边界**：仅用户主动提及时才将 content_rating 切换为 NSFW。不在例行询问中出现 NSFW 相关内容
- **润色模式灵活切换**：用户可在编辑过程中随时说"切换润色模式"、"分卷润色配置"，不影响已保存内容
- **分卷润色独立管理**：分卷项目支持每卷独立润色模式，通过"分卷润色配置"进入管理；未配置卷自动继承全局大纲模式
- **文件路径特殊字符**：书名/路径中的 `/` `\` `:` `*` `?` `"` `<` `>` `|` 自动替换为 `_`
- **保持引导式语气**：每次只问一个问题，不给用户"考试感"
- **与剧情大纲/角色文件的关系**：设定文件是世界观约束的唯一来源，剧情编辑和人物创建均从此读取设定约束——设定不完善时提示用户优先完善
