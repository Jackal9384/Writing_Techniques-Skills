# Writing Techniques — 懒人写作工具集

> 一个业余爱好者的 Vibe Coding 项目，基于纯文本模式打造的一套懒人式写作工具，使用AI辅助创建，会不定期更新更多的专项写作技能。

## 这是什么

一个运行在 Claude Code 中的写作技能包，覆盖小说创作从立项到正文的全流程。技能包内容仅包含Markdown文件。

## 技能列表（共 7 项）

| # | 技能         | 一句话                                                     |
|---|------------|---------------------------------------------------------|
| 1 | **创建新书**   | 建立项目文件夹结构，收集书名/篇幅/种类等元数据                                |
| 2 | **创建人物**   | 按模板创建角色，新增角色自动双向更新人物关系                                  |
| 3 | **剧情编辑**   | 规划故事主线，支持连载（5 阶段）与非连载（4 阶段）两套模板，可自由增减分卷                 |
| 4 | **设定编辑**   | 编辑世界观、核心设定、简介、次要设定等，逐板块引导填写                             |
| 5 | **基础写作辅助** | 正文润色核心引擎——五条写作规范（段落节奏/人物间接描写/风景穿插/对话增强/防过度润色），区分大纲与正文档位 |
| 6 | **学生作文**   | 中小学作文写作助手                                               |
| 7 | **快速重建**   | 将已有的旧作设定按 WT 规范标准化迁移                                    |

## 设计思路

- **纯文本驱动**：所有数据以 `.md` 和 `.json` 存储，可直接用任何文本编辑器打开修改
- **对话即操作**：不设菜单、不设按钮，一切通过自然语言触发
- **懒人友好**：能自动的不手动的，能推断的不询问的，能用默认值的不让你选的
- **润色分层**：大纲有一套润色标准，正文有另一套——两者独立配置，进入正文时二次确认
- **项之间松耦合**：每个技能独立运作，按需互相调度，不强依赖

## 使用方式

在 Claude Code 中安装此技能包后，直接使用自然语言对话即可：

- "创建一本新书" → 启动项目
- "创建人物" → 添加角色
- "编辑剧情" → 规划故事线
- "编辑设定" → 完善世界观
- "写正文/润色这段" → 调用写作辅助优化文本
- "帮我写作文" → 学生作文模式
- "整理已有设定" → 旧作迁移

也支持独立辅助写作技能调用，满足短文需求。

## 项目结构（创建后）

```
[书名]/
├── 作品状态.json          ← 大纲完善度追踪
├── 大纲/
│   ├── 项目信息.json      ← 书名/篇幅/种类等元数据
│   ├── 润色配置.json      ← 大纲&正文独立润色档位
│   ├── 设定/
│   │   └── 设定.md        ← 世界观/核心设定
│   ├── 人物/
│   │   └── 人物存档.md    ← 所有角色统一存档
│   └── 剧情/
│       └── 剧情大纲.md    ← 故事主线与分卷
├── 正文/                  ← 正式章节（第XX章 章节名.md）
└── 番外/                  ← 番外篇（番外篇名（X）.md）
```
