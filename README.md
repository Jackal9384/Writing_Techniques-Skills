## 这是什么

一套运行在 Claude Code 中的写作技能包，覆盖小说创作从立项到正文的全流程。

技能包内容仅包含 Markdown 与 Json 文件。

## 推荐配置

- 推荐将 `成品输出校验` 交给单独的 Agent 负责，避免占用主对话上下文
- 推荐使用 `提示词增强` 的**辅助创建模式**而非全自动模式——至少告诉 AI 你每章想看到什么情节、或每阶段想看到什么情节，输出质量远高于零提示词全自动生成
- 提示词工程仍是目前阶段调教 AI 最好用的工具——花几分钟写好一章的提示词，比事后反复修改正文更高效

## 技能列表

```
大纲类/    创建新书 · 创建人物 · 剧情编辑 · 设定编辑 · 快速创建
写作类/    路由（Write-Router）· 核心（基础写作辅助）
           专项（战斗[对决+战争子项] · 言情 · 长篇）
           辅助（提示词增强 · 成品输出校验）
其他类/    学生作文
```

**模板库（templates/）**：设定类模板的字段定义统一 schema 化（人物/设定/剧情大纲/项目配置等）——新增字段只改一处 JSON，校验与生成同源不漂移。

**规范库（body/Core/norms/）**：写作规范按内容类型分组独立成文件，由 Core 按需加载执行——正文写作加载量 -50%，新增规范只需建文件 + 注册一行。

**规格数据（data/）**：大块数据（内容检测/分发协议/校验清单/伏笔规格/章节张力指引等）外置于此，经 `data-registry.json` 注册、被引用才有效——防止 SKILL.md 臃肿。

## 设计思路

- **模板库驱动**：设定类模板字段 JSON schema 化（`templates/`）——新增字段只改 JSON 一处，校验与生成同源不漂移
- **数据外置防臃肿**：大块数据（词汇表/协议/阈值）外置 `data/`，SKILL.md 只保留规则与流程；数据经 `data-registry.json` 注册、被引用才有效
- **程序化规范库**：Core 拆为「执行引擎 + 规范库按需加载」——按内容类型选组读取，正文写作加载量 -50%、大纲场景 -75%；新增规范只需建文件 + 注册一行
- **规格数据一次性加载**：协议/检查项/阈值类数据首次调度完整读取一次进入工作记忆，之后按记忆执行；规则变更/新会话重读
- **字段级精确**：field_name 协议校验 + 字段→加工标准映射 + `facts` 事实约束块随数据包分发——OOC 约束前移至写作前
- **正文阶段张力双结构**：阶段级事件烈度（tension_level L1-L5）+ 章节分类级二次规划（chapter_type 7 类）——张力只指导事件安排，不挂钩写作参数；传导与指引解耦
- **叙事质量增强**：剧情规划六维度校验新增叙事质量维度——波动模型软引导 + 剧情点四要素强制 + 冲突双类型 + 代价豁免
- **懒人友好**：对话即操作，能自动的不手动，能推断的不询问，能用默认值的不让你选
- **自适应路由**：自然语言意图识别 → 自动分发到对应子技能，无需记命令
- **全流程串联**：标准写作流水线由 Write-Router 独家驱动（用户提示词 → 路由 → Core+专项 → 长篇专项 → 成品输出校验），各技能松耦合独立运作

## 典型创作流程

```
创建新书 ──→ 创建人物 ──→ 编辑设定 ──→ 剧情编辑
                                          │
                                          ▼
                                     提示词增强
                                          │
                                          ▼
                                  Write-Router（写正文）
                                        ├→ Core（一般）
                                        ├→ Combat（战斗）
                                        └→ Romance（言情）
                                          │
                                          ▼
                                   长篇专项 → 成品输出校验
```

> 流程非强制，随时可跳转或中途加入。已有现成设定可从「快速创建」直接起步。

## 使用方式

在 Claude Code 中安装此技能包后，直接使用自然语言对话即可：

**项目创建**
- "创建一本新书" → 启动项目，收集元数据
- "快速创建 / 迁移旧作" → 有现成设定的快速重建

**大纲规划**
- "创建人物" → 添加角色（支持龙套快速通道）
- "编辑剧情" → 三模式规划故事线
- "编辑设定" → 五大板块完善世界观

**正文写作**
- "写正文 / 润色这段" → 路由至 Write-Router → 自动检测内容类型 → 分发处理
- "写第X章"（无提示词）→ 自动调度提示词增强生成写作指令
- "写一场战斗 / 优化这段打斗" → 自动调度战斗描写专项
- "写战争 / 写战役 / 写攻城" → 自动调度战斗描写专项 warfare 子项（以小见大：指挥部/参谋部/一线多场景切片组合，软引导）
- "写一段感情戏 / 优化这段暧昧描写" → 自动调度言情写作专项

**伏笔管理**
- "这是一个伏笔"（正文中标注）→ 自动登记
- "回收XX伏笔" → 更新伏笔状态为已回收
- "查看伏笔 / 还有哪些坑没填" → 全书伏笔清单 + 状态诊断
- "之前第X章发生了什么" → 跨章节情节回忆

**质量校验与其他**
- "检验一下 / 检查标点" → 成品输出校验（标点+结构双轨扫描，违规自动修正）
- "帮我写作文" → 学生作文模式（小初高）

## 项目结构（创建后）

```
{书名}/
├── 大纲/
│   ├── 项目信息.json        ← 书名/篇幅/种类等元数据（权威数据源）
│   ├── 写作配置.json        ← 大纲&正文独立润色档位，支持分卷覆盖
│   ├── 设定/设定.md         ← 世界观/核心设定/次要设定
│   ├── 人物/人物存档.md     ← 所有角色统一存档（主要/次要/龙套）
│   └── 剧情/剧情大纲.md + Prompt.md（批量生成的写作提示词）
├── 正文/                    ← 正式章节（第XX章 章节名.md）
└── 番外/                    ← 番外篇（番外篇名（X）.md）
```
