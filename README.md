# Writing Techniques — 懒人写作工具集

> 一个业余爱好者的 Vibe Coding 项目，基于纯文本模式打造的懒人式写作工具。AI 辅助创建，不定期更新更多专项写作技能。

[**中文**](README.md) | [English](README_EN.md)

V0.20

## 这是什么

一套运行在 Claude Code 中的写作技能包，覆盖小说创作从立项到正文的全流程。

技能包内容仅包含 Markdown 与 Json 文件。

## 推荐配置

- 推荐将 `成品输出校验` 交给单独的 Agent 负责，避免占用主对话上下文
- 推荐使用 `提示词增强` 的**辅助创建模式**而非全自动模式——至少告诉 AI 你每章想看到什么情节、或每阶段想看到什么情节，输出质量远高于零提示词全自动生成
- 提示词工程仍是目前阶段调教 AI 最好用的工具——花几分钟写好一章的提示词，比事后反复修改正文更高效

## 设计思路

- **纯文本驱动**：所有数据以 `.md` 和 `.json` 存储，可直接用任何文本编辑器打开修改
- **对话即操作**：不设菜单、不设按钮，一切通过自然语言触发
- **懒人友好**：能自动的不手动，能推断的不询问，能用默认值的不让你选
- **润色分层**：大纲有一套润色标准，正文有另一套——两者独立配置，进入正文时二次确认
- **伏笔追踪**：放置时自动登记，回收时自动匹配，跨章未回收伏笔自动提醒
- **全自动写作**：支持零提示词批量生成章节提示词，持久化至 Prompt.md 后可随时执行
- **项之间松耦合**：每个技能独立运作，Write-Router 统一编排调度，各写作技能专注本职工作
- **自适应路由**：自然语言意图识别 → 自动分发到对应子技能，无需记命令
- **标准写作流水线**：用户提示词 → Write-Router（判断+预分配）→ Core + 专项技能 → 长篇专项 → 成品输出校验，全流程由 Write-Router 独家驱动

## 典型创作流程

```
创建新书 ──→ 创建人物 ──→ 编辑设定 ──→ 剧情编辑
                                          │
                                          ▼
                                     提示词增强
                                          │
                                          ▼
                                  Write-Router（写正文）
                                          │
                              ┌───────┼───────┐
                              ▼       ▼       ▼
                            Core   Combat  Romance
                          （一般）  （战斗） （言情）
                              │       │       │
                              └───────┼───────┘
                                      ▼
                                 长篇专项
                               （伏笔/回忆）
                                      │
                                      ▼
                                成品输出校验
                               （校验+落盘）
```

> 流程非强制，随时可跳转或中途加入。已有现成设定可从「快速创建」直接起步。

### 标准写作流水线（Write-Router 驱动）

接收到用户创作意图后，由 Write-Router 独家编排执行：

```
用户提示词 → Write-Router
              ├── ① 内容检测与判断
              ├── ② 段落预分配
              ├── ③ 并行调度
              │      ├── general  → Core（纯文本优化）
              │      ├── combat  → 战斗描写专项
              │      └── romance → 言情写作专项
              ├── ④ 结果整合 + 豁免收集 + 一致性过检
              ├── ⑤ → 长篇专项（伏笔登记/剧情回忆）
              └── ⑥ → 成品输出校验（标点+结构→落盘）
```

各环节由 Write-Router 自动检测并调度下游技能，无需用户手动触发。

## 使用方式

在 Claude Code 中安装此技能包后，直接使用自然语言对话即可：

**项目创建：**

- "创建一本新书" → 启动项目，收集元数据
- "快速创建 / 迁移旧作" → 有现成设定的快速重建

**大纲规划：**

- "创建人物" → 添加角色（支持龙套快速通道）
- "编辑剧情" → 三模式规划故事线
- "编辑设定" → 五大板块完善世界观

**正文写作：**

- "写正文 / 润色这段" → 路由至 Write-Router → 自动检测内容类型 → 分发处理
- "写第X章"（无提示词）→ Write-Router 自动调度提示词增强 → 生成写作指令 → 执行
- "你再帮我补一点" → 单章提示词扩充
- "批量生成章节提示词" → 全自动生成第X到Y章提示词，存储至 Prompt.md
- "写一场战斗 / 优化这段打斗" → Write-Router 检测战斗内容 → 自动调度战斗描写专项
- "写一段感情戏 / 优化这段暧昧描写" → Write-Router 检测言情内容 → 自动调度言情写作专项

**伏笔管理：**

- "这是一个伏笔"（在正文中标注）→ 自动登记
- "回收XX伏笔" → 更新伏笔状态为已回收
- "查看伏笔 / 还有哪些坑没填" → 全书伏笔清单 + 状态诊断
- "之前第X章发生了什么" → 跨章节情节回忆

**质量校验：**

- "检验一下 / 检查标点" → 成品输出校验（标点+结构双轨扫描，违规自动修正）

**其他：**

- "帮我写作文" → 学生作文模式（小初高）

## 项目结构（创建后）

```
{书名}/
├── 大纲/
│   ├── 项目信息.json        ← 书名/篇幅/种类等元数据（权威数据源）
│   ├── 润色配置.json        ← 大纲&正文独立润色档位（轻度/中度/重度）
│   ├── 设定/
│   │   └── 设定.md          ← 世界观/核心设定/次要设定
│   ├── 人物/
│   │   └── 人物存档.md      ← 所有角色统一存档（主要/次要/龙套三区）
│   └── 剧情/
│       ├── 剧情大纲.md      ← 故事主线与分卷
│       └── Prompt.md        ← 批量生成的写作提示词（提示词增强输出）
├── 正文/                    ← 正式章节（第XX章 章节名.md）
└── 番外/                    ← 番外篇（番外篇名（X）.md）
```
