# Writing Techniques — 懒人写作工具集

> 一个业余爱好者的 Vibe Coding 项目，基于纯文本模式打造的懒人式写作工具。AI 辅助创建，不定期更新更多专项写作技能。

[**中文**](README.md) | [English](README_EN.md)

## 这是什么

一套运行在 Claude Code 中的写作技能包，覆盖小说创作从立项到正文的全流程。技能包内容仅包含 Markdown 文件，共 11 项子技能。

## 技能列表

```
大纲类技能（5项）/
├── 创建新书      ← 建立项目文件夹结构，收集书名/篇幅/种类等元数据，生成配置文件
├── 创建人物      ← 按模板创建角色（主要/次要/龙套三类别），自动双向更新人物关系
├── 剧情编辑      ← 三模式（手动/辅助/自动）规划故事线，连载/非连载双模板
├── 设定编辑      ← 五大板块逐板块引导填写：基本信息/简介/核心设定/世界观/次要设定
└── 快速创建      ← 已有旧作设定按WT规范标准化迁移，支持手动/自动双模式

写作类技能（5项）/
├── 核心
│   └── 基础写作辅助  ← 正文润色引擎，七项写作规范（段落节奏/间接描写/性格间接化/
│                       风景穿插/对话增强/降重率），区分大纲与正文档位
├── 专项
│   └── 长篇专项      ← 伏笔全生命周期管理（放置/登记/回收/清单），跨章节情节回忆
└── 辅助
    ├── 提示词增强    ← 读取剧情大纲→聚合人物/设定/伏笔/润色配置→输出LLM可直接执行的
    │                   高质量写作提示词，批量处理时经用户允许持久化至 Prompt.json
    └── 成品输出校验  ← 输出前最终合规校验：CPS.json标点扫描 + Core规范段落/字句结构
                        扫描双轨检验，违规自动修正至通过后输出

其他类技能（1项）/
└── 学生作文          ← 中小学作文写作助手，自动识别文体/适配年级/控制字数
```

## 设计思路

- **纯文本驱动**：所有数据以 `.md` 和 `.json` 存储，可直接用任何文本编辑器打开修改
- **对话即操作**：不设菜单、不设按钮，一切通过自然语言触发
- **懒人友好**：能自动的不手动，能推断的不询问，能用默认值的不让你选
- **润色分层**：大纲有一套润色标准，正文有另一套——两者独立配置，进入正文时二次确认
- **伏笔追踪**：放置时自动登记，回收时自动匹配，跨章未回收伏笔自动提醒
- **全自动写作**：支持零提示词批量生成章节提示词，持久化至 Prompt.json 后可随时执行
- **项之间松耦合**：每个技能独立运作，按需互相调度，不强依赖
- **自适应路由**：自然语言意图识别 → 自动分发到对应子技能，无需记命令

## 典型创作流程

```
创建新书 ──→ 创建人物 ──→ 编辑设定 ──→ 剧情编辑
                                          │
                                          ▼
                                     提示词增强
                                          │
                                          ▼
                                     写正文（基础写作辅助）
                                          │
                                    ┌─────┴─────┐
                                    ▼             ▼
                               成品输出校验    长篇专项
                                              （伏笔/回忆）
```

> 流程非强制，随时可跳转或中途加入。已有现成设定可从「快速创建」直接起步。

## 使用方式

在 Claude Code 中安装此技能包后，直接使用自然语言对话即可：

**项目创建：**

- "创建一本新书" → 启动项目，收集元数据
- "快速创建 / 迁移旧作" → 有现成设定的快速重建

**大纲规划：**

- "创建人物" → 添加角色（支持龙套快速通道）
- "编辑剧情" → 三模式规划故事线
- "编辑设定" → 五大板块完善世界观

**正文写作：**

- "写正文 / 润色这段" → 调用基础写作辅助优化文本
- "写第X章"（无提示词）→ 自动调度提示词增强 → 生成写作指令 → 执行
- "你再帮我补一点" → 单章提示词扩充
- "批量生成章节提示词" → 全自动生成第X到Y章提示词，存储至 Prompt.json

**伏笔管理：**

- "这是一个伏笔"（在正文中标注）→ 自动登记
- "回收XX伏笔" → 更新伏笔状态为已回收
- "查看伏笔 / 还有哪些坑没填" → 全书伏笔清单 + 状态诊断
- "之前第X章发生了什么" → 跨章节情节回忆

**质量校验：**

- "检验一下 / 检查标点" → 成品输出校验（标点+结构双轨扫描，违规自动修正）

**其他：**

- "帮我写作文" → 学生作文模式（小初高）

## 项目结构（创建后）

```
{书名}/
├── 大纲/
│   ├── 项目信息.json        ← 书名/篇幅/种类等元数据（权威数据源）
│   ├── 润色配置.json        ← 大纲&正文独立润色档位（轻度/中度/重度）
│   ├── 设定/
│   │   └── 设定.md          ← 世界观/核心设定/次要设定
│   ├── 人物/
│   │   └── 人物存档.md      ← 所有角色统一存档（主要/次要/龙套三区）
│   └── 剧情/
│       ├── 剧情大纲.md      ← 故事主线与分卷
│       └── Prompt.json      ← 批量生成的写作提示词（提示词增强输出）
├── 正文/                    ← 正式章节（第XX章 章节名.md）
└── 番外/                    ← 番外篇（番外篇名（X）.md）
```
